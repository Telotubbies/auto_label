\begin{abstract}
\renewcommand{\abstractname}{Abstract}
\noindent
This work presents an automated dataset construction pipeline for Personal Protective Equipment (PPE) detection using SAM 3.1, and a comprehensive benchmark of two YOLO26 medium models for both object detection and instance segmentation. The dataset comprises 662 images covering four classes---\texttt{person}, \texttt{helmet}, \texttt{closed footwear}, and \texttt{harness}---split into 566 training (85.5\%), 48 validation (7.3\%), and 48 test (7.3\%) images. Both models---YOLO26m (detection) and YOLO26m-seg (segmentation)---were trained under a unified two-stage optimizer schedule (SGD stage 1 + AdamW stage 2) with deterministic seed 42 on identical hardware (AMD Radeon RX 7800 XT via ROCm on WSL2).

Experimental results on the test set show that YOLO26m detection achieves mAP@0.5 of 0.693, mAP@0.5:0.95 of 0.507, precision of 0.795, and recall of 0.657. YOLO26m-seg segmentation achieves box mAP@0.5 of 0.599 and mask mAP@0.5 of 0.512. For fair comparison, YOLO26s (small) models were trained on the same v3 four-class dataset with the identical two-stage recipe: small detection achieves mAP@0.5 of 0.670 (slightly below medium's 0.693), and small segmentation achieves box mAP@0.5 of 0.566 (competitive with medium's 0.599) at less than half the parameters. All models were exported to ONNX and evaluated; medium ONNX metrics closely match PyTorch ($\Delta$mAP@0.5 $<$ 0.02), confirming export fidelity. Blur robustness testing on 48 blurred images shows the detection model produces 718 detections (avg 15.0/image) and the segmentation model produces 814 detections (avg 17.0/image), with zero images yielding zero detections. Raw-image predictions were generated for 480 images (48 blurred + 432 custom capture) across both models. All experiment provenance is tracked in SQLite and MLflow.

\vspace{8pt}
\noindent\textbf{Keywords:} SAM 3.1, Automated Annotation, Dataset Construction, YOLO26m, Object Detection, Instance Segmentation, ONNX Export, Blur Robustness, MLflow
\end{abstract}

\section{Introduction}

\subsection{Background and Motivation}

Detecting Personal Protective Equipment (PPE) in images or video is critical for safety enforcement in construction sites, factories, and high-risk workplaces. Effective models must satisfy two competing requirements: \emph{accuracy} to correctly identify equipment and \emph{speed} sufficient for real-time deployment.

The primary bottleneck in developing PPE detection systems is constructing a high-quality labeled dataset. Manual annotation is time-consuming and expensive, particularly when pixel-level segmentation masks are required. Segment Anything Model (SAM) 3.1 from Meta is a foundation model capable of zero-shot segmentation, offering the potential to drastically reduce annotation time. Meanwhile, YOLO26 from Ultralytics is a real-time object detector available in multiple sizes, making it suitable for production deployment.

\subsection{Configuration}

This iteration of the pipeline uses a \textbf{4-class configuration}:
\begin{itemize}[leftmargin=2cm, itemsep=2pt]
  \item \texttt{person}
  \item \texttt{helmet}
  \item \texttt{closed footwear}
  \item \texttt{harness}
\end{itemize}

The previous 6-class configuration (including \texttt{boots}, \texttt{shoes}, \texttt{sandals}) was consolidated: footwear classes are merged into \texttt{closed footwear}, and \texttt{sandals} is excluded as a non-PPE class. Only \textbf{medium-sized models} (YOLO26m) are trained in this iteration, per the production decision to focus on the accuracy--speed sweet spot.

\subsection{Research Objectives}

\begin{itemize}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{O1:} Develop an automated annotation pipeline using SAM 3.1 to construct a 4-class PPE dataset.
  \item \textbf{O2:} Train and benchmark YOLO26m detection and segmentation models under a two-stage optimizer schedule.
  \item \textbf{O3:} Evaluate ONNX export fidelity, blur robustness, and real-world generalization.
\end{itemize}

\section{Dataset}

\subsection{Overview}

The PPE dataset (combined version 3) contains 662 images with 4 classes: \texttt{person}, \texttt{helmet}, \texttt{closed footwear}, and \texttt{harness}. Annotations were generated by SAM 3.1 with per-class text prompts and exported in COCO and YOLO formats. Image-level PPE counts are tracked in a SQLite \texttt{ppe\_counts} table with columns: \texttt{image\_filename}, \texttt{person\_count}, \texttt{helmet\_count\_worn}, \texttt{harness\_count\_worn}, \texttt{closed\_footwear\_count\_worn}.

\section{Methodology}

\subsection{SAM 3.1 Annotation Pipeline}

The annotation pipeline uses SAM 3.1 with text prompts for each PPE class:
\begin{enumerate}[leftmargin=2cm, itemsep=2pt]
  \item Load raw images from \texttt{data/raw/<batch>/}.
  \item For each image, run SAM 3.1 with per-class text prompts.
  \item Apply per-class confidence thresholds and mask IoU NMS.
  \item Export annotations in COCO and YOLO formats.
  \item Generate visualization overlays for human verification.
  \item Record PPE counts in SQLite \texttt{ppe\_counts} table.
  \item Track experiment metadata in MLflow.
\end{enumerate}

\textbf{Key observations:}
\begin{itemize}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{Medium detection outperforms small detection} (mAP@0.5: 0.693 vs 0.670), confirming the expected capacity-accuracy trade-off. The gap is modest (2.3 points), indicating diminishing returns from the larger backbone on this dataset size.

\subsection{Failure Analysis}

Failure cases were identified by scoring missed detections, low confidence, and small object size. The top 10 failure cases across both models are shown in \Cref{fig:failure_montage}.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/failure_montage/montage_combined.jpg}
\caption{Top 10 failure cases (green=GT, red=Pred). Crowded scenes with small objects are the dominant failure mode.}
\label{fig:failure_montage}
\end{figure}

Key failure modes:
\begin{itemize}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{Crowded scenes:} Images with 30+ ground truth objects have high miss rates (up to 21 missed).
  \item \textbf{Small objects:} \texttt{closed footwear} and \texttt{harness} are small and frequently missed.
  \item \textbf{Class imbalance:} \texttt{harness} has very few training samples, resulting in mAP@0.5 of 0.455 (detect) and 0.298 (seg box).
  \item \textbf{Occlusion:} Partial occlusion of PPE by tools or body parts causes missed detections.
\end{itemize}

%%% 5. DISCUSSION
%%% ════════════════════════════════════════════════════════════
\section{Discussion}

\subsection{Key Findings}

\begin{enumerate}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{Detection outperforms segmentation.} YOLO26m detection achieves mAP@0.5 of 0.693 vs segmentation box mAP@0.5 of 0.599. The mask head adds complexity without sufficient mask quality in the training data.
  \item \textbf{Medium outperforms small on detection.} YOLO26m detection (0.693) outperforms YOLO26s (0.670) by 2.3 mAP@0.5 points, confirming the expected capacity-accuracy trade-off. The gap is modest, indicating diminishing returns from the larger backbone on this dataset size.
  \item \textbf{ONNX export is faithful.} The $\Delta$mAP@0.5 between PyTorch and ONNX is $<$ 0.02 for medium models, confirming reliable export. Small models show larger ONNX degradation (likely due to opset/operator fusion differences on CPU).
  \item \textbf{Blur robustness is strong.} Both models produce detections on all 48 blurred images (zero zero-detection images), with the segmentation model actually producing more detections (814 vs 718).
  \item \textbf{Class imbalance persists.} \texttt{harness} remains the weakest class (mAP@0.5 = 0.446 detect, 0.298 seg box) due to very limited training samples.
  \item \textbf{Person and helmet are reliable.} Both classes achieve mAP@0.5 $>$ 0.74 across both medium models.
\end{enumerate}

\subsection{Error Analysis}

The dominant failure modes are:
\begin{itemize}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{Crowded scenes:} Images with 30+ objects have miss rates up to 21 missed detections.
  \item \textbf{Small objects (closed footwear, harness):} Low resolution and small bounding box area reduce detection confidence.
  \item \textbf{Rare classes (harness):} Very few training instances limit diversity even after oversampling.
  \item \textbf{Occlusion:} Partial occlusion of PPE by tools or body parts causes missed detections.
\end{itemize}

\subsection{Known Warnings}

\begin{itemize}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{Resource leak:} Ultralytics reported \texttt{SharedSignalPool} signal leaks after training completion. This is a warning, not a training failure.
  \item \textbf{RAM cache:} \texttt{cache='ram'} may produce non-deterministic results despite deterministic config. Disk cache would ensure stricter reproducibility.
  \item \textbf{Duplicate labels:} 1 duplicate label was removed during training. No impact on final metrics.
\end{itemize}

\section{Conclusion}

This work demonstrates a complete pipeline for 4-class PPE dataset construction and YOLO26m model evaluation:

\begin{enumerate}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{O1 (Automated Annotation):} SAM 3.1 with per-class text prompts produces usable annotations. PPE counts are tracked in SQLite for traceability.
  \item \textbf{O2 (Model Benchmarking):} YOLO26m detection achieves mAP@0.5 = 0.693, outperforming segmentation (box mAP@0.5 = 0.599) and small detection (mAP@0.5 = 0.670). The two-stage SGD$\rightarrow$AdamW schedule with seed 42 produces stable, deterministic results.
  \item \textbf{O3 (ONNX, Robustness, Generalization):} ONNX export is faithful ($\Delta$mAP $<$ 0.02 for medium). Blur robustness is strong (zero zero-detection images). Raw-image predictions on 480 images confirm real-world applicability.
\end{enumerate}

The primary constraint remains dataset scale and rare-class coverage (harness). Future work should focus on collecting more diverse data, particularly for harness, and on statistical rigor via multi-seed evaluation.

%%% 9. FUTURE WORK
%%% ════════════════════════════════════════════════════════════
\section{Future Work}

\begin{enumerate}[leftmargin=2cm, itemsep=2pt]
  \item \textbf{Data expansion:} Collect more images for rare classes (harness) with diverse angles, lighting, and occlusion.
  \item \textbf{Statistical rigor:} Run 5--10 seeds per model and report mean $\pm$ std for all metrics.
  \item \textbf{ONNX GPU:} Resolve \texttt{libhipblas.so.3} dependency to enable ROCm ONNX EP for GPU-accelerated ONNX inference.
  \item \textbf{Model optimization:} Quantization (INT8) and pruning to reduce model footprint for edge deployment.
  \item \textbf{Active learning:} Use model uncertainty to prioritize images for human review.
  \item \textbf{Additional model sizes:} Train nano and small variants for edge deployment comparison.
\end{enumerate}
