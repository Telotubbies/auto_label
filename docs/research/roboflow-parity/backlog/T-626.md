## User story
As a reviewer, I want to confirm a list of differences instead of hunting for what changed, so that a rejection takes one look and points at the object it means.

## UX flow (LabelDesk words)
1. **Review queue → an image → review mode** — the existing warning banner stays; beside the canvas a `Card` lists the conflicts grouped `Missing 2 · Extra 1 · Wrong class 3`. [empty: "No conflicts on this image."] [loading: the panel's three skeleton rows] [error: "No answer key for this project." — the panel is hidden and review mode continues without it]
2. **View toggle `Answer key / Submitted / Both`** — the key draws dashed boxes in the class colour, the submission draws solid; only the selected layers render. [empty: when the key has no labels the toggle shows `Answer key` disabled]
3. **Click a conflict row** — the canvas centres on that box and selects the submitted annotation when there is one.
4. **Edit tools** — hidden while `Answer key` alone is shown, so a reviewer cannot draw on the key; switching to `Submitted` or `Both` restores them.
5. **`Approve` / `Reject`** — unchanged, plus the existing optional note; the conflict list stays visible until the image changes.

## Acceptance criteria
- [ ] Review mode lists the conflicts grouped in a stable order and clicking one centres the canvas on it.
- [ ] The view toggle switches between key, submission and both, and edit tools are locked on the key-only layer.
- [ ] An image without a key hides the panel and leaves review mode exactly as it was.
- [ ] Empty, loading and error states above all render: no-conflicts line, skeleton rows, and the no-key case hiding the panel.
- [ ] Workspace A cannot see workspace B's key: the panel only calls this project's route, and a labeler never reaches review mode.
- [ ] Flag off ⇒ no toggle, no panel and no request.

## Notes for the implementer
Dashed for the key, solid for the submission — the two layers must be distinguishable without colour, per the accessibility rule in `VISUAL-OVERRIDE.md`. Do not add a second canvas: draw the key in the same SVG layer the boxes already use, with a different stroke dash.
