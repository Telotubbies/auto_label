## User story
As an ML engineer, I want the evaluation to end in four concrete actions with counts and a link to the images, so that "mAP 0.61" becomes a list of things to do this afternoon.

## UX flow (LabelDesk words)
1. **Model → Evaluation → Recommendations** — a card with up to six lines, each: severity dot, one sentence with the count, and one link. Order: blockers first (a class with no data), then misses, then false positives, then confusions, then slices, then calibration.
2. **Each line is an action** — "127 images contain no `harness` label — add negatives" → opens the dataset filtered to that class, unannotated, sorted oldest; "22 `harness` images score under 0.3 — review their labels" → opens the model's worst-image gallery; "`helmet` is predicted as `vest` 34 times — check labels" → opens the confusion cell for that pair; "`dark` images reach AP 0.31 — collect night shots" → opens the slice's images where a dataset filter exists, otherwise the worst gallery with the slice named.
3. **Nothing to suggest** — the card reads "Nothing stands out — the next gain is more images." with a link to Upload. [empty: `generated: false` ⇒ "Recommendations are built after the evaluation finishes." instead of an empty card]
4. **Not enough evidence** — an evaluation without stored detections shows one line: "Counts need per-image detections; this run kept none." with the *Re-evaluate* entry (T-283).
5. **Every line is testable** — each item carries `code`, `count` and `link`; a link that cannot be built is omitted and the line says where to look instead of linking to the wrong view.

- **States** — [loading: the card shows three skeleton lines while the first request resolves] [error: a derivation failure returns `generated: false` with a reason, never a 500].

## Backend changes
- Models/schema: none — recomputed from `TrainedModel.metrics.eval` and cached with `insights_common.cached`.
- Routers: `GET {P}/models/{mid}/recommendations` → `{generated: bool, conf: float, items: [{code, severity, title, detail, count, link}]}`; **404** foreign model; no writes.
- Services/jobs: new `apps/backend/app/services/recommendations.py` — `RULES` evaluated in order over `per_class`, `per_class_counts` (T-278), `confusion`, `calibration` and `slices`:
  - `class_without_data` (blocker): `instances == 0` and predictions exist for that class → "`x` has no labelled instances but is predicted — label some or remove the class".
  - `missing_labels` (warn, count = images): a class whose `missed` count is ≥ 20 % of the split's instances → link `browse?class=<id>&annotated=no&sort=oldest`.
  - `false_positives` (warn): `false_positive ≥ 20 %` of predictions for a class → link `browse?class=<id>&min_ann=0&status=review`.
  - `confusion_pair` (warn, count = cell): a cell off the diagonal with `count ≥ 10` and `≥ 15 %` of the row → link `#confusion` with `cell=<row>:<col>` (the gallery opens from the panel).
  - `class_needs_data` (warn): `instances < 50` and AP < 0.5 → "`x` has 12 instances — aim for 50".
  - `small_split` (info): valid or test under 15 images → link to the version page.
  - `weak_slice` (info): a slice row with AP at least 0.2 below the overall AP → link to `browse?tag=`/`?batch=`/`?min_mp=` when the dimension maps, else `#worst`.
  - `overconfident` (info): `calibration.ece > 0.15` → "scores are over-confident — raise the default threshold" (links to T-277's panel).
  Return at most 6, ordered by severity then count.
- Permissions + workspace isolation: `c.perm("project.models")` (the same grant as the eval payload); foreign model/project → 404.
- Secrets/safefetch: none.
- OpenAPI: yes — regenerate both files.

## Tests to write first
pytest — `apps/backend/tests/test_recommendations.py`:
- `test_a_class_with_no_instances_is_the_first_line` — a predicted class with zero truths → `items[0].code == "class_without_data"`, severity `blocker`.
- `test_missing_labels_counts_images_not_instances` — 30 missed across 10 files → `count == 10` and the link contains `annotated=no`.
- `test_false_positives_need_twenty_percent` — 1 FP of 20 predictions → no item; 5 of 20 → item with the class name.
- `test_a_confusion_pair_needs_ten_and_fifteen_percent` — 9 hits → no item; 12 → item naming both classes and `cell` set.
- `test_at_most_six_items_and_severity_order` — a full fixture → `len(items) == 6`, severities non-decreasing.
- `test_an_unevaluated_model_is_generated_false` — no eval → `{generated: False, items: []}`, HTTP 200.
- `test_links_only_use_filters_the_dataset_page_understands` — every `link` matches `#` or `browse?` and its query keys are a subset of the dataset's documented keys.
- `test_foreign_model_is_a_404` and `test_flag_off_is_a_404`.
node — none: the rendering is asserted in T-280.

## Acceptance criteria
- [ ] One payload of at most six ordered recommendations, each with a count, a severity and a link or an explicit "look here" fallback.
- [ ] Counts are images where the sentence says images, instances where it says instances.
- [ ] An unevaluated model returns `generated: false`, not a 500.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no route and no card.

## Notes for the implementer
Thresholds are in the card and are the whole specification: 20 % missed, 20 % FP, 10-and-15 % confusion cell, 50 instances, 15 split images, 0.2 AP below overall, ECE 0.15. Change one and change its test in the same commit.
