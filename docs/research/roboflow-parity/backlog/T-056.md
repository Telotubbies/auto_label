## User story
As a maintainer, I want one way to get a logged-in test client and one way to get a seeded database, so
that a change to the demo login or the seed is a one-line edit and a new test file does not start with 15
lines of copied boilerplate.

## UX flow (LabelDesk words)
None: test-only. No application behaviour and no screen changes.

## Backend changes
- Models/schema: none.
- Routers: none.
- Services/jobs: none. `apps/backend/tests/conftest.py` gains two module-level helpers (not fixtures, so
  they can be called with a different email):
  ```python
  def login(c: TestClient, email: str = DEMO_EMAIL, pw: str = DEMO_PW) -> dict[str, str]:
      """Authorization headers for a seeded account; raises on a failed login so a broken seed is loud."""
  def login_as(c: TestClient, email: str) -> dict[str, str]:
  ```
  and one fixture used by the modules that currently define `_schema`:
  `@pytest.fixture` `seeded(db)` is **not** added — `_seeded_database` is already `autouse=True` and
  session-scoped, so the twelve `_schema` fixtures are deleted outright, not replaced.
- Permissions + workspace isolation: the helper logs in through `POST /api/auth/login` like a user; it
  must not construct a session or a token by hand.
- Secrets/safefetch: none. OpenAPI: no.

## Tests to write first
pytest — `apps/backend/tests/test_login_helper.py` (new):
- `test_login_returns_authorization_headers` — the helper returns `{"Authorization": "Bearer …"}` and a
  request with them reaches a protected route (200, not 401).
- `test_login_raises_on_a_wrong_password` — a 401 from the route must raise, not return empty headers;
  this is the assertion that stops the helper from silently passing every test.
- `test_login_as_reaches_a_second_account` — a second seeded member gets a different identity (so the
  helper is not hard-wired to one user).
pytest — the whole suite, unchanged:
- run `python -m pytest -q` in `apps/backend` and expect **1,519 passed, 0 failed**, the same count as
  before the card. A count that drops means a duplicate test was deleted with its helper.
