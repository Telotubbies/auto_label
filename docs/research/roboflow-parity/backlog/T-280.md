## User story
As an ML engineer, I want the Recommendations card to sit above the charts with one click per line, so that the diagnosis is the shortest path to the images that caused it.

## UX flow (LabelDesk words)
1. **Model → detail → Recommendations** — above the metric tiles: a card titled "What to fix next" with a severity dot, the sentence, the count in bold, and an arrow link. [empty: `generated: false` ⇒ "Recommendations are built after the evaluation finishes." with the *Run evaluation* entry] [loading: three skeleton lines] [error: "Recommendations could not be built" + Retry, the rest of the page unaffected]
2. **A line with an images link** — navigates to `/:ws/:project/browse?class=<id>&annotated=no&sort=oldest`; the dataset page's filter chips show what was applied and a *Clear* control, so the arrival is explainable.
3. **A line that opens the model's own gallery** — the worst-images modal opens with the slice named in its title ("Worst images · dark") — no navigation, no lost context.
4. **A confusion line** — scrolls to the matrix, opens that cell's gallery.
5. **A threshold line** — scrolls to the threshold panel (T-277) with the save control focused.
6. **Dismiss** — each line has a *Done* affordance that hides it for this browser session only (no server state), and the card says "Regenerated from the evaluation — nothing is stored."
