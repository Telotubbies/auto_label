## User story
As a reviewer, I want to require, exclude or merely allow a tag when freezing a version, so that I can train on one camera or one site without cloning the project.

## UX flow (LabelDesk words)
1. **Wizard → step 1** — each project tag gets one of three roles. [empty: "No tags on this project yet — tagging images on the Annotate board is what makes this step useful."] [loading: tag counts load with the step] [error: "Could not load tags — retry"]
2. **Wizard → Create** — a tag marked both *Required* and *Excluded* is refused with "A tag cannot be both required and excluded." (code `tag_rule_conflict`).
3. **Generation** — the version's manifest records the rules under `source.tags`, and the stats carry `pool_matched` / `pool_dropped` so the result page explains a smaller dataset.

## Notes for the implementer
