## User story
As an engineer preparing a release, I want to drop, rename or merge classes inside one version, so that a cleaner taxonomy ships to the trainer without touching the project's classes.

## UX flow (LabelDesk words)
1. **Wizard → step 3 → Classes card** — one row per project class with *Keep · Omit* and a *Rename to* field; two classes renamed to one target merge them. [empty: "This project has no classes yet."] [loading: n/a] [error: "A name may contain letters, numbers, spaces and . ( ) - only." on the rename field]
2. **Effect line** — "Omitting a class removes its boxes; images left with nothing become empty frames and follow the empty-frame rule above."
3. **Merge hint** — when a rename target equals another class name: "Harness and helmet will be merged into helmet."
4. **Preview** — the count line shows "3 classes → 2 · 412 boxes → 398".
5. **Reset** — restores every class to *Keep* and empties the rename fields.

## Backend changes
- Models/schema: none — the map lives in `settings.preprocessing.classes` and in the manifest; the project's `LabelClass` rows are never written.
- Routers: none (recipe value); preview returns `classes: {before, after, annotations_before, annotations_after}`.
- Services/jobs: `app/services/versioning.py` — build `out_classes` by applying `omit` and `rename` to the project classes in `created` order, remap each annotation's class index, drop annotations of omitted classes, and write the new names into `manifest["classes"]` and `stats.classes`. The version hash uses the mapped names, so a rename changes the hash (as a project rename already does).
- Permissions + workspace isolation: unchanged (`c.need("reviewer")`; foreign slug 404).
- Secrets/safefetch: none.
- OpenAPI: no.
- Flag: `task_190` off ⇒ a `preprocessing.classes` block is a 400 `op_unavailable`.

## Notes for the implementer
Remap by **index into the new class list**, exactly as `cls_idx` works today, so `manifest.items[].anns[].cls` stays an integer. Omitted classes must be removed before the split is computed, otherwise stratification counts a class that will not exist.
