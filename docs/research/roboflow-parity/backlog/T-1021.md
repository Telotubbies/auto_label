## User story
As the design owner, I want the hub checked in light, dark and 375 px with every state rendered, so that
it looks like the product that already ships instead of a bolt-on admin page.

## UX flow (LabelDesk words)
1. **Light and dark** — every tab, the sheets, the job card, the log sheet, the assets panel.
2. **375 px** — tab bar → select; tables scroll with a sticky first column; calculator stacks; sheets
   full-height; no horizontal page scroll.
3. **States** — empty, loading, error, offline host, blocked engine, gated model, fails-verdict, low
   disk; each captured once.
4. **Copy** — sentence case, no vendor taglines, units on every number, "estimate" where it is one.
5. **A11y** — keyboard reaches the tabs, the row menu, the sheet close and the confirm checkbox; focus
   visible on glass; logs readable at `text-xs` AA; `prefers-reduced-transparency` falls back to solid.
