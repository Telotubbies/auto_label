## User story
As a team lead, I want to tag a run (`nightly`, `line-3`, `customer-a`) and leave a sentence about why it exists,
so that six weeks later the run list explains itself without opening the job log.

## UX flow (LabelDesk words)
1. **Models → a run → Tags** — chips in the settings card, an *Add tag* control with key and value fields, and a
   **Note** textarea with Save/Cancel. Below them, a dimmed system row: `Trained by <user> · started 12 Nov 14:02
   · finished 12 Nov 14:41` (from the job's own timestamps). [empty: `No tags yet.` and an empty note showing
   `Add a note for whoever reads this run next.` as a placeholder] [loading: the chip row keeps its height]
   [error: a failed save keeps the typed text, shows `Tags could not be saved.` and offers retry]
2. **Add tag** — Enter saves the chip; a duplicate key replaces the value after a confirm; `×` on a chip deletes
   it after a confirm. Validation is inline: key ≤ 64 chars, value ≤ 256, at most 20 tags.
3. **Annotations are visible to every project member** — a labeler sees the chips and the note read-only (no add
   control, no ×), because tags describe the run, not the model's performance.
4. **The note is searchable later** — T-907's filter matches `tag:<key>` and `tag:<key>=<value>`; this card only
   stores the data.

- Models/schema: `apps/backend/app/models/training.py` — `TrainedModel` gains

  `note: Mapped[str] = mapped_column(String(2000), default="")`. `apps/backend/app/schema/training.py` —
  `TRAINED_MODELS` gains `"tags": "JSON"` and `"note": "VARCHAR(2000) DEFAULT ''"` (append only; existing rows
  read `tags = NULL` → `m.tags or {}`). No backfill, no `STEPS` reorder (the block is already registered at
  `app/schema/__init__.py:11`).

  422 for a schema violation (more than 20 tags, key > 64, value > 256, note > 2000), 403 for a caller without
  `project.models`. Also add `d["tags"] = m.tags or {}` and `d["note"] = m.note or ""` in `model_out()`
  (`:99-103`).

- Permissions + workspace isolation: read needs `project.infer` (the existing `models()` gate, `:150`);

- Secrets/safefetch: none — the text is stored as-is and rendered as text, never as HTML.
- OpenAPI: yes — `python tools/export_openapi.py`, then `npm run gen:api-types`.

## Acceptance criteria
- [ ] Tags and the note survive a reload and appear for every project member.
- [ ] A labeler can read but cannot write; the control set differs, the data does not.
- [ ] The four limit violations are caught before the request and again on the server.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
