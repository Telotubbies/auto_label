## User story
As an ops lead, I want the picture to be the configuration, so that adding an expert review tier is dragging one node instead of opening a second project.

## UX flow (LabelDesk words)
1. **Project → Label path** (`/:ws/:project/stages`) — a vertical chain of stage `Card`s joined by arrows, each showing its name, kind and role, with `Add stage` at the end. [empty: "No stages yet — start from the default path." with a `Use the default path` button] [loading: three skeleton nodes] [error: "This path did not load." + `Retry`]
2. **Select a node** — the right panel edits `Name`, `Kind` (`Annotate`, `Model`, `Consensus`, `Review`, `Rework`), `Who can act here`, `Cap`, `Edits allowed`, `Instructions` and, for a review stage, `Rejections return to`. [error: "Stage 3 has no assignee role, so it cannot accept files." inline on that node]
3. **Drag to reorder** — HTML5 drag between neighbours reorders `position`; a connector that would create a loop is refused with "The path must end at a stage with no next stage."
4. **`Publish`** — saves the graph, then asks "Reroute open images?" and runs the reroute with `[loading: Rerouting 118 open images]`, reporting "118 moved · 6 unchanged".
5. **Removing a stage in use** — refused inline: "3 images still sit in stage `rework` — move them first." and the node stays.

## Acceptance criteria
- [ ] The screen draws the project's stages as a chain, including the default path for a project that never configured one.
- [ ] Reordering and editing a node, then `Publish`, saves the graph and offers the reroute with counted results.
- [ ] A stage without an assignee role, a loop, or removing a stage in use is refused inline with the same sentence the API returns.
- [ ] Empty, loading and error states above all render: the no-stages empty line, skeleton nodes, the load error and the reroute loading bar.
- [ ] Workspace A cannot see workspace B's path: the screen calls this project's routes only and the nav hides it on a foreign project.
- [ ] Flag off ⇒ no nav entry, no route and no request.

## Notes for the implementer
Do not build a canvas engine: a vertical list of `Card`s with a border connector reads better than a free-form graph and matches "the picture is the configuration" for a chain with one reject edge. Reordering is neighbour-swap on drag, never free positioning — a stage's `position` is its order, and gaps make the queue's stage chips lie.
