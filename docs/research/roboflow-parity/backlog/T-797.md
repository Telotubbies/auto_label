## User story
As the person sending a monthly model update to a customer, I want to drag charts and a conclusion into one page and export it, so that the customer files a document instead of a screenshot.

## UX flow (LabelDesk words)
1. **Insights → Report** (`/:ws/:project/model-insights?tab=report`) — `New report` asks for a title; the empty canvas says "Add a block to start the report." [loading: the draft opens with its block skeletons]
2. **Add block** — a picker offers the curves, the runs table, a slice chart, the confusion matrix, a text block and a dataset image; each block freezes its data when the report is published. [error: a block whose model was deleted renders "This block's data is no longer available." in place, never a broken chart]
3. **Reorder** — drag handles move a block; the order is saved with the draft. [loading: the save indicator shows pending without blocking editing]
4. **Publish** — asks for confirmation, then shows the link, `Anyone with this link can read it.` and the frozen timestamp. [error: publishing with no block shows the API's sentence on the publish button]
5. **Print or save as PDF** — the published page prints on A4 with the workspace name, the title and `Data as of {time}`, and hides navigation, ids and toggles. [empty: a revoked link renders "This link is no longer available." with no chrome]

## Backend changes
- Models/schema: none in this card.
- Routers: none — it consumes T-796's routes.
- Services/jobs: none.
- Permissions + workspace isolation: create/edit with `reviewer`, publish with `admin`; the public page renders only what the token payload returns.
- Secrets/safefetch: none — the client never sends a signed URL to the public page; image blocks use the frozen URL the API stored at publish.
- OpenAPI: no.

## Acceptance criteria
- [ ] A report is built from ordered blocks of the offered kinds and survives a reload.
- [ ] Publishing returns a link that opens without a session and prints on A4 with the frozen timestamp.
- [ ] A revoked link shows the stated sentence and no chrome; a block whose model vanished says so in place.
- [ ] Empty, loading and error states above all render: an empty canvas explains the first step, a save shows pending, a failed publish states its reason.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no Report tab and `/r/:token` falls through to the existing login redirect.

## Notes for the implementer
Print from the public page, not from the builder: the same markup then serves the screen reader, the link and the PDF. The print stylesheet is one block in `index.css` (`@media print`) — no PDF library, no server-side renderer, and no second layout.
