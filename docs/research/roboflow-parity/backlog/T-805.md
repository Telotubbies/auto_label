## User story
As the admin who installed a house rule, I want it to appear as a panel beside our own analysis with its capabilities visible, so that a colleague can tell what it reads and can switch it off without a support call.

## UX flow (LabelDesk words)
1. **Settings → Extensions** (`/:ws/settings/extensions`) — a table of installed extensions: name, version, author, API version, capabilities, enabled switch and last error. [empty: "No extensions installed." with the upload action] [loading: three skeleton rows] [error: "Extensions could not be loaded" with a retry]
2. **Add** — the file picker accepts `.json`; before install the dialog lists `Asks for` the capabilities and the API version, and `Add` is disabled until the file parses. [error: the API's refusal sentence is shown verbatim beside the file name]
3. **Panel slot** — on the model page, enabled `metric` and `check` extensions render as one `Extensions` card with their values and verdicts, each naming the extension that produced it. [empty: no enabled extension ⇒ the card is absent, not an empty card]
4. **A broken extension** — its row shows the stored error, the card renders the rest, and the one that threw is disabled with "{name} stopped working and was disabled." [error: a run failure never breaks the model page]
5. **Disable** — one toggle; the panel slot disappears on the next load and the audit row is written. [loading: the toggle shows pending in place]

## Acceptance criteria
- [ ] The Extensions tab lists name, version, author, API version, capabilities, state and last error.
- [ ] Installing shows the requested capabilities before the file is accepted, and the API's refusal verbatim when it is not.
- [ ] Enabled metric and check extensions render on the model page with their values and verdicts, each naming its extension.
- [ ] Empty, loading and error states above all render: no extension says so, a failed load retries, a broken extension is isolated.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no Extensions tab and no model-page card.
