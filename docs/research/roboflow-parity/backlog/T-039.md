## User story
As an admin, I want the members page to show a link per role and the pending invites with how long they have left, so that I can add a whole shift without retyping emails and see who has not accepted.

## UX flow (LabelDesk words)
1. **Settings → Members** — above the roster, a `Join links` block: one row per role (`Reviewer`, `Labeler`, `Member`, …) showing `Active · created 2 days ago` with `Copy link`, `Rotate`, and, when none exists, `Create link`. [empty: no links → `No join links. Create one per role you hand out.`] [loading: three skeleton rows] [error: `Could not load join links — Retry`; the roster still renders]
2. **Rotate** — confirm `Replace the reviewer link? Anyone holding the old link will be told it was replaced.` → the row's copy value changes, toast `New reviewer link copied.`
3. **Pending invites** — each row shows email, role, `expires in 2 days` (or `Expired` in the warning colour), and actions `Resend`, `Revoke`. Expired rows keep `Resend` as the primary.
4. **Invite form** — accepts comma-separated emails (up to 20) with one role; results list per address (`sent`, `already a member`, `seat limit reached — upgrade or remove a member`). [error: partial failures listed per address, successful ones still shown as pending]
5. **Seat limit** — a persistent line under the form when the workspace is at its seat cap: `3 of 3 seats used. Remove a member or change the plan to invite.` and the submit disabled.
