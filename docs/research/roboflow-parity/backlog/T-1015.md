## User story
As a workspace admin, I want to compare segmentation models on memory and licence, see which one this
host is ready to run, and jump into auto-label with it selected, so that the handoff is one click rather
than a hunt through the registry.

## UX flow (LabelDesk words)
1. **Segmentation tab** — project picker (the workspace's projects, default: the last opened project from
   the store), then a responsive card grid: name, family, params, VRAM `512 px: 8.4 GB · 1024 px:
   11.2 GB`, licence badge, source link, state chip with reason.
2. **Ready card** — primary action `Use for auto-label`; secondary `Open documentation`.
3. **Not ready card** — the action is disabled with the reason and the exact env to fix:
   "Missing checkpoint: set `LD_SAM_ROOT` to a `sam3_auto_label` checkout with
   `checkpoints/sam3.1_multiplex.pt`." [error: a missing project → "Choose a project first."].
4. **Use** — navigates to `/:ws/p/:project/dataset?autolabel=<ref>`; the dataset screen opens the
   existing Auto label dialog with that model preselected (T-1016). [loading: the button shows a spinner
   while the route resolves; there is no API call].
5. **No project in the workspace** — the picker reads "No projects yet." with a `Create a project` link;
   every use action is disabled. [empty: no provisioned model → the setup sentence and the docs link].
6. **Licence** — AGPL and non-commercial badges are visible on the card and repeated in the dialog title
   area (the dialog already renders the model licence).
7. **375 px** — one card per row, VRAM figures stack, the action is full width.

## Acceptance criteria
- [ ] Cards show params, VRAM at both resolutions, licence and a state chip with a reason.
- [ ] Only a `Ready` card offers `Use for auto-label`, and it navigates to the dataset with `autolabel`.
- [ ] A not-ready card names the env var and path to fix; a CPU host names the OS.
- [ ] AGPL and non-commercial badges are visible on the card.
- [ ] No project and no provisioned model are distinct empty states.
- [ ] 375 px: one card per row, no horizontal page scroll, action full width.
- [ ] No new token, hex, font size or icon library; glass only on the picker/popovers.

## Notes for the implementer
Build the URL with `URLSearchParams`, not string interpolation: the ref contains `:` and a project slug
can contain characters that need encoding. Do not fetch the registry here; the provisioned verdict and
the ref both come from `GET /segmentation`.
