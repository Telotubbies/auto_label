## User story
As a safety officer preparing for an inspector, I want one printable A4 sheet of today's PPE rate, incidents, dead cameras and the person who signs it, so that the numbers on it are the product's own rather than a spreadsheet I rebuilt at 17:00.

## UX flow (LabelDesk words)
1. **The sheet is data first** — `GET /documents/safety.html` renders from a `Document` value: title, subtitle, a metadata block, one section per zone, an incidents table with thumbnails, an offline-camera list, a supervisor block and the remark. [empty: a day with no events renders the sheet with `วันนี้ยังไม่มีเหตุการณ์` and a zero summary, because an inspector still wants the sheet]
2. **Zones are chosen, not guessed** — `zones=a,b` limits the sections; an unknown zone is ignored with a warning line, never a 500. [error: `ไม่พบโซนที่เลือก — แสดงทุกโซน` inside the sheet]
3. **Signing needs a name** — `sign=1` without a configured supervisor is 409 `ยังไม่ได้กำหนดผู้ตรวจ — เซ็นไม่ได้`, because an unsigned sheet is not evidence. [error: that sentence, which T-722 renders]
4. **The print view is the sheet** — the same HTML carries `@page { size: A4; margin: 16mm }` and the Anuphan face, so the browser's own PDF is the artefact. [error: a render failure is a 500 with `สร้างเอกสารไม่สำเร็จ` and no half file]
5. **A range past retention** — 400 with the project's own number, the same rule the yield board uses. [error: `ช่วงวันที่เกินระยะเก็บข้อมูลของโปรเจกต์ (30 วัน)`]

## Backend changes
- Models/schema: none — the sheet reads `StreamEvent`, `Stream`, `Audit` and `project.settings["safety_supervisor"]`; no table and no column.
- Routers: `app/routers/documents.py` (new), prefix `/api/ws/{ws}/projects/{project}/documents`, `dependencies=[Depends(require_flag("task_safety_sheet"))]`; `GET "/safety.html?date&tz_offset&zones&sign"` → `HTMLResponse`; 400 for a bad date or a range past `retention_days`, 409 for `sign=1` without a supervisor, 404 for a foreign project.
- Services/jobs: `app/services/documents.py` (new) — `Document` (dataclass: `title`, `subtitle`, `meta: [(label, value)]`, `sections: [{heading, rows, notes}]`, `images: [str]`, `footer`), `render_html(document) -> str` with `html.escape` on every value, `@page` CSS, the `PUBLIC_URL` Anuphan face, base64-free signed image URLs capped at 12, and no script. `app/services/safety_sheet.py` (new) — `ppe_rate(predictions) -> float | None` (a person is compliant when a helmet box overlaps it by IoU ≥ 0.3), `build(db, project, date, tz_offset, zones, sign) -> Document`, `settings_supervisor(project)`. No job: the sheet renders in the request.
- Permissions + workspace isolation: `project.streams` to read; the project is resolved from the path and filtered by workspace, and an image path outside `DATA_DIR` is dropped rather than signed.
- Secrets/safefetch: none — no URL is fetched; images are signed by `security.sign_path` and only paths under `DATA_DIR` are eligible.
- OpenAPI: yes — one route (its HTML body is documented as `text/html`).

## Tests to write first
pytest — `apps/backend/tests/test_safety_sheet.py`:
- `test_the_document_matches_the_golden_shape` — the built `Document` for a fixed seed day equals `tests/fixtures/safety_sheet.json` (keys, order, section headings, row values), so the renderer is tested by data, never by pixels.
- `test_ppe_rate_counts_a_person_without_a_helmet_as_non_compliant` — three persons, two with an overlapping helmet box (IoU ≥ 0.3) → `0.67`; no person at all → `None`, printed as `—`.
- `test_a_day_with_no_events_still_builds_a_sheet` — no events → the sheet has the zero summary, one `วันนี้ยังไม่มีเหตุการณ์` note and no incident rows.
- `test_signing_without_a_supervisor_is_409` — `sign=1` and no `safety_supervisor` → 409 with the sentence; after setting one, 200.
- `test_a_zone_name_is_escaped_in_the_html` — a zone named `<script>x</script>` appears escaped and the body contains no `<script>`.
- `test_a_range_past_retention_is_400` — `retention_days = 30` and a 60-day `date` is refused with the number.
- `test_the_route_is_hidden_while_the_flag_is_off` — 404.
- `test_a_project_from_another_workspace_is_404` — 404 and no sheet is rendered.

## Acceptance criteria
- [ ] One route renders a printable A4 sheet from a `Document` value: PPE rate per zone, incidents with thumbnails, offline cameras and the supervisor block.
- [ ] The sheet is tested by its data shape and one golden fixture, and every value is HTML-escaped.
- [ ] Signing is refused with 409 when no supervisor is configured, and a day with no events still prints.
- [ ] Empty, loading and error states above all render — an empty day is a sheet with its own sentence, a bad range is a 400 with the number.
- [ ] Workspace A cannot see workspace B's project or an image outside its own `DATA_DIR` (404, not 403).
- [ ] Flag off ⇒ the route 404s and no document is produced anywhere.

## Notes for the implementer
No PDF library is added: the renderer produces a self-contained print sheet and the browser's own PDF engine makes the file, which is also the only way to embed Thai glyphs without a font-subsetting dependency — say so in the route's docstring so the next reader does not "fix" it. `render_html` is the only renderer in the product; T-726 adds a template to this engine, never a second one. Cap: 12 images per sheet, 500 rows per section, and every text value goes through `html.escape` before it reaches the template.
