## User story
As a visitor who clicked copy, I want the copy to show its progress and to tell me exactly which of five things went wrong, so that I know whether to retry, upgrade or look elsewhere.

## UX flow (LabelDesk words)
1. **Dialog** — `Copy “PPE Detection” into Acme`; fields: destination workspace (read-only, the current one), new name (default `PPE Detection copy`), `What you get: 128 images, 4 classes, annotations, splits. Versions and models are not copied.`; primary `Copy dataset`, ghost `Cancel`. [empty: name cleared → primary disabled with `Name the new project.`]
2. **Copying** — primary becomes a progress row: `Copying images… 64 of 128` with a determinate bar, polling the returned job every 2 s; `Cancel` hides the dialog and leaves a job-tray row (the copy continues server-side).
3. **Success** — dialog closes and the client routes to `/:ws/p/<new-slug>/dataset?tab=versions` with a toast `Copied 128 images. Make a version when you are ready to train.`
4. **Failures, one sentence each** — 402 `This workspace is out of image quota or credits.` with `See usage` link; 403 `That dataset is not public.`; 404 `No dataset at that address.`; 409 `This workspace already has a copy.` with `Open it` link to the existing project; 422 `Name the new project.` [error: network → `Could not start the copy — nothing changed.` and the dialog keeps its values]
5. **Signed-out visitor** — pressing the page CTA sends them to login first, and after sign-in the same dialog opens with their own workspace prefilled.

## Acceptance criteria
- [ ] The dialog shows name, what is copied and what is not, and starts the copy with a determinate progress row.
- [ ] Each of the five failures has its own sentence and, where useful, its own action link.
- [ ] Empty, loading and error states above all render (blank name, progress, network failure).
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — the destination workspace is never a form field.
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
- [ ] Success lands on the new project's versions tab, not a generic project home.

## Notes for the implementer
One dialog, five labels; do not collapse the errors into "something went wrong". Cancel hides the dialog (the job continues) — the job tray is the durable view.
