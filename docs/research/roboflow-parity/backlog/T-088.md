## User story
As an annotator, I want to point at one image and see look-alikes among unassigned frames or inside the
dataset, so that I label the next similar thing or spot a repeat without leaving the editor.

## UX flow (LabelDesk words)
1. **Editor · ⋯ menu** — **Find similar unassigned** and **Find similar in dataset** (the second is hidden
   when the project has no approved images). [error: the index cannot read the image →
   "This image cannot be compared — its file may be missing"]
2. **Dataset · Images** — results open as the normal grid sorted by similarity, with the chip
   "Similar to IMG_0421.jpg ×" and a line "24 close matches · ranked, not de-duplicated". [loading:
   12 tile skeletons] [empty: "No similar images found"]
3. **Dataset · Images** — removing the chip returns to the previous filter; the selection bar can tag or
   remove the matches in bulk. [error: the source image was deleted meanwhile → the chip reads
   "Source image no longer available" and the grid falls back to all images]
4. **Developer API** — `GET …/images?similar=<id>&similarScope=unassigned` returns the same ranking, so a
   script can reproduce it.

## Backend changes
- Models/schema: none.
- Routers: `apps/backend/app/routers/images.py`
  - `GET /api/images/{image_id}/similar?scope=unassigned|dataset&limit=50` → `200 {items: [{id, name,
    score, thumbnail, split, status}], backend: "clip"|"cv", candidates: n}`; `404` for a foreign image;
    `400` for a bad scope.
  - `GET P/images` gains `similar: str = ""` and `similar_scope: str = "dataset"`, ranked by the same
    service and then filtered by the existing `_visible`/labeler rule.
- Services/jobs: `apps/backend/app/services/similar.py` (new) —
  `vectors(rows) -> dict[row_id, np.ndarray]` reading `insights_embedding.FEATURE_DIR` caches (clip first,
  cv fallback) and computing the cheap CV descriptor for a missing cache (bounded: target + first 500
  candidates by `created desc`, so the request is O(500) not O(dataset)); `rank(db, project, target_id,
  scope, limit)` → cosine similarity, excluding the target and any row outside `scope`
  (`unassigned` = `status == "unassigned"`, `dataset` = `status == "done"`). No embedding job is enqueued;
  a missing CLIP cache silently uses the CV descriptor and `backend` says which.
- Permissions + workspace isolation: `project.read` for the grid path; the single-image route uses
  `image_ctx` (labeler assignment rule applies); a foreign project id is 404.
- Secrets/safefetch: none.
- OpenAPI: yes — one route, two parameters.

## Acceptance criteria
- [ ] Both scopes are reachable from the editor menu and open the grid ranked by similarity.
- [ ] The chip removes cleanly and a deleted source shows the fallback copy instead of an error page.
- [ ] A labeler's results respect the assigned-only rule; a foreign image is 404.
- [ ] The ranking works without CLIP (CV fallback) and says which backend produced it.
- [ ] Empty, loading and error states above render.
- [ ] Flag off ⇒ no menu items and the `similar` parameter changes nothing.
- [ ] Workspace A cannot see or change workspace B's data (404 for a foreign image or project id).

## Notes for the implementer
This is ranking, not de-duplication: no threshold, no "these 14 are duplicates" claim (F2.36 owns the
cluster view). Cap the descriptor computation at 500 candidates so an editor click cannot scan a 250k-image
project.
