- **Wave label.** Wave G is already "regression guards (T-001–T-007)" and Wave F's industrial family already
  calls itself G3 (T-670–T-697). This G3 is the third code-health wave of the owner's directive; its table
  sits before E-frame in the execution order and before Wave A in §6a, and it shares no card, file or row
  with either of those G3s.
- **No PARITY rows.** Clean-up re-plans nothing, so no guard is duplicated and no row is touched twice.
- **T-053 is a bug fix inside a clean-up wave.** The defect is corrupt source text, and the fix is a literal
  edit; it is in the card because no feature wave owns it.

  T-054 → T-055 → T-059 → T-056 → T-057 → T-058. T-056 is after T-050 because both edit nine backend test

  audit), so T-054 and T-055 rebase on T-525's `index.css` rule and T-523's `Models.tsx` card.
- **Everything rejected.** `streams/manager.py` split, `Auth.tsx`/`Editor.tsx`/`StreamDetail.tsx` splits,
  the two `ChartCard`s, `jobs.is_cancelled`, column and index drops, and the permission-helper divergence are
