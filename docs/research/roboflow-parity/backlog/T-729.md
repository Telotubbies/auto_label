## User story
As a security manager answering a police request, I want one zip with the clip, three stills, the event log, the camera's location, a hash per file and a Thai cover sheet naming who exported it, so that the file has weight instead of being a screenshot.

## UX flow (LabelDesk words)
1. **A package is requested from an event** — `POST /evidence` names the events, the window around them and the items; the response is the package id, its files and its size. [empty: an event with only a snapshot is still packaged, with `events.json` noting `no clip`] [loading: `กำลังสร้างแพ็กหลักฐาน`] [error: `สร้างแพ็กไม่สำเร็จ — ลองอีกครั้ง`]
2. **The manifest is the evidence** — `manifest.json` lists every file with its sha256 and size, plus the operator, the time, the camera location and the redaction policy applied. [error: a file that cannot be hashed stops the package; a partial zip is never left on disk]
3. **Footage past retention** — 409 `ไฟล์หลักฐานหมดอายุตามนโยบายเก็บข้อมูลแล้ว (30 วัน)` with the number, rather than a broken zip. [error: that sentence]
4. **The cover sheet** — `cover.html` is the same A4 sheet engine as the safety sheet: what is attached, why, who, and the hash of the manifest. [error: a package without a cover is refused at build time, never at download time]
5. **The record** — every export writes one `evidence.export` audit row and one `EvidencePackage` row, and the download is a signed path that expires. [error: `ลิงก์หมดอายุ — สร้างแพ็กใหม่`]

## Backend changes
- Models/schema: `app/models/evidence.py` (new) — `EvidencePackage(id, workspace_id, project_id, stream_id, event_ids JSON, window_s, items JSON, path, manifest_sha256, bytes, redacted, export_reason, created_by, created, expires)` with `Index(project_id, created)`; register in `models/__init__.py`; `create_all` makes the table, no `ADD COLUMN`.
- Routers: `app/routers/evidence.py` (new), prefix `/api/ws/{ws}/projects/{project}/evidence`, `dependencies=[Depends(require_flag("task_evidence_package"))]`; `POST ""` `{event_ids, before_s, after_s, items, export_reason?}` → 201 `{id, files: [{name, sha256, bytes}], manifest_sha256, url}`; `GET ""?month=`; `GET "/{id}"` → the manifest; `GET "/{id}/download"` → `{url}` signed for 15 minutes. 400 for no items or a window over 60 minutes, 403 for an original export without `project.settings`, 409 past retention, 404 for a foreign event or package.
- Services/jobs: `app/services/evidence.py` (new) — `window(events, before_s, after_s)`, `collect(db, project, events, items, policy)` → `{files: [(name, bytes)]}` from `StreamEvent.snapshot_path`, the clip held by T-681, `events.json`, `cameras.json` (name, zone, area, install note — never a credential: `creds.mask_source`) and `cover.html` from `documents.render_html`; `manifest(files, meta)`; `write(db, package, files)` building through `shutil.make_archive` exactly like `routers/ocr.py::_zip` (atomic rename, temp name), then hashing the manifest and writing the row plus `audit(..., "evidence.export", ...)`. No job: a package is built in the request and a 200-file cap keeps it bounded.
- Permissions + workspace isolation: `project.export` to build, `project.streams` to list; the events, the stream and the clip are resolved through `workspace_id` + `project_id`, so a foreign id is 404 before any file is read.
- Secrets/safefetch: `services/secretbox.py` — no new secret; `services/safefetch.py` — no outbound call, every byte comes from `DATA_DIR` and anything resolving outside it is dropped. The download URL is `security.sign_path`.
- OpenAPI: yes — four routes and the manifest schema.

## Acceptance criteria
- [ ] One request produces a zip with the chosen items, a hash per file and a manifest hash, plus a Thai cover sheet naming the operator and the time.
- [ ] An event with only a snapshot still packages and states that no clip exists; footage past retention is refused with the project's own number.
- [ ] An original export needs a manager and a recorded reason, and both land in the manifest.
- [ ] Empty, loading and error states above all render — a failed build writes no archive and no row.
- [ ] Workspace A cannot package workspace B's event (404, not 403) or read a file outside `DATA_DIR`.
- [ ] Flag off ⇒ no route, no archive, no audit row.

## Notes for the implementer
R7: what is stored is one zip under `DATA_DIR/exports/evidence/<ws>/`, redacted according to the stream's policy; it expires after 30 days and is swept by `services/retention.py` on the same pass that sweeps snapshots, and the `EvidencePackage` row plus its audit row are kept one year because the point of the package is the record that it existed. Threshold and redaction failures degrade to the safe state: if the clip cannot be redacted, the package is refused rather than shipped with the faces visible — a missing package is a conversation, a leaked one is an incident. Never include a signed URL in `events.json`: sign at download time, not at build time.
