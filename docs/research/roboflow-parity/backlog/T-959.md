## User story
As an ML lead, I want the time and tokens each model call cost, per day and per model, so that a slow or
expensive provider is a number on a screen instead of a bill I read at month end.

## UX flow, click by click.
1. **Project → Model insights → Cost** — a new tab: calls, median and p95 duration, total tokens in and out,
   and the estimated spend for the window, per model. [empty: "No calls recorded in this window" with the
   window selector still rendered] [loading: the table keeps its header and shows placeholder cells]
2. **Price a model** — a small dialog: model, price per 1M input tokens, price per 1M output tokens, currency;
   saved per project. Until a price exists the row shows tokens and "not priced" rather than zero spend.
   [error: "a price of 0 is not a price — leave the field empty to keep it unpriced"]
3. **Drill** — clicking a bar opens Traces filtered to that model and window.
4. **Two ledgers, never confused** — the panel names the workspace's metered usage beside the token estimate
   and links to it: "This is provider cost, not the credits in your plan." [empty: a project with no metered
   usage in the window says so]
5. **A call with no usage block** — counted as "tokens not reported" and excluded from cost, with the count
   shown, never as zero.

## Backend changes
- Models/schema: `ModelPrice(id, workspace_id, project_id, model_id, in_per_million, out_per_million,
  currency, created_by, created, updated)` unique `(project_id, model_id)` in
  `apps/backend/app/models/evaluation.py`. Tokens ride T-954's `Trace.tokens_in/tokens_out`.
- Routers: `GET {P}/insights/cost?days=30` → `{window: {from, to}, models: [{model_id, name, calls,
  p50_ms, p95_ms, tokens_in, tokens_out, tokens_missing, spend, currency, priced}]}`; `PUT {P}/insights/
  cost/price/{model_id}` body `{in_per_million, out_per_million, currency}` → the row; 400 for a negative or
  zero price, 404 for a foreign model.
- Services/jobs: `apps/backend/app/services/model_cost.py` (new) — `summary(db, project, days)` grouping
  traces by `model_id` with `percentile_cont` for p50/p95 and a left join to prices; `spend =
  tokens_in/1e6 * in_per_million + tokens_out/1e6 * out_per_million`, rounded to the currency's minor unit.
  Read-only. The VLM adapter's response `usage` is read into `tokens_in`/`tokens_out` at write time in
  T-954's `record`.
- Permissions + workspace isolation: `project.review` to read, `c.need("admin")` to set a price; foreign ids 404.
- Secrets/safefetch: none. Dependency: none added (no `mlflow-skinny`), so no
  `THIRD_PARTY_LICENSES.md` change.
- OpenAPI: yes — regenerate both files.

## Acceptance criteria
- [ ] Per-model calls, p50/p95 duration, tokens in/out and priced spend are shown for the chosen window.
- [ ] An unpriced model and a call without a usage block are both reported honestly, never as zero.
- [ ] The panel distinguishes provider cost from workspace credits and links to the metered view.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
