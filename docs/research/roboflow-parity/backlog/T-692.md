## User story
As a quality engineer, I want to calibrate a station once with a known target and then read `12.4 mm · อยู่ในช่วง`, so that a report carries a dimension an auditor accepts instead of a pixel count.

## UX flow (LabelDesk words)
1. **Station page → `คาลิเบรต`** (`/:ws/stations/:stationId`) — `จับภาพอ้างอิง` freezes the current frame, two clicks set the reference points, `ระยะที่ทราบค่า (มม.)` is typed, and saving reads `บันทึกคาลิเบรตแล้ว · 0.042 มม./พิกเซล`. [empty: `สถานีนี้ยังไม่ได้คาลิเบรต — การวัดถูกปิดไว้`] [error: `ระยะพิกเซลสั้นเกินไป — คลิกให้ห่างกันกว้างขึ้น` when the two points are under 10 px]
2. **The calibration record** — who calibrated, when, the pixels, the known millimetres and the resulting scale; the history stays readable, and an old measurement keeps the calibration id it was measured under. [loading: the capture button reads `กำลังจับภาพ`]
3. **Editor → `วัดระยะ`** — two clicks on the canvas produce `12.4 มม. · อยู่ในช่วง` beside the line; a point outside the band reads `เกินไป 0.3 มม.` or `ขาดไป 0.2 มม.`. [error: `สถานีนี้ยังไม่ได้คาลิเบรต — การวัดถูกปิดไว้` and the tool stays disabled]
4. **The measurement is stored** — on the annotation with the value, the unit, the tolerance and the calibration id, so an export and an audit can follow it.
5. **Re-calibration** — after 90 days or a camera move the station page shows `ควรคาลิเบรตใหม่ (ครบ 90 วัน)` in the warning tone; nothing is blocked.

## Backend changes
- Models/schema: `app/models/metrology.py` (new) — `StationCalibration(id, workspace_id, project_id, station_id, mm_per_px, pixels, known_mm, measured_by, created)` with `Index(station_id, created)`; register in `models/__init__.py`; `create_all` creates it, no `ADD COLUMN`. The measurement rides on the annotation as a `measure` payload, like `ocr`.
- Routers: `app/routers/metrology.py` (new), prefix `/api/ws/{ws}/projects/{project}/meters`, `dependencies=[Depends(require_flag("task_metrology"))]`; `POST /stations/{station_id}` `{pixels, known_mm}` → the calibration (400 for `pixels < 10` or `known_mm <= 0`, 404 unknown station); `GET /stations/{station_id}` → `{current, history}`. `routers/images.py::_check_ann` validates a `measure` payload through `services/metrology.clean_measure` and refuses one whose `calibration_id` is not the project's.
- Services/jobs: `app/services/metrology.py` (new) — `scale(pixels, known_mm) -> float`, `mm(distance_px, mm_per_px)`, `verdict(value_mm, low, high) -> {"state": "in"|"over"|"under", "delta_mm"}`, `clean_measure(raw) -> dict` (`p1`, `p2` normalised, `value_mm` 0–100000, `unit: "mm"`, `tolerance {low, high}`, `calibration_id`), `stale(calibration, now, days=90) -> bool`. No job.
- Permissions + workspace isolation: calibration needs `project.settings`, reading it needs `project.read`; the station, the calibration and the annotation's `calibration_id` are all resolved through `workspace_id` + `project_id`, so a foreign station or calibration id is 404/400 and never silently applied.
- Secrets/safefetch: none.
- OpenAPI: yes — two routes and the `measure` annotation payload.

## Tests to write first

- `test_scale_divides_known_millimetres_by_pixels` — `scale(240, 10.0)` is `0.041666…` and `mm(298, that)` is `12.42`.
- `test_a_verdict_names_the_band_and_the_delta` — `verdict(12.4, 12.0, 12.3)` is `{state: "over", delta_mm: 0.1}`; inside the band is `in` with `0.0`.
- `test_calibration_bounds_are_enforced` — `pixels: 9` is 400, `known_mm: 0` is 400, and a valid pair stores `mm_per_px` rounded to six places.
- `test_a_measure_annotation_needs_a_calibration_of_this_project` — an annotation with `measure.calibration_id` from another project is 400; the project's own is stored with unit and tolerance.
- `test_a_stale_calibration_warns_but_does_not_block` — `stale(cal, now, 90)` is true after 91 days and the route still returns the scale.
- `test_the_routes_are_hidden_while_the_flag_is_off` — 404 with the flag off and a `measure` annotation is refused.
- `test_a_station_from_another_workspace_is_404` — calibrate and read with a foreign station id are 404.
node — `apps/frontend/tests/measure.test.mjs`:
- `test_pixels_between_scales_normalised_points_by_the_frame_width` — a 0.1 horizontal gap on a 1920-wide frame is 192 px.
- `test_to_millimetres_rounds_to_one_decimal` — `12.42 → 12.4`, `12.36 → 12.4`.
- `test_verdict_reads_in_over_or_under_with_the_delta` — `verdict(12.6, 12.0, 12.3)` → `over` with `0.3`; `11.8` → `under` with `0.2`.
- `test_measure_label_always_carries_the_unit` — `measureLabel({value_mm: 12.4, state: 'in'})` reads `12.4 มม. · อยู่ในช่วง` and never a bare number.

## Acceptance criteria
- [ ] A station stores a calibration with its pixels, known millimetres, scale, operator and time, and the history stays readable.
- [ ] The editor's `วัดระยะ` tool returns a millimetre value with an in/over/under verdict against the tolerance band.
- [ ] A measurement without a calibration, or with one from another project, is refused, and a stale calibration warns without blocking.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no calibration card, no measure tool, no `measure` payload, and the editor is today's.

## Notes for the implementer
One scale per station, stored with its pixel pair and the operator, because the record is the product: a re-calibration writes a **new** row and never edits the old one, so an old measurement keeps the id it was measured under. Refuse a measure annotation without a calibration id rather than storing pixels as millimetres — a silent unit change is worse than a disabled tool. Copy: `meter.calibrate`=`คาลิเบรต`, `meter.capture`=`จับภาพอ้างอิง`, `meter.capturing`=`กำลังจับภาพ`, `meter.known`=`ระยะที่ทราบค่า (มม.)`, `meter.saved`=`บันทึกคาลิเบรตแล้ว · {scale} มม./พิกเซล`, `meter.pixelsTooShort`=`ระยะพิกเซลสั้นเกินไป — คลิกให้ห่างกันกว้างขึ้น`, `meter.noCalibration`=`สถานีนี้ยังไม่ได้คาลิเบรต — การวัดถูกปิดไว้`, `meter.measure`=`วัดระยะ`, `meter.inTolerance`=`อยู่ในช่วง`, `meter.over`=`เกินไป {d} มม.`, `meter.under`=`ขาดไป {d} มม.`, `meter.recalibrate`=`ควรคาลิเบรตใหม่ (ครบ {n} วัน)`.
