## User story
As an engineer wiring a training script, I want the download command one click away with a warning about what a round trip loses, so that I neither leak a key into a screenshot nor trust class names to survive.

## UX flow (LabelDesk words)
1. **Export dialog → Use from code** — a disclosure that reveals two tabs, *cURL* and *Python*, each showing the signed download command with the real URL **wrapped, never clipped**, and a *Copy* button. [empty: "Export first — the snippet needs a built artefact." shown instead of a broken command] [loading: n/a] [error: "This link expires; export again for a fresh one." when the artefact is stale]
2. **Key warning** — directly above the snippet: "This link is signed and temporary. Your API key is **not** printed here — create one under Settings → API keys and keep it out of screenshots." [empty: n/a]
3. **What a round trip loses** — a *What changes in a ZIP* disclosure with four lines: images are re-encoded to JPEG at quality 92 (original bytes are only in the image detail); class names must pass the class-name rule, so a name with symbols is refused at creation and an import that carries one is renamed; choosing a detection format for a segmentation project turns polygons into boxes; per-image typed metadata is not part of any format yet.
4. **Copy feedback** — the button reads "Copied" for 2 s and is keyboard reachable. [error: "Copy failed — select the text above."]

## Notes for the implementer
Reference the key as `$LABELDESK_KEY` / `os.environ["LABELDESK_KEY"]` and say so in the warning: a snippet that prints a real secret is one screenshot away from an incident, and the signed URL already carries the grant.
