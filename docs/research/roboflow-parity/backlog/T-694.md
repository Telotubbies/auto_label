## User story
As a maintenance technician, I want the camera to compare itself against a reference frame and tell me when the light, the focus or the window changed, so that an accuracy drop is a maintenance ticket instead of a two-week mystery.

## UX flow (LabelDesk words)
1. **Stream detail → `ภาพอ้างอิง`** (`/:ws/:project/streams/:sid`) — `จับภาพอ้างอิง` freezes the current frame, then three limits (luminance, contrast, sharpness) default to ±25 %, ±30 % and ±40 %. [empty: `ยังไม่มีภาพอ้างอิง`] [loading: `กำลังจับภาพ`] [error: `ไม่สามารถจับภาพอ้างอิงได้ — ยังไม่มีเฟรม`]
2. **The comparison** — the tab shows the reference and the current frame side by side with the three deltas (`ความสว่าง −41 %`, `คอนทราสต์ −8 %`, `ความคมชัด −3 %`) and `กำลังเทียบ 12 เฟรม` while it samples. [error: `ภาพเคลื่อนจากค่าอ้างอิง 41% — ตรวจไฟ` in the destructive tone]
3. **One event per drift** — a breach writes one event with the sentence and a snapshot, then stays quiet for an hour; the alarm queue sees one row, not four hundred.
4. **The wall** — a drifted camera carries `ภาพเคลื่อน` beside its status chip, so a wall of forty cameras shows the dirty lens without opening any of them. [empty: a stream with no reference shows no chip at all]
5. **Clearing** — deleting the reference stops the check and removes the chip; the events already written stay.

## Backend changes
- Models/schema: `Stream` gains `reference_path VARCHAR(1024) DEFAULT ''`, `ref_luma FLOAT`, `ref_contrast FLOAT`, `ref_sharpness FLOAT`, `ref_limits JSON`, `ref_captured FLOAT` (null) and `scene_state VARCHAR(16) DEFAULT ''` as one `ADD COLUMN` block in `app/schema/streams.py` `STREAMS`.
- Routers: `app/routers/scene.py` (new), prefix `/api/ws/{ws}/projects/{project}/streams`, `dependencies=[Depends(require_flag("task_scene_guard"))]`; `GET /{sid}/scene` → `{reference: {path, luma, contrast, sharpness, captured}, current, deltas, state, limits}`; `POST /{sid}/reference` → captures the live frame (503 `ไม่สามารถจับภาพอ้างอิงได้ — ยังไม่มีเฟรม` when there is none); `PUT /{sid}/reference/limits` (each 5–100 %); `DELETE /{sid}/reference`. `stream_out` gains `scene` (`ok|drift|''`) for the wall.
- Services/jobs: `app/streams/scene.py` (new) — `measure(frame_bgr) -> {luminance, contrast, sharpness}` on the same scale as `services/quality.py` (sharpness = Laplacian variance / 20 000 on a 512 px copy, luminance = mean / 255, contrast = std / 64 clamped) and `compare(current, reference, limits) -> {"state", "deltas", "worst"}`. `app/streams/manager.py` measures one analysed frame every 60 s, compares, and on a breach writes one `StreamEvent` with `rule={"kind": "scene", "label": "scene drift"}` at a one-hour cooldown while setting `scene_state = "drift"`; recovery clears it without an event. No job kind.
- Permissions + workspace isolation: reading needs `project.streams`, capture and limits need `c.need("admin")`; the stream is resolved through `workspace_id` + `project_id`, the reference file is written under `DATA_DIR/streams/<sid>/` and the path is checked to stay inside `DATA_DIR`.
- Secrets/safefetch: none — frames come from the decoder; no URL is fetched.
- OpenAPI: yes — four routes and one `stream_out` key.

## Tests to write first
pytest — `apps/backend/tests/test_scene_guard.py`:
- `test_measure_returns_the_three_numbers_on_the_quality_scale` — a uniform grey frame yields `luminance ≈ 0.5`, `contrast ≈ 0`, and a sharpened checkerboard yields a higher sharpness than a blurred one.
- `test_compare_flags_a_dimmer_frame` — a current frame 41 % darker than the reference returns `state: "drift"`, `worst: "luminance"` and `deltas.luminance ≈ -0.41`.
- `test_a_within_limits_frame_is_ok` — a 5 % change against default limits is `ok` and writes no event.
- `test_a_breach_writes_one_event_per_hour` — two breaches 10 minutes apart write one `scene` event; a third after 61 minutes writes a second.
- `test_capture_without_a_frame_is_503` — a stopped stream answers 503 with `ไม่สามารถจับภาพอ้างอิงได้ — ยังไม่มีเฟรม`.
- `test_limits_outside_the_band_are_422` — `{luminance: 1}` and `{contrast: 120}` are refused.
- `test_the_routes_are_hidden_while_the_flag_is_off` — 404 with the flag off and no event is written.
- `test_a_stream_from_another_workspace_is_404` — read, capture and delete with a foreign stream id are 404.
node — `apps/frontend/tests/scene-guard.test.mjs`:
- `test_delta_label_carries_the_sign_and_the_percent` — `-0.41` reads `−41 %` and `0.03` reads `+3 %`.
- `test_worst_sentence_names_the_measured_cause` — a luminance drift reads `ภาพเคลื่อนจากค่าอ้างอิง 41% — ตรวจไฟ`.
- `test_scene_chip_is_absent_without_a_reference` — `sceneChip('')` is null and `sceneChip('drift')` is `ภาพเคลื่อน`.
- `test_limits_validation_matches_the_api` — `{luminance: 5, contrast: 30, sharpness: 40}` is valid, `{luminance: 0}` is not.

## Acceptance criteria
- [ ] A stream captures a reference frame and stores the three measurements with its limits and the capture time.
- [ ] A frame outside the limits raises one drift event with the cause and the percentage, and at most one per hour.
- [ ] The stream page shows reference and current side by side with deltas, and the wall shows `ภาพเคลื่อน` for a drifted camera.
- [ ] Empty, loading and error states above all render, including the no-frame 503 sentence.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no tab, no chip, no routes and no measurement.

## Notes for the implementer
Reuse the `services/quality.py` scale for sharpness and luminance so a stream number and a dataset-health number are the same number; contrast is the extra axis and must be clamped to 0–1 like the others. One event per hour, not per frame: this guard exists to get a technician to a lens, and an alarm queue flooded by it will be snoozed into uselessness. Copy: `scene.title`=`ภาพอ้างอิง`, `scene.capture`=`จับภาพอ้างอิง`, `scene.capturing`=`กำลังจับภาพ`, `scene.limits`=`ขีดจำกัดความสว่าง / คอนทราสต์ / ความคมชัด`, `scene.comparing`=`กำลังเทียบ {n} เฟรม`, `scene.drift`=`ภาพเคลื่อนจากค่าอ้างอิง {p}% — ตรวจไฟ`, `scene.ok`=`ตรงกับภาพอ้างอิง`, `scene.noRef`=`ยังไม่มีภาพอ้างอิง`, `scene.noFrame`=`ไม่สามารถจับภาพอ้างอิงได้ — ยังไม่มีเฟรม`, `scene.delete`=`ลบภาพอ้างอิง`, `streams.scene.drift`=`ภาพเคลื่อน`.
