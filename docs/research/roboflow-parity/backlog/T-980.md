## User story
As a user opening a project, I want the experiments branch of the sidebar to exist and lead
somewhere honest, so that runs have a home before I know what a run is.

## UX flow (LabelDesk words)
1. **Sidebar → project → MODELS group → "Experiments"** — one entry, visible to `project.read`; the
   breadcrumb reads `project / experiments`. [empty: the page says "no experiments yet — every
   training run lands in `default`. Create one to group a sweep." with two buttons] [loading: the nav
   renders immediately, the page shows a 5-row skeleton] [error: the list fails — an inline retry that
   keeps the sidebar usable, never a blank shell].
2. **List** — table: name, tags, runs, last activity, archived badge. Row click opens the experiment.
   [empty with a filter applied: "no experiments match — clear the filter", distinct from the true
   empty state].
3. **Deep link** — `/:ws/p/:project/experiments/<id>` reloads to the same experiment; an unknown id is a
   not-found panel inside the project chrome, not a redirect.
4. **Cross-check** — `:ws/experiments` is added to the reserved workspace segments so it is never read
   as a project slug.
