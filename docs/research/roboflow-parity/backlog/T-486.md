## User story
As a new user who dismissed the tour, I want a three-step hint inside the first project card and a way to bring it back, so that guidance is available without covering the work I came to do.

## UX flow (LabelDesk words)
1. **First visit to a workspace** — the first project card carries an inline hint: step 1 of 3, one sentence, `Next`, `Dismiss`. It is a region inside the card, not a modal over the page. [empty: a workspace with no projects shows the hint at the top of the empty state instead of inside a card]
2. **Step 3 → Done** — the hint closes, the "seen" flag is written per user per workspace, and the card keeps its normal height.
3. **Home header** — a `Show the guide` text button (not a primary) re-opens it at step 1; it no longer sits above real work. [error: storage that refuses to write (private mode) still hides the hint for this session and never throws]
4. **Reducer motion preference** — steps change by opacity only; no scroll animation, no spotlight ring.
