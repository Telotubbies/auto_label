## User story
As a safety officer, I want to see the exact page, turn zones off and add one remark before it prints, so that what I hand the inspector is the sheet I checked rather than a PDF I hoped for.

## UX flow (LabelDesk words)
1. **`ใบสรุปความปลอดภัยประจำวัน`** (`/:ws/:project/ops/safety`) — a date, a zone checklist on the left and the sheet preview on the right, scaled to fit. [loading: `กำลังสร้างเอกสาร` as a skeleton the size of the page] [error: `สร้างเอกสารไม่สำเร็จ — ลองอีกครั้ง` with retry] [empty: a day with no events still previews, with `วันนี้ยังไม่มีเหตุการณ์` in the sheet]
2. **Zones** — each zone is a checkbox; unchecking one regenerates the preview and the incidents table drops that zone's rows. [error: a zone the API no longer knows reads `ไม่พบโซนที่เลือก — แสดงทุกโซน` above the frame]
3. **The supervisor** — a name and phone field under the preview, saved to the project's settings; without them the print button is dimmed with `ยังไม่ได้กำหนดผู้ตรวจ — เซ็นไม่ได้` and the API would refuse the same request with 409. [error: the 409 renders the same sentence, never a toast]
4. **The remark** — one 300-character field that prints above the signature block. [error: over the limit, the field counts down instead of failing at submit]
5. **`พิมพ์ / บันทึกเป็น PDF`** — opens the sheet in a new tab with the browser's print dialog; the officer saves it. [error: the popup blocked message names the button and offers the direct link]

## Backend changes
- Models/schema: none.
- Routers: none — the page reads `GET /documents/safety.html` and writes the supervisor through the existing project settings route.
- Services/jobs: none.
- Permissions + workspace isolation: the route is `<PermGate perm="project.streams">`; saving the supervisor needs `project.settings` and is dimmed otherwise; a project id from another workspace is 404 through T-721.
- Secrets/safefetch: none.
- OpenAPI: no — no route changes.

## Acceptance criteria
- [ ] The page previews the exact sheet for the chosen date and zones, and unchecking a zone changes the preview.
- [ ] The print action is refused with the supervisor sentence until a supervisor is set, and the API refuses the same request with 409.
- [ ] The remark prints above the signature block and is capped with a visible countdown.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's sheet or supervisor (404, not 403).
- [ ] Flag off ⇒ no Ops item, no route, no document.

## Notes for the implementer
Copy: `sheet.title`=`ใบสรุปความปลอดภัยประจำวัน`, `sheet.zones`=`โซนที่รวมในรายงาน`, `sheet.supervisor`=`ผู้ตรวจ`, `sheet.supervisorPhone`=`เบอร์ติดต่อ`, `sheet.remark`=`หมายเหตุ`, `sheet.remarkLimit`=`เหลือ {n} ตัวอักษร`, `sheet.print`=`พิมพ์ / บันทึกเป็น PDF`, `sheet.noSupervisor`=`ยังไม่ได้กำหนดผู้ตรวจ — เซ็นไม่ได้`, `sheet.empty`=`วันนี้ยังไม่มีเหตุการณ์`, `sheet.loading`=`กำลังสร้างเอกสาร`, `sheet.error`=`สร้างเอกสารไม่สำเร็จ — ลองอีกครั้ง`, `sheet.unknownZone`=`ไม่พบโซนที่เลือก — แสดงทุกโซน`, `sheet.popupBlocked`=`เบราว์เซอร์บล็อกหน้าต่างใหม่ — เปิดลิงก์เอกสารแทน`. There is no server-side PDF and no "download" button: the browser's print dialog is the PDF engine, and the button says exactly that so nobody reports a missing file.
