## User story
As a team, I want to reuse one pipeline as a block inside another, so that our crop-then-classify template stops being copy-pasted into every project.

## UX flow (LabelDesk words)
1. **Palette → "Workflow"** — adding the block asks which saved workflow of this project to use; the node shows that workflow's name and its input ports, mapped to the parent's. [empty: the project has one workflow → the palette row says "This is the only workflow in the project."] [loading: the picker lists saved workflows with a spinner] [error: the picked workflow is missing after a removal → the node shows "That workflow was deleted." and saving is refused]
2. **Map the ports** — the config panel lists the child's inputs with a source picker (`$parent.image`, `$steps.crop.crops`, a literal). Unmapped required inputs are highlighted and block the save with "Image input is not mapped."
3. **Run** — the child's blocks execute in the parent's plan; `plan.order` names them `inner:<nodeId>/<childNodeId>` so the run panel's "N blocks ran" is honest.
4. **Recursion** — a child that (directly or transitively) contains the parent is refused at save: "A workflow cannot contain itself." Depth is capped at three nested levels.

## Backend changes
- Models/schema: none — the reference is `{type: "inner", config: {workflow_id, map: {port: source}}}` inside the graph.
- Routers: `apps/backend/app/routers/workflows.py` — `GET /{workflow_id}/versions` is reused by the picker; no new route, because the picker reads the existing workflow list.
- Services/jobs: `apps/backend/app/services/workflow_inner.py` (new) — `resolve(db, project, node) -> Workflow` refusing a foreign or deleted id, `inline(db, project, graph, depth=0) -> graph` splicing the child's nodes and edges with prefixed ids, `depth(node_graph, seen) -> int` and `check(db, project, graph)` raising `ValueError("A workflow cannot contain itself.")` or `"Nested workflows are limited to three levels."`.
- Permissions + workspace isolation: the child is read with `svc.get(db, project, id)`, so another project's or workspace's workflow is invisible.
- Secrets/safefetch: none.
- OpenAPI: yes — the block type appears in the graph schema.

## Notes for the implementer
Inline at compile time, never at save time: the parent must pick up the child's later fixes, and a stored copy is the copy-paste drift this block exists to remove. Prefix every spliced id so two inner nodes of the same child cannot collide.
