## User story
As an operations engineer, I want the datasource row to show its filters, its last run and its cooldown so
that a nightly bucket mirror is something I configure once and can explain to my manager.

## UX flow (LabelDesk words)
1. **Settings · Connectors · Datasources** — each row: name, provider, destination ("PPE Detection"),
   last run ("12 min ago · 398 added"), a play button, an eye button and an overflow menu (Edit, History,
   Delete). [empty: "No datasources yet — connect a bucket to mirror its images."]
2. **Settings · Datasources · Mirror** — destination picker (project; the library option is disabled with
   "Available after the asset library ships"), include globs, exclude globs, naming strategy, "Update
   images when the bucket copy is newer" (on) and "Remove images whose object was deleted" (off, amber
   when on). [error: invalid glob → the pattern is underlined and the primary is disabled]
3. **Settings · Datasources** — play is disabled with "Available again in 12:41" or "Hourly limit reached
   — next manual run at 14:05"; clicking during a run shows "A sync is already running".
   [loading: the row's progress bar follows the job]
4. **Settings · Datasources · History** — table of runs with trigger and counts; a failed run shows the
   error and a **Retry** that starts a manual run. [empty: "No runs yet — press play to test the
   configuration."]
5. **Settings · Datasources** — "Run automatically every day" switch shows "Next run tomorrow, 02:00"; the
   eye button opens the filtered asset view once a run has completed and is disabled before that with
   "Available after the first sync".
