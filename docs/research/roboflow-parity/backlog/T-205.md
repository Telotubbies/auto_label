## User story
As an aerial-inspection reviewer, I want the tiling card to show the mode, the overlap and the resulting tile count, so that I can predict the dataset size before I generate it.

## UX flow (LabelDesk words)
1. **Wizard → step 3 → Tiling card** — mode select, then only the fields that mode uses: grid → *Rows · Columns*; fixed size → *Tile width · Tile height · Overlap %*; fixed aspect → *Ratio · Span (width/height) · Overlap %*. Plus *Pad edges with black / white*. [empty: off] [loading: tile count "…"] [error: "Tile size must be 224–4096 px." and "Overlap must be 0–90%." beside their fields]
2. **Count line** — "6 tiles for this image" (grid/fixed, exact) or "≈ 6 tiles for this image · the pool count depends on each image's size" (aspect). [empty: "No sample image to count."]
3. **224 px floor explained** — a hint under the size field: "Tiles smaller than 224 px stop helping — the objects are already big enough at that scale."
4. **Incompatibilities** — turning tiling on with crop or isolate objects on shows the pair message from T-193 and *Create* stays blocked.
5. **Flag off** — with `task_30` off the card is absent (today's behaviour); with `task_190` off only *Fixed size* renders.
