## User story
As a project manager, I want one sheet that repeats what I am about to spend and what will happen to existing labels, so that confirming a batch is an informed click.

## UX flow (LabelDesk words)
1. **Annotate board → Auto Label → Class prompts → Label batch** — the primary button now opens a summary sheet instead of queueing immediately. [loading: the sheet opens with the estimate line in a skeleton until T-131's response lands]
2. **Sheet contents, in order** — batch name (or "Whole project" when no batch is chosen) · `40 images` · model name with its licence chip · output shape ("Masks" / "Boxes" / "Polygons", from T-141) · class list with each threshold, folded to "+3 more" above four · policy line ("Merge into existing labels") · `0.40 credits · 4,120 AI calls left`.
3. **Not affordable** — the confirm button is replaced by an explanation and a disabled **Label 40 images**, plus a **View usage** link to `/:ws/settings/usage`. [error: the estimate request failed → "Cost estimate unavailable — try again" with a retry inside the sheet, and confirm stays disabled]
4. **Confirm** — "Label 40 images" queues the job, closes both sheets, toasts "Auto-label queued — results land in Review", and the board banner appears. Escape or Cancel returns to the class prompts with every value intact.
5. **Second guard** — the confirm button carries the count, so a double click cannot queue twice: it disables on first press and the request is idempotent per click.
6. **Where the numbers come from** — every number on the sheet is the server's; the sheet never recomputes credits or counts client-side.

## Acceptance criteria
- [ ] Label batch opens a summary naming the batch, image count, model, output shape, class thresholds, policy and cost before anything is queued.
- [ ] An unaffordable or unestimated batch cannot be confirmed, and the reason is stated in the sheet.
- [ ] Confirming queues exactly one job and closes both sheets; Cancel and Escape return to the class prompts unchanged.
- [ ] Every number shown is the value the API returned, verified by a test that passes deliberately odd numbers through.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — no new endpoint.
- [ ] No flag: a step inside the existing dialog.
- [ ] Keyboard-only path: Auto Label → Label batch → Tab to the confirm → Enter → board banner.

## Notes for the implementer
Two sheets stacked is acceptable here (class prompts → summary) because Cancel is explicit; do not make the summary a third route or a page. Keep the count in the button label — it is the whole point of the screen.
