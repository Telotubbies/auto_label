## User story
As a reviewer, I want the dataset snapshot behind a run — version, counts, classes and its content hash — so I can
prove two compared runs saw the same images instead of assuming it.

## UX flow (LabelDesk words)
1. **Models → a run → Dataset** — version number and name, `1 240 images · 992 train / 198 valid / 50 test`, the
   class list with counts, the evaluation split, and `Snapshot 3f9a1c2e` with a copy button.
   [empty: a run whose version row was deleted renders `The dataset version behind this run was deleted.`]
   [loading: four skeleton rows] [error: `Dataset details could not be loaded.` with retry, and the rest of the
   run page unaffected]
2. **Copy the hash** — pasting it into the run filter (T-908) is how a user lists every run on that exact snapshot,
   once the filter learns `dataset:`; until then the copy is for a report.
3. **Compare guard** — a run trained on another version says `Trained on a different dataset version` in the
   compare picker's tooltip, matching the 400 the API already gives (`services/insights.py:714-715`).

## Backend changes
- Models/schema: none — `Version.stats` (`models/project.py:203`) and the manifest written at
  `services/versioning.py:199-203` (`manifest.json` → `version_hash`) already hold every field.
- Routers: `apps/backend/app/routers/training.py` — `GET …/models/{mid}/dataset` → `{"versionId", "version",
  "name", "images", "splits", "classes", "digest", "split", "deleted": bool}`; 404 for an unknown or foreign model.
- Services/jobs: `apps/backend/app/services/run_view.py` — add `dataset_input(db: Session, m: TrainedModel) -> dict`:
  reads the version row, takes `stats.images/splits/classes/class_names`, and reads
  `version_dir(v)/"manifest.json"` (`services/versioning.py:18`) for `version_hash`; a missing or unreadable
  manifest yields `digest: None` with `note: "snapshot hash unavailable"`. The evaluation split comes from
  `(m.metrics or {}).get("eval", {}).get("split")`. Read-only; no caching layer.
- Permissions + workspace isolation: `project.models`; the version is resolved through the model's own project, so a
  version from another project cannot be named.
- Secrets/safefetch: none — one file read under `DATA_DIR` via `version_dir()`.
- OpenAPI: yes — `python tools/export_openapi.py`, then `npm run gen:api-types`.

## Tests to write first
pytest — `apps/backend/tests/test_run_dataset.py`:
- `test_the_digest_is_the_manifest_hash` — generate a version → the endpoint's `digest` equals
  `json.loads(manifest.json)["version_hash"]`, and the counts equal `Version.stats`. (also the flag-on path)
- `test_a_missing_manifest_returns_no_digest` — delete `manifest.json` → 200, `digest` null, `note` present, no 500.
- `test_a_deleted_version_is_reported_not_raised` — remove the version row → `deleted: true` and the copy the UI
  ships; the run itself still serves.
- `test_the_eval_split_is_the_recorded_one` — `metrics.eval.split == "test"` → `split == "test"`; a run without an
  evaluation → `split` null.
- `test_a_foreign_model_is_404` — workspace B's token on workspace A's run → 404.
- `test_reading_the_block_writes_nothing` — no `Version`, `TrainedModel` or audit row changes.

node — `apps/frontend/tests/run-dataset.test.mjs`:
- `test_counts_and_hash_render_in_one_line` — a payload → `1 240 images · 992 train / 198 valid / 50 test` and
  `Snapshot 3f9a1c2e`; a long class list is truncated with a `+N more` affordance.
- `test_a_missing_digest_hides_the_copy_action` — `digest: null` → no copy button and the note ships.
- `test_the_deleted_copy_is_exact` — the string above ships verbatim, and no version link is rendered.

## Acceptance criteria
- [ ] A run shows its version, counts, classes, split, and a hash that matches the manifest on disk.
- [ ] A missing manifest or a deleted version degrades to a named note, never an error page.
- [ ] Two runs on different versions are visibly different here before the compare tab refuses them.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.

## Notes for the implementer
