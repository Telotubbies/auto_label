## User story
As a security manager, I want to see exactly which files will leave, choose redacted or original with a reason, and then download one zip, so that nobody discovers afterwards what was in the package.

## UX flow (LabelDesk words)
1. **`แพ็กหลักฐาน`** — a button on the incident row on `/:ws/:project/streams/:sid` opens the dialog with the window set to ±10 minutes around the event. [empty: `เหตุการณ์นี้ยังไม่มีคลิป — จะแนบเฉพาะภาพนิ่ง` above the item list] [loading: `กำลังเตรียมรายการ`] [error: `เตรียมรายการไม่สำเร็จ — ลองอีกครั้ง`]
2. **The items** — five checkboxes (`คลิป`, `ภาพนิ่ง 3 ภาพ`, `บันทึกเหตุการณ์`, `ตำแหน่งกล้อง`, `ใบปะหน้า`) with a live file count and size estimate; the cover cannot be unchecked. [error: `เลือกอย่างน้อยหนึ่งรายการ` when everything but the cover is off]
3. **Redaction** — a two-option choice: `ส่งออกแบบเบลอ (ค่าเริ่มต้น)` or `ส่งออกต้นฉบับ`; the second reveals a required reason field and is dimmed for a caller without `project.settings` with the lock line. [error: `ส่งออกต้นฉบับต้องมีสิทธิ์ผู้จัดการและเหตุผลที่บันทึกไว้`]
4. **Build** — `สร้างแพ็กหลักฐาน` then `กำลังสร้างแพ็ก ({n} ไฟล์)`, ending in a download link with the manifest hash shown. [error: `ไฟล์หลักฐานหมดอายุตามนโยบายเก็บข้อมูลแล้ว (30 วัน)` when the window is past retention, and the dialog stays open]
5. **The result** — the manifest is rendered as a table of file, size, sha256 (first 12 characters, full value on copy); the link expires in 15 minutes and says so. [error: `ลิงก์หมดอายุ — สร้างแพ็กใหม่`]

## Backend changes
- Models/schema: none.
- Routers: none — the dialog reads `POST /evidence`, `GET /evidence/{id}` and `GET /evidence/{id}/download`, and reads the stream's `export_policy` from the stream payload T-728 extended.
- Services/jobs: none.
- Permissions + workspace isolation: the route is `<PermGate perm="project.streams">`; the build button is disabled unless `can('project.export')`, and the original option unless `can('project.settings')`; the API enforces both, and an event id from another workspace is 404.
- Secrets/safefetch: none.
- OpenAPI: no — no route changes.

- `test_the_cover_cannot_be_removed` — `itemList({cover:false})` still contains `cover`, and `canBuild({raw:true, reason:''})` is `{ok:false, reason:'ส่งออกต้นฉบับต้องมีสิทธิ์ผู้จัดการและเหตุผลที่บันทึกไว้'}`.

- `test_the_policy_line_names_what_leaves` — `policyLine('redacted')` is `ส่งออกแบบเบลอ (ค่าเริ่มต้น)`; `policyLine('original')` is `ส่งออกต้นฉบับ`.
pytest — `apps/backend/tests/test_evidence_dialog_contract.py`:
- `test_the_package_payload_has_every_field_the_dialog_draws` — `POST /evidence` returns `id`, `files[{name, sha256, bytes}]`, `manifest_sha256`, `url`, `expires`.
- `test_the_package_from_another_workspace_is_404` — a foreign event id is 404.

## Acceptance criteria
- [ ] The dialog shows the window, the five items and a live count before anything is built.
- [ ] Redacted is the default; original requires the manager permission and a reason, and the button states why it is dimmed.
- [ ] The built package lists every file with its hash and the link's expiry, and a retention refusal is a sentence in the dialog.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's event (404, not 403).
- [ ] Flag off ⇒ no action on the incident row and the stream page is unchanged.
