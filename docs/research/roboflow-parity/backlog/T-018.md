## User story
As a labeler or importer, I want the project type to refuse work the target model cannot learn from, so that a polygon in a detection project or a box in a semantic project never reaches a version.

## UX flow (LabelDesk words)
1. **Save an annotation of the wrong shape** — e.g. a polygon on an `object-detection` project is approximated to its bounding box, and the API response says `{"shape": "bbox", "converted_from": "polygon"}` so the editor can show `Polygon saved as a box — detection learns boxes.` [error: a keypoint shape on a detection project is refused `400 This project type does not store keypoints`].
2. **Import a file the type cannot hold** — the upload result sheet names it: `3 files skipped — polygons need a segmentation project.` instead of a generic failure. [empty: nothing skipped → the line is absent]
3. **Version and export** — the format list is the one the type allows (`GET /projects/{p}/versions/formats` already filters by `exporters.FORMATS[*].tasks`); a request for a foreign format returns 400 `format not available for this project type`.
4. **Project settings** — the type is shown read-only with the sentence `Type is fixed when the project is created.` (no control, no dropdown).

## Backend changes
- Models/schema: none.
- Routers: `GET /api/ws/{ws}/projects/{p}` gains `"typeContract": {"shapes": [...], "imports": [...], "formats": [...], "augmentations": [...]}`; `PUT`/`POST` annotation paths validate the shape kind against it; version export keeps its 400.
- Services/jobs: `services/project_contract.py` (new) — `SHAPES = {type: frozenset({bbox|polygon|class|keypoints|segment})}`, `IMPORTS = {type: frozenset({"coco","yolo","voc","labelstudio","cvat","folder","multiclass_csv"})}`, `FORMATS` derived from `exporters.FORMATS` (no duplicate list), `checks(project_type) -> dict`, `coerce_shape(project_type, shape) -> (shape, note|None)`, `allowed_import(project_type, fmt) -> bool`.
- Permissions + workspace isolation: rules run inside `project_ctx`; a project id from another workspace still 404s before any check.
- Secrets/safefetch: none.
- OpenAPI: yes (`typeContract` field).

## Acceptance criteria
- [ ] Wrong-shape annotations are converted (polygon→box on detection) or refused with the type named; never silently stored as-is.
- [ ] Import skips name the type-level reason and the count.
- [ ] Empty, loading and error states above all render (no skips → no line; unknown contract → no note).
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag none: the rule applies to every project; the previous click paths keep working, with one extra note line.
- [ ] The format list is derived from `exporters.FORMATS`, not a second hard-coded table.

## Notes for the implementer
`FORMATS` stays in `exporters.py`; `project_contract` imports it. One coercion rule only: polygon→bbox for `object-detection`; everything else is refused, never approximated.
