## User story
As an inspector of PCB or IC images, I want to read a defect's size in millimetres and see the image's real facts, so that a judgement does not need an export round trip.

## UX flow (LabelDesk words)
1. **Editor → bottom bar → ruler button** — opens the **Measure** panel: a scale block (pixels per known length + unit `mm | cm | m | in | ft`, blank = pixels only) and a guide switch. `Shift+M` toggles the guide. [empty: no scale set → the guide reads pixels and the panel says "Set a scale for real units"] [error: a non-numeric or zero scale → the field keeps the last valid value and explains]
2. **Guide on canvas** — two dotted pairs (one horizontal, one vertical) with draggable tabs outside the image and a label per pair showing the length in the chosen unit; dragging a label moves the pair, and `←`/`→`/`↑`/`↓` nudge the selected tab 10 px (`Shift` = 1 px). [loading: nothing to load — the guide is local]
3. **Persistence** — the scale is stored in the browser (`localStorage` key `ld:measure`), never on the project, and survives image changes; a **Clear scale** button removes it.
4. **Facts panel** — the drawer's Classes/Objects area gains a **Facts** panel (opened from the Objects header's information button): dimensions, megapixels, file size, uploaded at, last modified, split chip, batch name, tag count. [empty: a batch-less image shows "No batch"] [error: the facts read fails → the panel shows the last known values with a retry]
5. **Honesty** — the guide never affects annotations, never marks the image dirty and never appears in an export. The panel has no uploader field because an image row does not record who uploaded it — the card says so rather than inventing one.

## Acceptance criteria
- [ ] With a scale set, both guide pairs report real units; without one they report pixels and say why.
- [ ] The guide can be toggled by `Shift+M`, dragged by its tabs and labels, and nudged by the arrow keys.
- [ ] The scale is per browser (survives image changes and reloads) and never touches the image row.
- [ ] The Facts panel shows dimensions, megapixels, size, uploaded and modified times, split, batch and tag count, each with its empty case.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ the ruler button and the guide are absent; the Facts panel still works (no flag).
- [ ] Keyboard-only path: `Shift+M` → Tab to the panel → arrow-nudge the selected tab.

## Notes for the implementer
No uploader field: `Image` has no `created_by` column and adding one for a label is not worth the migration — say "Uploaded at" and stop. The unit list is fixed to `mm, cm, m, in, ft`; adding more is a one-line array, not a settings screen.
