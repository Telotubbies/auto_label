## User story
As the performance owner, I want one script that measures the build and the main routes against fixed
budgets and names the commit when a budget is missed, so that "fast enough to work a shift" is a number the
merge captain can enforce.

## UX flow (LabelDesk words)
1. **`npm run perf`** — builds the app, prints the bundle table, starts the preview and the stub API, and
   measures the routes in `docs/qa/USABILITY-PROGRAM.md` §7. [error: a missing build says "run the build
   first" instead of measuring a stale `dist`].
2. **A passing run** — each row prints measured, budget and margin; the exit code is 0.
3. **A failing run** — the row prints the overage, the route and the commit; the exit code is 1. A miss
   under 20 % is reported as S3 and does not fail the process.
4. **The report** — `docs/qa/audits/performance.md` holds the baseline table, the machine, the date and the
   attribution of every overage.

## Acceptance criteria
- [ ] The bundle table reports initial JS, every lazy chunk and CSS, all gzipped, and enforces §7.
- [ ] Every §7 metric has a measured value on a named build, machine and date.
- [ ] A budget miss over 20 % exits non-zero; under 20 % is an S3 row, not a failure.
- [ ] The report attributes each overage to a commit or says "unattributed"; it never hides the number.
- [ ] No budget is raised in this card; the baseline may only equal or tighten the §7 ceiling.
- [ ] Empty, loading and error states: a missing build, a preview that fails to start, a route that 404s —
      each prints one actionable sentence.
- [ ] Workspace isolation: not applicable; the measurement is read-only and stays on the seeded workspace.
- [ ] Flag off ⇒ the measured routes are the flag-off defaults; the card adds no flag.

## Notes for the implementer
Measure the production build with `vite preview`, never the dev server. Pin the machine and the Node
version in the report; a budget measured on another machine is evidence, not a gate. No CI job is added:
the nightly lane runs `npm run perf` and the triage card records the result.
