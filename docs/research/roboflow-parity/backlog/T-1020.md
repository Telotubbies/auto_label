## User story
As the release reviewer, I want one Playwright run that walks the hub end to end against mocked
inference endpoints, so that the shipped flow and its states are verified without a GPU or a download.

## UX flow (LabelDesk words)
1. Sign in as the demo admin → the workspace rail shows **Inference** → open it.
2. **Calculator** — pick the RTX 4090 preset, 7B BF16, 8192 context, batch 4 → "Fits" and a tok/s
   estimate with the range and the assumptions link.
3. **Engines** — host `gpu-demo` selected → vLLM `Compatible`, TensorRT-LLM `Blocked` (driver) → tick
   vLLM → `Review install plan` → the sheet shows argv and bytes → tick the acknowledgement → `Install`
   → the job card runs `Installing vLLM` to `Installed`.
4. **Models** — filter `Fits this host` → download Qwen2.5-VL 7B AWQ → the sheet shows the disk after →
   confirm → progress → `Installed` → the assets panel shows it and the disk bar drops.
5. **Segmentation** — SAM 3.1 `Ready` → choose project `ppe-detection` → `Use for auto-label` → the
   dataset opens with the Auto label dialog and `sam3:sam3.1` selected.
6. **Permission** — sign out, sign in as a labeler, the rail has no **Inference**, and a direct
   `/inference` URL lands on the workspace home. [error: every API failure renders its inline state].

## Acceptance criteria
- [ ] One spec covers all four tabs and the labeler denial, and passes headless on CI.
- [ ] Every stubbed failure renders its inline state (409, block, gated, empty).
- [ ] No real engine, download, HF token or GPU is used; the only network is the local API/web.
- [ ] The run is deterministic: fixed fixtures, no timers longer than the poll interval, no sleeps.
- [ ] Screenshots on failure are attached to the report.

## Notes for the implementer
Stub only the inference routes (`**/api/ws/*/inference/**`) so permissions and project resolution remain
real. Do not stub the registry: the handoff's preselection must be proved against the real model list.
Keep the fixtures in one JSON file so the API-shape tests and the e2e cannot drift apart silently.
