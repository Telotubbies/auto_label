## User story
As a developer copying the cURL call, I want the first line of the snippet to be readable, so that I can
see the endpoint and the auth header before I paste it.

## UX flow (LabelDesk words)
1. **Deploy & Test** (`/:ws/:project/deploy`) — the "Call the endpoint" card shows the cURL snippet. The
   Copy button sits in its own strip above the code, or inside the card's padding, never on a code line.
2. **Long line** — the `<pre>` scrolls horizontally, and the first line is fully readable at both ends.
3. **Copy** — the same `toast.ok('Copied')` as today. [error: unchanged, clipboard failure already falls
   through silently]

## Notes for the implementer
Options considered:
1. **`pr-12` on the `<pre>` (recommended).** One class, the button keeps its corner, the code keeps its
   scroll.
2. **Move the button into a header row above the block.** Cleaner, but it adds a row and changes the card's
   height on a dense page.
3. **`<pre>` with `overflow-wrap: anywhere`.** Rejected: wrapping a cURL command breaks the paste.

Do not shorten the snippet to make room. The URL is the point of the card.
