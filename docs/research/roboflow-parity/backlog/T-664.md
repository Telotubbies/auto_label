## User story
As an ops lead, I want to write the job in a sentence, fix the plan it produces, look at twenty images and then leave, so that I approve the work I asked for instead of the work a threshold happened to produce.

## UX flow (LabelDesk words)
1. **Annotate board → New job** (`/:ws/:project/annotate`) — a sheet with one text box ("Label helmets and vests on the night-shift batch, and show me 20 images first"), a batch picker and "Plan it". [error: "I could not read a target class list — name the objects you want"; the sentence stays editable]
2. **The plan card** — rows for classes and their prompts, the model, the review policy, the trial size and the call budget; each row is an editable control, and "Save changes" writes the plan back. [loading: "Reading your sentence…"] [empty: a plan with no class shows the fix sentence and disables the trial]
3. **Trial** — `[loading: "Running 18 of 20 trial images…"]`, then a yield table per class, three sample crops and "escalated: 6"; "Revise" returns the plan, "Approve and run" starts the batch.
4. **The run** — the sheet closes and the board's existing auto-label banner tracks it; a link "Open the report" goes to `/:ws/:project/agent/:rid`.
5. **The report** — labelled / escalated / skipped with a reason each, the spend, the plan snapshot as an audit record, and a link to the review batch the escalations became.
6. **Flag off** — no New job button and no route.

## Acceptance criteria
- [ ] One sentence plus a batch opens an editable plan, and save persists the edits before anything runs.
- [ ] A trial shows a per-class yield, three samples and the escalated count, and Revise returns to the plan.
- [ ] Approve starts one run, the board tracks it, and the report separates labelled, escalated and skipped with the spend and the plan snapshot.
- [ ] Empty, loading and error states above all render, including an unreadable sentence and a plan with no class.
- [ ] Workspace A cannot open workspace B's run: the route only ever requests ids from this project's own responses.
- [ ] Flag off ⇒ no button, no route and the board is unchanged.

## Notes for the implementer
The sentence is a starting point, not a contract — always show the plan as editable rows, because a misread class name is the expected failure and fixing it must cost one field. Never hide the budget line behind a disclosure: it is the reason a manager approves. On approve, close the sheet and hand the user to the existing auto-label banner; do not build a second progress surface.
