## User story
As a packaging QA engineer, I want the expected lot and expiry text registered once and every read graded against it, so that one wrong digit is a red row with its position instead of a recall found by a person reading 900 strings.

## UX flow (LabelDesk words)
1. **Project settings → `ตรวจข้อความ`** (`/:ws/:project/settings?tab=ocv`) — one row per field: the field name, `ค่าที่คาดหวัง` (a literal or a pattern), and `การตรวจ` (`ตรงทั้งหมด`, `ตามรูปแบบ`, `ไม่สนตัวพิมพ์`). [empty: `ยังไม่ได้ตั้งค่าที่คาดหวัง — ตั้งค่าครั้งเดียวแล้วใช้ได้ทุกชุด`] [loading: `กำลังโหลดการตั้งค่า`]
2. **`ตรวจทั้งโครงการ`** — runs over every image that carries an OCR annotation and returns `ตรง 812 · ไม่ตรง 7`, with the seven listed. [loading: `กำลังตรวจ 819 ภาพ`]
3. **A mismatch row** — reads the field, the expected value, the read value and `ตำแหน่งที่ต่าง 7`, with the first differing character highlighted in both strings and a link into the editor at that image. [error: `ต้องระบุค่าที่คาดหวังก่อนตรวจ` when a field has an empty expectation]
4. **Export** — Markdown and JSON export carry `expected`, `read` and `verdict` beside the text, and a `ไม่ตรง` count in the export response, so the gate is auditable outside LabelDesk.
5. **A station without an expectation** — reads `ยังไม่ได้ตั้งค่าที่คาดหวังสำหรับสถานีนี้` and is skipped by the run instead of failing silently.

## Backend changes
- Models/schema: `app/models/ocr_check.py` (new) — `OcrCheck(id, workspace_id, project_id, station_id nullable, field, expected, grading ('exact'|'pattern'|'ignore_case'), created)` with `UniqueConstraint(project_id, station_id, field)`; register in `models/__init__.py`; `create_all` creates it, no `ADD COLUMN`.
- Routers: `app/routers/ocr_checks.py` (new), prefix `/api/ws/{ws}/projects/{project}/ocr/checks`, `dependencies=[Depends(require_flag("task_ocv_verify"))]`; `GET ""` → the checks with their station labels; `PUT ""` `{station_id?, field, expected, grading}` → upsert (400 empty expected, 422 unknown grading); `DELETE /{id}`; `POST /run` `{station_id?}` → `{checked, matched, mismatched: [{image_id, image_name, field, expected, read, first_diff}]}` (422 when there is nothing to run against).
- Services/jobs: `app/services/ocr.py` gains `verify(read, expected, grading) -> {match, first_diff}` (exact, `*`/`?` pattern, and a case-folded compare) and threads the result into `markdown_for`/`json_for` as `expected`/`read`/`verdict` when a check exists. No job: the project's OCR annotations are already in rows and the run is one pass.
- Permissions + workspace isolation: read `project.read`, write `project.roles` (manager only); images and annotations are read through `project_id` and `workspace_id`, so a foreign image id never enters a run.
- Secrets/safefetch: none — but PDPA still binds: every exported value keeps the existing `mask_pii` path, so an expectation is compared against the *unmasked* read and the export still masks.
- OpenAPI: yes — four routes, one response shape and two export keys.

## Tests to write first
pytest — `apps/backend/tests/test_ocv_verify.py`:
- `test_an_exact_grade_matches_or_names_the_first_difference` — `verify("LOT-2481", "LOT-2481", "exact")` matches; `verify("LOT-2418", "LOT-2481", "exact")` returns `first_diff == 7`.
- `test_a_pattern_accepts_wildcards` — `LOT-24*` matches `LOT-2481` and not `LOT-1999`; `?` consumes exactly one character.
- `test_ignore_case_folds_both_sides` — `lot-2481` matches `LOT-2481` under `ignore_case` and not under `exact`.
- `test_a_run_counts_matches_and_lists_mismatches` — 8 annotated images, 1 mismatch → `{checked: 8, matched: 7, mismatched: [one row]}` with the image id and the position.
- `test_an_empty_expectation_is_refused` — `PUT` with `expected: ""` is 400 and `POST /run` on a station with no check returns the skip sentence.
- `test_the_export_carries_expected_read_and_verdict` — `json_for` on a checked image includes all three keys and the PII masking still applies to `read`.
- `test_the_routes_are_hidden_while_the_flag_is_off` — 404 with the flag off.
- `test_a_check_from_another_workspace_is_404` — read, save, delete and run with a foreign id or project are 404.
node — `apps/frontend/tests/ocv-checks.test.mjs`:
- `test_split_at_diff_marks_the_first_differing_character` — `splitAtDiff('LOT-2418', 'LOT-2481', 7)` returns the prefix, the differing character and the suffix.
- `test_verdict_text_reads_match_or_mismatch_with_the_position` — a mismatch reads `ไม่ตรง · ตำแหน่งที่ต่าง 7`; a match reads `ตรง`.
- `test_grading_labels_are_the_three_shipped_choices` — `exact|pattern|ignore_case` map to `ตรงทั้งหมด`, `ตามรูปแบบ`, `ไม่สนตัวพิมพ์`.
- `test_a_missing_read_renders_a_dash` — `verdictText({read: ''})` renders `—` and no position.

## Acceptance criteria
- [ ] A check registers a field, an expected literal or pattern and a grading rule, once per station, and can be edited or removed.
- [ ] `ตรวจทั้งโครงการ` returns matched and mismatched counts and lists each mismatch with its first differing position.
- [ ] The Markdown and JSON export carry expected, read and verdict, with the existing PII masking intact.
- [ ] Empty, loading and error states above all render, including the per-station "no expectation" sentence.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no `ตรวจข้อความ` tab, no routes, and the OCR export payload is today's.

## Notes for the implementer
Compare against the **unmasked** read and mask only on the way out — masking first turns every Thai ID field into `*************` and a mismatch into a false pass. Two graded fields with the same name on two stations are two rows, keyed by `(project, station, field)`. Live-stream OCR is not part of this card: OCR runs on annotations, so a stream event type for a mismatch would need a live OCR path that does not exist. Copy: `ocv.tab`=`ตรวจข้อความ`, `ocv.expected`=`ค่าที่คาดหวัง`, `ocv.grading`=`การตรวจ`, `ocv.grading.exact`=`ตรงทั้งหมด`, `ocv.grading.pattern`=`ตามรูปแบบ`, `ocv.grading.ignoreCase`=`ไม่สนตัวพิมพ์`, `ocv.run`=`ตรวจทั้งโครงการ`, `ocv.running`=`กำลังตรวจ {n} ภาพ`, `ocv.empty`=`ยังไม่ได้ตั้งค่าที่คาดหวัง — ตั้งค่าครั้งเดียวแล้วใช้ได้ทุกชุด`, `ocv.loading`=`กำลังโหลดการตั้งค่า`, `ocv.noExpectation`=`ยังไม่ได้ตั้งค่าที่คาดหวังสำหรับสถานีนี้`, `ocv.expectationRequired`=`ต้องระบุค่าที่คาดหวังก่อนตรวจ`, `ocv.match`=`ตรง`, `ocv.mismatch`=`ไม่ตรง · ตำแหน่งที่ต่าง {n}`.
