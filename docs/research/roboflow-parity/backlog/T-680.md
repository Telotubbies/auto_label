## User story
As a quality manager answering a customer complaint, I want the twelve seconds around the trigger, not one still, so that "it was already scratched when it arrived" can be settled by watching the part arrive.

## UX flow (LabelDesk words)
1. **A rule fires** — the worker keeps the frames it already decoded for the pre-roll and collects the post-roll; the event row records the clip path and its length. Nothing on screen changes until a clip exists, and an encoder failure leaves the still in place. [error: `เขียนคลิปไม่สำเร็จ — ภาพนิ่งยังอยู่` on the event, never a lost event]
2. **Event detail → `คลิป`** (`/:ws/:project/streams/:sid`, rendered by T-681) — `[loading: กำลังประกอบคลิป 12 วินาที]` while the file is written, then a player with the trigger marked on the timeline. [empty: `คลิปนี้ยังไม่พร้อม`]
3. **A short pre-roll is stated, not hidden** — a stream that started three seconds before the trigger answers 409 with `ช่วงก่อนเหตุการณ์ไม่พอ — สตรีมเริ่มก่อนเหตุการณ์ 3 วินาที` and the shortfall in seconds, so nobody mistakes a truncated clip for the whole event.
4. **The file** — an MP4 under `DATA_DIR/clips/<project>/<event>.mp4`, served through `sign_path` like every snapshot, and deleted with its stream by the existing delete path (a held clip is T-681's copy).

## Backend changes
- Models/schema: `StreamEvent` gains `clip_path VARCHAR(1024) DEFAULT ''`, `clip_seconds FLOAT` (null), `clip_error VARCHAR(120) DEFAULT ''` as one `ADD COLUMN` block in `app/schema/streams.py` `STREAM_EVENTS`.
- Routers: `app/routers/clips.py` (new), prefix `/api/ws/{ws}/projects/{project}/streams`, `dependencies=[Depends(require_flag("task_evidence_clip"))]`; `GET /{sid}/events/{eid}/clip` → `{url, seconds, preroll_s, postroll_s}` (200) or 409 `{error, shortfall_s}` when the pre-roll is short, 404 when the event has no clip and no error, 404 for a foreign event. `event_out` gains `clip` (signed or null) and `clip_error`.
- Services/jobs: `app/streams/clip.py` (new) — `RollingBuffer(seconds=8, fps=2)` with `add(ts, jpeg)`, `snapshot(trigger_ts)` returning `(frames, shortfall_s)`, and `write_mp4(frames, path)` through `cv2.VideoWriter` (`mp4v`, 2 fps, the first frame's size). `app/streams/manager.py` keeps one buffer per worker: the grabber adds every published JPEG, `_record` takes the pre-roll snapshot, starts a small thread that keeps adding published frames for `CLIP_POST_S` (4 s) and writes the file once, then sets `clip_path` on the row it already wrote. No job kind, no queue: the recording is a side effect that must not delay capture (the `alert_bridge` pattern).
- Permissions + workspace isolation: the clip route resolves the event through its stream and the stream through `workspace_id` + `project_id`, so a foreign event is 404; the signed URL is short-lived and viewer-bound exactly like `frame`/`mjpeg`.
- Secrets/safefetch: none — frames come from the decoder we already own; no URL is fetched.
- OpenAPI: yes — the clip route and two `event_out` keys.

## Acceptance criteria
- [ ] A firing records an MP4 with the frames before and after the trigger, and the event carries its path and length.
- [ ] A stream younger than the pre-roll answers 409 with the shortfall in seconds instead of serving a truncated clip.
- [ ] Capturing and analysing are not slowed by the recording: the file is written on its own thread after the event row is committed.
- [ ] Empty, loading and error states above all render — a missing clip is `คลิปนี้ยังไม่พร้อม`, never a broken `<video>`.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no buffer is kept, no file is written, and the event payload is exactly today's.

## Notes for the implementer
Eight seconds of pre-roll and four of post-roll at 2 fps is the shipped default: a twelve-second clip is what an audit asks for and a longer buffer is RAM per camera that a 40-camera box cannot pay. Encode at the analysed sample rate, not the capture rate — the frames we hold are the ones the model saw, which is also what makes the trigger marker honest. Copy: `streams.clip.assembling`=`กำลังประกอบคลิป {n} วินาที`, `streams.clip.shortfall`=`ช่วงก่อนเหตุการณ์ไม่พอ — สตรีมเริ่มก่อนเหตุการณ์ {n} วินาที`, `streams.clip.none`=`คลิปนี้ยังไม่พร้อม`, `streams.clip.download`=`ดาวน์โหลด MP4`.
