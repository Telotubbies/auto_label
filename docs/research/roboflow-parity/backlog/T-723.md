## User story
As a merchandiser, I want a bay drawn once and every later capture reduced to a short list — row 3, four facings missing — so that I check the shelf against the plan instead of photographing a shelf at somebody.

## UX flow (LabelDesk words)
1. **`ตรวจเชลฟ์`** (`/:ws/:project/ops/shelf`) — a bay is chosen from the project's cameras; its layout is drawn once as shelf rows with slot boundaries on the still, and reused on every capture. [empty: `ยังไม่ได้วาดชั้นวางสำหรับกล้องนี้` with the draw action] [loading: `กำลังโหลดแผนผังชั้นวาง`] [error: `โหลดแผนผังไม่สำเร็จ — ลองอีกครั้ง`]
2. **Audit a capture** — picking a stored image or the camera's last frame returns each slot as `เต็ม`, `ว่าง`, `สินค้าผิด` or `ถูกบัง`, with a confidence, drawn as a grid over the picture. [empty: a bay that matches its plan reads `ช่องวางตรงตามแผนผัง` and produces no gaps] [error: `เส้นชั้นวางไม่ตรงกับภาพนี้ — ตั้งแนวใหม่` when the layout matches fewer than half the slots]
3. **The gap list** — one row per empty or wrong slot: `แถว 3 · ช่อง 4 · ขาด 4 หน้า`, assignable to a person, with the capture thumbnail. [error: `มอบหมายไม่สำเร็จ — ลองอีกครั้ง`]
4. **A re-capture closes it** — a later audit where the slot is `เต็ม` closes the gap and stamps the closing capture. [empty: `ยังไม่พบช่องว่าง — เชลฟ์ตรงตามแผนผัง`]
5. **A camera that moved** — the layout is refused rather than applied, and the bays list marks it `ต้องตั้งแนวใหม่`.

## Backend changes
- Models/schema: `Stream` gains `planogram JSON` (default `{}`) — one `STREAMS` entry in `app/schema/streams.py`; `app/models/shelf.py` (new) — `ShelfGap(id, workspace_id, project_id, stream_id, row, slot, status, assigned_to, capture_id, opened_at, closed_at)` with `Index(stream_id, status)`, registered in `models/__init__.py` (`create_all` makes the table).
- Routers: `app/routers/shelf.py` (new), prefix `/api/ws/{ws}/projects/{project}/shelf`, `dependencies=[Depends(require_flag("task_shelf_audit"))]`; `GET "/{stream_id}/planogram"`, `PUT "/{stream_id}/planogram"` (`{rows: [{y, class, slots: [[x0,x1]]}]}`, ≤ 12 rows and ≤ 40 slots, normalised 0–1), `POST "/{stream_id}/audit"` `{image_id?}` → `{slots: [{row, slot, status, confidence, box}], gaps: [...], matched}` , `GET "/{stream_id}/gaps?status="`, `POST "/gaps/{id}/assign"` `{user_id}`. 400 for a layout that is not normalised or too large, 404 for a foreign stream or image, 409 for an audit while a gap is already being closed by the same capture.
- Services/jobs: `app/services/shelf.py` (new) — `slot_status(detections, slot_box, expected_class) -> (status, confidence)` pure, `attribute(detections, planogram) -> list[dict]`, `review(db, stream, image, detections)` opening and closing `ShelfGap` rows, `detect(stream, image)` calling `adapters.resolve` + one inference exactly as `services/batch_inference.py::_predict` does. No job; the audit runs in the request over one stored frame.
- Permissions + workspace isolation: `project.streams` to read and audit, `c.perm("project.settings")` to save a layout; every stream, image and gap is resolved through `workspace_id` + `project_id`, so a foreign id is 404.
- Secrets/safefetch: none — the image is one we already store and no URL is fetched.
- OpenAPI: yes — six routes and the planogram schema.

## Tests to write first
pytest — `apps/backend/tests/test_shelf_audit.py`:
- `test_a_slot_with_a_box_inside_it_is_filled` — a detection whose centre is inside slot `[0.1,0.3]` → `status == "filled"` and the confidence is the detection's score.
- `test_an_empty_and_a_wrong_class_slot_differ` — no detection → `empty`; a box of another class → `wrong`; a box taller than the row (a tote) → `blocked`.
- `test_an_audit_opens_one_gap_per_empty_or_wrong_slot` — two empty slots → two `ShelfGap` rows with `status: "open"`.
- `test_a_later_capture_closes_a_gap` — a second audit where the slot is filled → the gap is `closed` with `capture_id` set and `closed_at`.
- `test_a_layout_that_does_not_match_is_refused` — fewer than half the slots matched → 409 with the re-align sentence and no gaps written.
- `test_a_layout_outside_zero_to_one_is_400` — a slot at `x1: 1.4` and a 13-row layout are both 400.
- `test_the_routes_are_hidden_while_the_flag_is_off` — 404 for all six.
- `test_a_stream_or_gap_from_another_workspace_is_404` — both, 404.
node — `apps/frontend/tests/shelf-view.test.mjs`:
- `test_every_slot_status_has_a_tone_and_a_label` — `slotTone('blocked')` is the warning tone and `ถูกบัง`; all four statuses are covered.
- `test_a_gap_line_names_row_slot_and_count` — `gapLine({row:3, slot:4, facing:4})` is `แถว 3 · ช่อง 4 · ขาด 4 หน้า`.
- `test_a_layout_is_valid_only_when_normalised_and_bounded` — a row at `y: 1.2`, a slot `[0.5,0.4]` and 13 rows are each invalid.
- `test_a_low_coverage_warns_before_the_server_refuses` — `coverageWarning({matched: 0.3, total: 10})` returns the re-align sentence.

## Acceptance criteria
- [ ] A bay's layout is drawn once, stored on the camera and reused on every capture.
- [ ] An audit returns four slot states with a grid over the still, and a matching bay produces no gaps.
- [ ] A gap opens, is assignable, and closes when a later capture shows the slot filled.
- [ ] Empty, loading and error states above all render — a matching bay reports so instead of an empty table.
- [ ] Workspace A cannot see or change workspace B's layout, image or gap (404, not 403).
- [ ] Flag off ⇒ no route, no nav item, no `planogram` read, and the stream page is unchanged.

## Notes for the implementer
Owner-hold: BEYOND §4 names this as a non-goal; do not schedule until the owner overrules it. Ship it behind `task_shelf_audit` and do not import a planogram format: the layout is `{rows: [{y, class, slots}]}` in normalised coordinates, the same shape `ZoneEditor` already draws polygons in, and a retailer's shelf plan stays a spreadsheet they translate by hand. Four states only — `filled`, `empty`, `wrong`, `blocked` — and the count in a gap line is facings, never a percentage. Copy: `shelf.title`=`ตรวจเชลฟ์`, `shelf.emptyLayout`=`ยังไม่ได้วาดชั้นวางสำหรับกล้องนี้`, `shelf.empty`=`ยังไม่พบช่องว่าง — เชลฟ์ตรงตามแผนผัง`, `shelf.align`=`เส้นชั้นวางไม่ตรงกับภาพนี้ — ตั้งแนวใหม่`, `shelf.filled`=`เต็ม`, `shelf.emptySlot`=`ว่าง`, `shelf.wrong`=`สินค้าผิด`, `shelf.blocked`=`ถูกบัง`, `shelf.gap`=`แถว {row} · ช่อง {slot} · ขาด {n} หน้า`, `shelf.assign`=`มอบหมาย`, `shelf.assigned`=`มอบหมายไม่สำเร็จ — ลองอีกครั้ง`, `shelf.loading`=`กำลังโหลดแผนผังชั้นวาง`, `shelf.error`=`โหลดแผนผังไม่สำเร็จ — ลองอีกครั้ง`, `shelf.stale`=`ต้องตั้งแนวใหม่`.
