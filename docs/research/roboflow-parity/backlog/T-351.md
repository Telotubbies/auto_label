## User story
As a project manager, I want to set the caps, the cadence and the reviewer in one place and see what is waiting, so that collected images become labelled images instead of a growing folder.

## UX flow (LabelDesk words)
1. **Project settings → Active learning** — the existing card keeps its threshold and sample controls and gains the caps, the cadence select and a `Review` block: "Batches ready: 3 · 74 images", a `Review images` button that opens the annotate board filtered to the active-learning batch, and a sorted list of the last five batches (status, images, date). [empty: nothing collected yet → "Nothing collected yet. Images arrive here when a request matches the rule."] [loading: one skeleton row per expected batch] [error: a save that the server refuses → the field keeps the user's value and the message names the field]
2. **Reviewer assignment** — pick project members, images per person and optional instructions; the assignment uses the board's existing assign sheet (area 3's `T-143`), so no second assignment path is written. Reassignment is the same sheet reopened.
3. **Ordering** — the batch list sorts by date (newest first), size or progress; the two extra sorts are a select, not three tables.
4. **After saving** — one line confirms what changed: "Saved · daily bundle · 25 images a day max."

## Backend changes
None beyond T-350: the form reads `GET /active-learning` (policy, `batches`, usage) and writes `PUT /active-learning/settings`. Reviewer assignment reuses the existing board assignment route.

## Notes for the implementer
`Review images` is a link to the board with `?batch=<id>`; do not build a second review surface. The form saves only changed fields, so a rejected cap cannot silently reset the threshold beside it.
