## User story
As a user clicking any project card, batch row or breadcrumb, I want the link to go straight to the new stage URL so that no click costs a redirect hop and no screen keeps a hand-built path.

## UX flow (LabelDesk words)
1. **Home → project card** — the card links to `/w/p/:project` in one hop. [empty: the "no projects yet" state keeps its create action]
2. **Stage rail, breadcrumb, stage card, batch row, saved-view link, editor back-link** — every link is built by `projectPath()`, so a route prefix change is one file.
3. **Editor → back** — returns to `/w/p/:project/annotate` in review mode and `/w/p/:project/dataset` otherwise, as today, with the query the editor was opened with.
4. **A stale link in a support email** — still works, because T-474's legacy branch redirects it.

## Notes for the implementer
Relative strings (`../browse`) are the trap: they look correct while the route depth is unchanged and break silently the moment a stage gains a tab segment. Convert every one to `projectPath(ws, project, 'dataset')` — absolute, one builder, testable.
