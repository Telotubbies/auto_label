## User story
As the design and quality leads, I want one audit of everything a buyer meets before a project — landing,
auth, first run, workspace home and project overview — scored against the heuristics, axe and three
breakpoints, so that "the first hour" has evidence rather than opinion.

## UX flow (LabelDesk words)
1. **Landing** (`/`) — the claim, the one primary and the proof; no marketing word the product cannot back.
2. **Auth** (`/login`, `/signup`, `/forgot`, `/reset/:token`, `/verify/:token`) — one primary per screen,
   inline errors, no dead end. [error: wrong password, duplicate email, unknown reset token].
3. **First run** (`/:ws` on an empty workspace) — the designed empty state with one next step.
4. **Workspace home** (`/:ws`) — the "needs you" queue first, project cards with five stage counts.
5. **Project overview** (`/:ws/p/:project`) — the pipeline board, the dynamic primary, the blocker list.
6. **Tour** — dismissible, anchored away from its target, and resumable from help.

## Acceptance criteria
- [ ] Every route above is captured at 375/768/1440 in light and dark, with the screenshots named in the
      report.
- [ ] axe: 0 critical/serious; every moderate/minor is listed with the element and the rule.
- [ ] The 10 Nielsen heuristics are scored 1–5 per screen with one evidence line each; no score < 3.
- [ ] The applicable `uxui-law` laws are pass/fail; each failure names the law.
- [ ] Findings are S1–S4 in the program's format; every S1/S2 names the fix area and a proposed card title.
- [ ] The tour never covers its target and never scrolls the page on step 1 (re-check A18/A19).
- [ ] The first-run empty state, the empty queue and the no-project state differ and each has one action.
- [ ] Copy: every string is from the shipped catalogue; no price, certification or unbacked claim.
- [ ] Three personas (P1, P3, P4) walk the area; each SUS-8 score is recorded.
- [ ] Workspace isolation is not re-tested here; the audit stays inside the seeded workspace.
