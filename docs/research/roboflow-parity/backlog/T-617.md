## User story
As a project owner, I want one screen that says which class is weak and which two labels people keep swapping, with every number one click from its images, so that a go/no-go on the dataset takes a minute.

## UX flow (LabelDesk words)
1. **QA → Quality** — a window switch `7 / 30 / 90 days` and three sections: `Agreement by class`, `Most swapped pairs`, `Reviewers agree with each other`. [loading: three skeleton blocks; the window switch keeps the previous numbers dimmed] [empty: "No consensus job yet — create one in Consensus to measure agreement." with a button to that tab]
2. **Agreement by class** — one row per class, lowest agreement first: class dot from `classColor`, name, a `bg-primary` bar in the cell (the pattern `ReviewQueue` already uses), `Agreement 72 %`, and the counts behind it. Clicking a row opens `/:ws/:project/browse?class=<class_id>`.
3. **Most swapped pairs** — a table `A → B · 12 times`; clicking a pair opens `browse?class=<a's id>` so the images are one click away. [empty: "Nobody swapped a class in this window."]
4. **Reviewers agree with each other** — a square grid, row and column headers by name, cells showing the percentage and coloured on three bands (`bg-success/15`, `bg-warning/15`, `bg-destructive/15`). Clicking a cell opens the review queue, which is where those disagreements are adjudicated.
5. **A window with no drafts** — "Nothing in this window." and the window switch stays usable. [error: "These numbers did not load." + `Retry`]

## Acceptance criteria
- [ ] The Quality tab lists every class lowest-agreement first and each row opens Browse filtered by that class.
- [ ] The pairs table names both classes and how many times they were swapped, and its rows open Browse.
- [ ] The matrix is square, symmetric and readable at three bands with the percentage in the cell.
- [ ] Empty, loading and error states above all render: no-job empty with the next action, skeleton blocks, and the load error with `Retry`.

## Notes for the implementer
Three sections, no charts library: a bar inside a table cell and a CSS grid are enough and keep the screen readable at 11–12 px. Use the darker text role for cell labels — the WCAG AA finding in `VISUAL-OVERRIDE.md` applies to this screen.
