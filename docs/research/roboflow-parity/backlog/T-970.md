## User story
As an ML engineer, I want the training screen to tell me everything that is wrong before a job is
queued, so that I do not burn a GPU hour and a credit block on a missing class or an empty split.

## UX flow (LabelDesk words)
1. **Project → Train → "Check before you spend"** — one button next to Run; it runs the checks and
   prints a list, never creates a job row and never charges. [empty: nothing to check — the button is
   disabled with the reason beside it ("pick a dataset version first")] [loading: "checking dataset …"
   with a spinner, one line per check as it settles] [error: a list of blocking problems, each linking
   to the screen that fixes it ("3 classes have no images → Classes & Tags")].
2. **Result** — a green tick line ("ready: 412 images, 6 classes, train 330 / valid 82") or the
   blocking list; the Run button enables only on a pass.
3. **CLI** — `labeldesk train --dry-run --spec labeldesk.yaml` prints the same plan and exits 0/1.

## Backend changes
- Models/schema: none.
- Routers: `routers/training.py` gains `POST /api/ws/{ws}/projects/{project}/train/preflight`
  returning `{ok: bool, checks: [{id, ok, message, fix_path?}], plan: {...}}`; the existing train
  handler calls the same service and refuses to insert a `Job` when `ok` is false.
- Services/jobs: `app/services/train_preflight.py` (new) — `check(ctx, project, body) -> Report` with
  checks: dataset version exists and is not archived, split counts non-zero, every class has ≥ 1
  training image, parameter set matches the spec, GPU/worker reachable (`app/gpu.py` lease if one
  exists), credits left (`deps.credits_left`). No writes.
- Permissions + workspace isolation: `project.train`; project by `project_ctx`; 404 for a foreign slug.
- Secrets/safefetch: none.
- OpenAPI: yes.

## Frontend changes
- Route: none (inside `/:ws/p/:project/train`).
- Nav entry: none.

## Acceptance criteria
- [ ] Preflight never creates a job row and never moves the credit counter.
- [ ] Every blocking check names the problem and links to the screen that fixes it.
- [ ] Run stays disabled until a preflight passes, and the server refuses the same case.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
