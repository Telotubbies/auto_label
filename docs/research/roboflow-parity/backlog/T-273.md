## User story
As someone who knows where the model will run, I want to pick the target — phone, edge box, cloud GPU — instead of an architecture name, so that the search is expressed in the language I actually have.

## UX flow (LabelDesk words)
1. **Train → Recipe → Search → Target** — three cards, one line each: *Fastest* ("lowest-latency candidates, for a CPU box or an edge device"), *Balanced* ("a wide range, the safe default"), *Most accurate* ("the heaviest candidates, for a cloud GPU"). One is preselected (Balanced).
2. **Instance segmentation** — the step is skipped with a note "Segmentation searches run the balanced range." and Balanced is used.
3. **Too few validation images** — the step renders but Start is disabled with "Search needs at least 15 validation images — this version has 6." and the primary names the fix (*Make a new version*).
4. **Next** — the summary shows the band's candidate count and total credits (T-269's plan), so the choice is priced the moment it is made. [loading: the plan line shimmers while quoting] [error: "This target cannot be planned" + reason]
5. **Remembered per project** — the chosen band is remembered on the project (`settings.train_search_band`) so a second search does not re-ask.

## Backend changes
- Models/schema: none new — the band rides in `Project.settings.train_search_band` (existing JSON column).
- Routers: `POST {P}/train` search branch already takes `search.band` (T-269); this card adds **persisting** it to `Project.settings` after a successful enqueue (one line, `project.settings = {**(p.settings or {}), "train_search_band": band}`), and `GET {P}/train/options` returns `search_defaults: {band, candidates}` so the form preselects it.
- Services/jobs: `services/train_preflight.py` — `small_valid_split` becomes a **blocker** (not a warning) when `engine == "search"`; the message keeps the count. This is the only backend rule this card changes.
- Permissions + workspace isolation: unchanged.
- Secrets/safefetch: none.
- OpenAPI: yes — `search_defaults` (regenerate both files).

## Acceptance criteria
- [ ] Three target cards, one preselected, each stating where the result is meant to run.
- [ ] Instance segmentation skips the step and uses the balanced range.
- [ ] A search with fewer than 15 validation images cannot start and the sentence carries the count.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no step, no persisted band, no search.

## Notes for the implementer
The band is a *latency* band, never a price band: two bands may cost the same. Store one value per project; do not version it or expose it in the export.
