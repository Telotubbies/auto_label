## User story
As a vendor manager, I want a scorecard with per-class results and the worst images, so that a hiring decision is evidence a customer can read instead of my opinion.

## UX flow (LabelDesk words)
1. **QA → Calibration** — a table of trials: person, status, score, pass mark, retry date, and `Open scorecard`. [empty: "No trials yet — score someone before they join the live queue."] [loading: three skeleton rows] [error: "These trials did not load." + `Retry`]
2. **`New trial`** — person `Select` (workspace members who can label), reference set (`Answer-key pool` / `An approved version`), image count, pass mark slider, and the sentence "The person sees normal work; only this page sees the answers." [error: "No reference set yet — add answer-key images first." or "This person already has an open trial."]
3. **`Open scorecard`** — a drawer with the overall score against the pass mark, a per-class table, and `Worst three` as thumbnails with their scores and the class that was missed. [loading: the drawer's spinner]
4. **`Finish trial`** — confirms "Scoring 12 images against the answer key", then shows `Passed — project access granted` or `Failed — retry after 2 Dec 2026`. [error: "The trial is already complete."]
5. **A person mid-trial** — their row shows `Open · 5 of 12 submitted` and `Finish trial` stays disabled until at least one image is submitted.

## Acceptance criteria

- [ ] `New trial` creates one for a chosen person and refuses an empty reference set or a second open trial with the API sentence.
- [ ] The scorecard shows the overall score against the pass mark, a per-class table and the worst three images.
- [ ] Empty, loading and error states above all render: the no-trials line, skeleton rows, the drawer spinner, and the 400/409 sentences.
- [ ] Workspace A cannot see workspace B's trials: the tab only calls this project's route.
- [ ] Flag off ⇒ no Calibration tab and no request.

## Notes for the implementer
Never show the answer key in the scorecard to anyone but a reviewer, and never show it in the labeler's editor at all — the worst-three thumbnails may carry the missed class name but not the key's boxes. "Calibration" is the LabelDesk word for this screen; the queue banner the labeler sees simply says `Trial`.
