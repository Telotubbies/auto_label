## User story
As a plant manager preparing a weekly review, I want to type "how many images on the night shift have no helmet" and get the number together with the filter that produced it, so that a wrong answer is debuggable and a right one becomes a view I reuse.

## UX flow (LabelDesk words)
1. **Dataset search box → Ask** (`/:ws/:project/browse`) — a mode toggle beside the existing search; the class list, splits, statuses and tags are the vocabulary. [empty: an empty box keeps the answer panel closed]
2. **Asking** — `[loading: "Reading the dataset schema…"]`, then an answer card: the number, the equivalent chips ("class: Helmet · status: review · tag: night"), and "showing 412 images". [error: "that needs the image content, not the labels — run a question set instead" with a link to T-648's panel]
3. **A structural question it cannot map** — `[error: "I can only answer about classes, splits, statuses, tags and counts; try naming one of those"]` and the raw chips it did understand, so the user can finish it by hand.
4. **Save as view** — writes the chips into the URL exactly as the chip editor would, so the saved link and a manual filter are one view.
5. **Nothing executes on its own** — the answer is a count over the current project; no write, no job, no credit.
6. **Flag off** — no Ask mode and no endpoint.

## Backend changes
- Models/schema: none.
- Routers: `POST /api/ws/{ws}/projects/{project}/insights/ask` in the existing `routers/insights.py` — body `{"question": str}` (≤ 300 chars) → `{"answer": int|float, "measure": "images"|"annotations", "chips": {"class_id"?, "split"?, "status"?, "tag"?, "annotated"?, "batch_id"?}, "matched": bool, "visual": bool}`; 422 for an empty question, 409 when the egress gate refuses, 400 when the question needs image content (`visual: true` with the hand-off sentence), 403 for a caller without `project.read`.
- Services/jobs: `services/ask.py` (new) — `VOCABULARY` (the allow-listed parameters the image list already accepts), `parse(vlm, question, classes, tags, batches)` asking for `{"measure", "chips", "visual"}` against a JSON schema, `validate(chips, project)` dropping anything not in the vocabulary and reporting `matched`, `count(db, project, chips, measure)` running one scoped select; `adapters/vlm_ad.py` gains `ask_json(text, schema)` for a text-only constrained call on the same endpoint.
- Permissions + workspace isolation: `project.read` to ask; the count query is built from `project.id` and `_visible()`-equivalent scoping, so a labeler's count matches what they can open; a class id or tag that is not in this project makes `matched: false` rather than running.
- Secrets/safefetch: `services/secretbox.py` holds a hosted endpoint token if one is stored; the question text leaves the deployment only through `ai_egress.require` (T-640), and no image is ever sent by this route.
- OpenAPI: yes — regenerate (`python tools/export_openapi.py`, `npm run gen:api-types`).

## Acceptance criteria
- [ ] A structural question returns a number with the equivalent chips, and the count equals what those chips produce in the grid.
- [ ] A visual question is refused with the question-set hand-off instead of a guessed number.
- [ ] Unrecognised or foreign vocabulary yields `matched: false` and no count from another project.
- [ ] Empty, loading and error states above all render, including an empty box and an unreachable model.
- [ ] Workspace A cannot count workspace B's data (every query is project-scoped; a foreign class id never matches).
- [ ] Flag off ⇒ no Ask mode, no route, and the search box behaves exactly as today.

## Notes for the implementer
The chips are the answer's proof: always show them, and make "Save as view" write the same URL the chip editor writes. The model never sees an image here — if the question cannot be expressed with classes, splits, statuses, tags and counts, say so and hand it to the question set. Allow-list the parameters from `GET .../images`; a new filter added later must be added to `VOCABULARY` deliberately.
