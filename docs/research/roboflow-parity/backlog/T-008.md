## User story
As the merge captain, I want one browser test of the core loop so that a merge that breaks a real user
path fails the gate even when unit tests pass.

## UX flow (LabelDesk words)
1. **Sign in** — open `/`, sign in as `demo@labeldesk.dev` / `demo1234`, land on the workspace home.
   [error: wrong password shows the sign-in error and stays on the page]
2. **Open project** — open the seeded PPE project overview.
3. **Upload** — upload one small fixture image; it appears in the dataset grid.
4. **Annotate** — open that image in the editor, draw one box, pick a class, save; reload keeps the box.
5. **Version** — open the versions page and create a version; it appears in the list.
6. **Train entry** — open the train page; the start form renders (do not start a real run).
7. **Deploy page** — open the deploy page; it renders without a console error.
