## User story
As a workspace admin, I want a catalogue of ready models with size, quantisation variants, licence and
gating, and a plan that says whether one fits this host, so that I download once and legally.

## UX flow (LabelDesk words)
The screen is T-1012; this card supplies the rows and the plan.
1. **Model row** — name, family, parameter count, variants as chips (`Q8_0`, `Q4_K_M`, `AWQ`, `GPTQ`,
   `FP8`, `BF16`), download size, licence badge, `Gated` badge, engine target, estimated VRAM on the
   host.
2. **Plan sheet** — the file list with bytes, the total, disk before/after, the gate and the token state
   ("This host has a Hugging Face token" / "No token on this host — this model is gated"), and any block.
3. **Gated without a token** — the download action is disabled with "This model needs a Hugging Face
   token on the worker. Set `HF_TOKEN` there, not here."
4. **Non-commercial licence** — a `Non-commercial` badge (Mask2Former-style) that survives into the
   confirm sheet; the row is not hidden.
5. **Custom repository** — not offered in v1; the empty state says "Only catalogue models can be
   downloaded." [empty: no model for the filters].

## Backend changes
- Models/schema: none.
- Routers: `GET /models?host=` → catalogue rows joined with installed state, `fits` verdict (T-1004
  helper) and `blocked` reasons; `POST /models/plan` `{host, id, variant}` → `{plan_id, model, variant,
  files, total_bytes, disk_free_gb, disk_after_gb, gate, token_present, blocked, warnings}`.
- Services/jobs: `apps/backend/app/services/inference_models.py` (new).
  - `MODELS: list[dict]` — 5 curated rows, each with `id, name, family, repo, revision, params_b,
    layers, kv_heads, head_dim, context_max, licence{name,url,gated,non_commercial}, engine,
    safetensors_only, variants[{id, quant, format, engine, bytes, files:[{path, bytes}]}],
    source_url, checked_on`.
    Starting set (pin the revision and re-check every byte count when the card is implemented):
    | id | repo | licence | gate | variants |
    | --- | --- | --- | --- | --- |
    | `qwen2.5-vl-7b` | `Qwen/Qwen2.5-VL-7B-Instruct` | Apache-2.0 | no | BF16, AWQ, GPTQ |
    | `qwen3-vl-8b` | `Qwen/Qwen3-VL-8B-Instruct` | Apache-2.0 | no | BF16, FP8, AWQ |
    | `llama-3.1-8b` | `meta-llama/Llama-3.1-8B-Instruct` | Llama 3.1 Community | **yes** | BF16, AWQ, GPTQ, GGUF Q8/Q4 |
    | `gemma-3-27b` | `google/gemma-3-27b-it` | Gemma Terms | **yes** | BF16, AWQ, GGUF Q4 |
    | `qwen2.5-7b-gguf` | `Qwen/Qwen2.5-7B-Instruct-GGUF` | Apache-2.0 | no | GGUF Q8_0, Q4_K_M |
    Every row names the engine(s) its variants target (`vllm`, `sglang`, `llamacpp`) and `safetensors_only`
    is `true` unless the variant is GGUF.
  - `public_models(host_inventory)` — strips `files` (the plan returns them), adds `installed`,
    `fits`, `blocked`.
  - `plan(host, id, variant)` — validates the repo id against `^[A-Za-z0-9][A-Za-z0-9._-]*/[A-Za-z0-9]
    [A-Za-z0-9._-]*$`, refuses `.bin`/pickle files (`safetensors_only`), sums bytes, compares against
    free disk × 0.8, and checks `HF_TOKEN` presence for a gated row.
  - `variant_bytes` are **pinned estimates** with `checked_on`; the worker's live metadata wins at
    download time and the log states any difference.
- Permissions + workspace isolation: admin only; flag off 404; `host` from the deployment's host list.
- Secrets/safefetch: no fetch in the API; `token_present` is the boolean from inventory.
- OpenAPI: yes.

## Tests to write first
pytest — `apps/backend/tests/test_inference_models.py`:
- `test_every_model_has_a_licence_url_a_pin_and_a_checked_date` — all five rows; `revision` is a hex
  commit, not `main`; `checked_on` parses as a date.
- `test_every_variant_lists_files_and_bytes` — non-empty files, each `bytes > 0`, total equals the sum.
- `test_licences_are_honest` — Llama and Gemma rows are `gated: true`; no row claims Apache-2.0 for a
  GGUF repack of a gated model; Ultralytics-style AGPL is not silently absent (this catalogue has no
  AGPL row, and the test asserts any future AGPL row is flagged).
- `test_repo_ids_reject_traversal_and_urls` — `../x`, `http://evil/x`, `a/b/c`, an empty string → 400.
- `test_pickle_files_are_refused` — a variant containing `pytorch_model.bin` → blocked with a reason.
- `test_gated_model_without_a_token_is_blocked` — inventory `hf_token: false` → `blocked` naming the
  token; with `true` → not blocked.
- `test_fit_uses_the_estimator` — a 27B BF16 on a 24 GB host → `fits: false` with the shortfall; AWQ →
  fits.
- `test_disk_check_uses_a_20_percent_margin` — 9.4 GB needed, 10 GB free → blocked; 12 GB free → ok.
- `test_public_models_hide_files` — the list response contains no file paths.

node — `apps/frontend/tests/inference-hub.test.mjs`: `none: no frontend surface`.

## Acceptance criteria
- [ ] Five models, each with licence name + URL, gating, exact revision, variants and bytes.
- [ ] A gated model without a worker token is blocked with a sentence that names `HF_TOKEN`.
- [ ] A non-commercial licence is visible in the row and the plan.
- [ ] Any repo id that is not `owner/name` is refused; pickle files are not offered.
- [ ] Fit and disk checks come from T-1004 and a 20% margin, not a second implementation.
- [ ] Admin-only; flag off 404.

## Notes for the implementer
GGUF is a redistribution by the model owner; the licence of the **row** is the licence of the weights,
not of llama.cpp. If a gated model's GGUF repack is published by a third party, do not add it in v1 —
the licence chain is not ours to assert. Record `checked_on` and re-verify bytes and revisions when the
card is implemented.
