## User story
As a site engineer whose floor calls one class "helmet", "safety helmet" and "หมวกนิรภัย" while a bike helmet must never match it, I want those names and the forbidden ones stored on the class, so that every auto-label run uses the site's own vocabulary without retyping it.

## UX flow (LabelDesk words)
1. **Auto label → Class prompts** (`/:ws/:project/annotate`, the dialog T-641 draws) — each class row expands into synonyms, exclusions and a one-line note; this card supplies the data behind those chips. [empty: a class with no pack returns `prompt: null` and the row shows "Uses the class name only"] [loading: the class list paints its rows before the packs arrive, so no chip count flickers] [error: a rejected pack is a 400 naming the field, never a silently dropped chip]
2. **Any auto-label run** — prompts for a SAM text model are the class name followed by its synonyms; an exclusion list adds one negative text pass per image and boxes overlapping a forbidden mask by IoU ≥ 0.5 are dropped and counted. [error: a worker without SAM keeps today's result and the excluded count reads 0]
3. **The job report** — carries `excluded` beside `annotations`, so the preview and the run report the same number for the same settings.
4. **A hosted model endpoint with no workspace consent** — the run stops with "image analysis on a hosted model is off for this workspace" (409) instead of sending the first crop.

## Backend changes
- Models/schema: `classes.prompt` JSON, nullable — `{"synonyms": [str], "exclusions": [str], "note": str}`; one `CLASSES["prompt"] = "JSON"` line in `app/schema/dataset.py`, no backfill (NULL = today's behaviour). `workspaces.ai_egress` BOOLEAN NOT NULL DEFAULT FALSE, one `WORKSPACES["ai_egress"] = "BOOLEAN DEFAULT FALSE"` line in `app/schema/identity.py`, plus the two column definitions on `LabelClass` and `Workspace`.
- Routers: `ClassIn` gains `prompt: dict | None`; `POST`/`PATCH /api/ws/{ws}/projects/{project}/classes[/{cid}]` validate and store it, `GET .../classes` (`classes_out`) returns it. 400 for a phrase over 60 characters, more than 8 synonyms or 8 exclusions, or a non-string entry; 409 when the phrase is already a synonym or exclusion on another class of the project, naming that class.
- Services/jobs: `services/prompt_pack.py` (new) — `clean_pack(raw)`, `phrases(cls)` (`[name, *synonyms]`), `exclusion_phrases(classes)`, `collision(db, project, cid, phrase)`; `services/ai_egress.py` (new) — `endpoint_is_local(url)`, `allowed(db, ws)`, `require(db, ws)` raising 409. `adapters/refine.py`: build the per-class prompt list from the pack, run one negative text pass per image when exclusions exist, drop overlapping boxes, and report counts through a new optional `stats: dict` argument of `label_image`.
- Permissions + workspace isolation: `project.classes` to write a pack, `project.read` to read it; a class id belonging to another project or workspace is 404 (the existing `edit_class` check), and `require()` reads only the caller's workspace row.
- Secrets/safefetch: `services/secretbox.py` — a hosted endpoint token, when an operator stores one, is encrypted through `secretbox.encrypt`/`decrypt`; this card adds no key and no image or prompt leaves the deployment unless `workspaces.ai_egress` is true and a workspace admin turned it on.
- OpenAPI: yes — regenerate (`python tools/export_openapi.py`, `npm run gen:api-types`).

## Acceptance criteria
- [ ] A class stores synonyms and exclusions and every later auto-label run uses them; a class with no pack behaves exactly as today.
- [ ] A phrase that is a synonym on one class and an exclusion on another is refused with both class names in the message.
- [ ] Excluded boxes are dropped and counted in the preview and the job report; a trained detector without text prompts reports `excluded: 0` rather than pretending to filter.
- [ ] Empty, loading and error states above all render: `prompt: null` is a real empty value, a bad pack is a 400 naming the field, an unreachable model is the existing readable 503.
- [ ] Workspace A cannot see or change workspace B's pack (404, not 403, for a cross-workspace class id).
- [ ] Flag off ⇒ the pack cannot be written or read back and auto-label output is unchanged.
- [ ] Without `workspaces.ai_egress` a non-loopback model endpoint is refused with 409 before any image or prompt is sent.

## Notes for the implementer
Exclusion matching is IoU ≥ 0.5 against the negative mask, counted once per dropped box; the negative pass runs only for `family == "sam3"`, so a trained YOLO reports `excluded: 0`. Caps are 8 synonyms and 8 exclusions per class, 60 characters each. `ai_egress.require` treats `localhost`, `127.0.0.0/8`, `::1` and RFC 1918 addresses as inside the deployment — everything else needs the workspace switch, which is the only place this decision is made.
