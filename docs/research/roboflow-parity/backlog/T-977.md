## User story
As the operator of a self-hosted deployment, I want the API to accept only the host names I published,
so that a DNS-rebinding page cannot drive a logged-in browser against our API.

## UX flow (LabelDesk words)
1. **Deploy** — the operator sets `LD_ALLOWED_HOSTS` (comma list, `*` wildcard for subdomains) and
   `LD_PUBLIC_URL`. A request whose `Host` is not on the list gets a plain 400. [empty: not configured —
   the default list is `localhost`, `127.0.0.1` and the origin of `LD_PUBLIC_URL`, never `*`] [loading:
   n/a] [error: the body reads "this host is not allowed to talk to this server"; the configured list
   appears in the server log, never in the response].
2. **Settings → Workspace → Security** — read-only lines: allowed hosts, whether TLS terminates in
   front (`X-Forwarded-Proto` trusted or not), and the CORS origins in force. [empty: n/a] [loading:
   skeleton] [error: 403 for a non-admin, the tab is hidden by role].
3. **Behind a proxy** — with `LD_TRUST_PROXY=1`, `X-Forwarded-Proto: https` makes signed links and
   redirects use `https`; without it the header is ignored (the safer default).

## Backend changes
- Models/schema: none.
- Routers: `app/main.py` adds `TrustedHostMiddleware` (allowed hosts from config) and a
  `ForwardedProto` middleware that rewrites `request.scope["scheme"]` only when `LD_TRUST_PROXY` is on;
  `routers/workspaces.py` gains `GET /security` returning `{allowed_hosts, trust_proxy, cors_origins,
  tls: bool}` read from config (no secrets).
- Services/jobs: `app/config.py` gains `ALLOWED_HOSTS` (default `["localhost", "127.0.0.1"]` plus the
  host of `PUBLIC_URL`) and `TRUST_PROXY` (default false); `app/services/runtime_state.py` gains
  `network_facts() -> dict` so the settings route and the doctor (T-986) read one source.
- Permissions + workspace isolation: `workspace.update` to read the Security facts (owner/admin);
  the middleware is global and names no workspace.
- Secrets/safefetch: none — no header value is echoed to a client.
- OpenAPI: yes (the new route).

## Acceptance criteria
- [ ] A request under an unlisted host is refused with a plain 400 and no configuration echo.
- [ ] The default configuration is localhost-only, never `*`.
- [ ] A spoofed `X-Forwarded-Proto` changes nothing unless the operator opted in.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
