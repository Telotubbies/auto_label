## User story
As a maintainer, I want the canvas transform rules for polygons, rotated boxes and keypoints in one pure module, so that correcting a shape is a small change and every rule is testable without a browser.

## UX flow (LabelDesk words)
1. **No screen changes in this card.** The module is consumed by T-124; until that lands the editor behaves exactly as today (only `bbox` is draggable, `Editor.tsx:388`).
2. **Contract the next card relies on** — `nearestHandle(shape, point, {zoom, radiusPx})` answers which handle a pointer is on; `moveShape(shape, dx, dy)` and `resizeShape(shape, handle, point)` return the new normalised shape; `handlePositions(shape, W, H)` returns the eight resize handles plus polygon vertices and keypoint joints for rendering.
3. **Edge cases encoded here** — a drag that would leave the image is clamped, not refused; a resize below 0.2% of the image snaps to the minimum; a rotated box resizes along its own axes so the angle never changes; a keypoint drag preserves the visibility digit of every other joint.

## Notes for the implementer
OBB resize works in the box's local frame: rotate the pointer back by `-angle`, clamp against the opposite corner, rotate the result forward. Do not introduce a second bounds implementation — `culling.shapeBounds` is the one.
