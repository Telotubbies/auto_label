## User story
As an engineer reviewing a run, I want its files grouped by what they are — checkpoints first — so I can grab the
best weights or the confusion matrix without reading a flat list of file names.

## UX flow (LabelDesk words)
1. **Models → a run → Artifacts** — four groups in a fixed order: **Checkpoints**, **Report**, **Plots**,
   **Builds**. Each row: name (monospace), size (`8.4 MB`), a `deployed` badge on the checkpoint behind the
   production alias, and a *Download* button. [empty: `This run produced no downloadable files.`]
   [loading: five skeleton rows sized like real rows] [error: a failed fetch renders
   `Artifacts could not be loaded.` with retry; a single missing file renders its row with `No longer on disk` and
   a disabled button]
2. **Keyboard** — Tab reaches each Download in group order; Enter downloads; the group headings are real headings
   so a screen reader can jump between them.
3. **Copy path** — the row menu offers *Copy file name* (not the signed URL: it expires).
4. **Nothing to download** — a run whose directory was cleaned still shows its copied checkpoint, because the row's
   own `weights` file survives the run directory.

## Tests to write first
pytest — none: no backend surface.
node — `apps/frontend/tests/run-artifacts.test.mjs`:
- `test_groups_render_in_the_fixed_order` — an item list in random order → `Checkpoints, Report, Plots, Builds`,
  and an empty group is omitted rather than rendered empty.
- `test_best_pt_leads_the_checkpoints_then_last_pt` — three checkpoints → `best.pt`, `last.pt`, then the rest
  alphabetically.
- `test_the_deployed_badge_follows_the_note_not_the_name` — an item with `note: "deployed"` renders the badge even
  if its name is `last.pt`.
- `test_a_missing_file_renders_a_disabled_row` — `url: null` and a `No longer on disk` note → no anchor, the note
  ships verbatim.
- `test_a_directory_checkpoint_has_no_download_anchor` — `url: null` with the directory note → the row renders and
  no `href` is produced.

## Acceptance criteria
- [ ] A finished run's files are grouped, sized and downloadable in one click.
- [ ] The deployed checkpoint is first and labelled; a missing file never becomes a broken link.
- [ ] The panel shows its own empty, loading and error states without disturbing the run's other cards.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
