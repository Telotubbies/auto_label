## User story
As a user learning the product, I want one icon per concept, drawn from one set, so that Train is not a brain in the rail and a rocket in a card, and nothing in the UI looks borrowed from another product.

## UX flow (LabelDesk words)
1. **Rail** — `Projects` layers, `Models` boxes, `Deployments` rocket, `Activity` bell, `Settings` gear; the five stages get their own five: upload arrow, tag, database, brain, rocket-with-signal, and no two concepts share a glyph.
2. **A locked stage** — the lock is the only extra glyph; the stage icon does not change when the state changes, so the row is recognisable at a glance.
3. **Group headers and buttons** — every icon is 16 px, stroke-only, `aria-hidden` next to a text label; an icon-only button always carries an `aria-label`.
4. **Dark mode and forced colours** — the icons inherit `currentColor`; none is a coloured bitmap. [error: an unknown nav icon renders the fallback `Circle` and logs nothing, so a typo cannot blank a row]
5. **A reviewer adds a nav entry** — the type union forces a registry line, and the test fails until the icon exists.

- [ ] No icon package other than `lucide-react` is imported anywhere in `src`.
- [ ] Icons inherit `currentColor` and survive forced-colours mode.
- [ ] Empty, loading and error states above all render: a skeleton row renders no icon rather than a placeholder glyph, so the row does not shift when it loads.
