## User story
As a Thai labeler, I want long Thai names to wrap at phrase boundaries with their spaces intact, so that a sentence never stretches across the row and a class name never reads as a different word.

## UX flow (LabelDesk words)
1. **Stage rail, project card, batch row, class list** — a long Thai name wraps to two lines at line-height 1.6, keeps its inter-phrase spaces, and offers `เพิ่มเติม` when it still does not fit. Latin filenames keep their one-line ellipsis. [empty: a name with no characters renders an em dash, never an empty box]
2. **A justified-looking row** — never: no `text-justify`, no `tracking-*` on Thai, no `leading-none`. A Thai string that has to fit uses the clamp, not a squeezed letter-spacing.
3. **A 30 % expansion stress run** — every converted surface renders with each Thai string lengthened by 30 % (pseudo-locale fixture), and no control overflows, clips a hit area or pushes the primary action off screen.
4. **A Thai string in a fixed-width cell** — cut only by `excerpt()` from `lib/text.ts`, never `slice()`, never `substring`, never a CSS `max-width` with `overflow: hidden` and no affordance. [error: a Thai string that cannot fit shows the ellipsis plus a title/tooltip with the full text]
5. **Screen reader** — `lang="th"` is on the element that holds Thai text, so a Thai voice reads it, and a mixed Thai/English row marks only its Thai span.

## Acceptance criteria
- [ ] Long Thai names wrap to two lines with their spaces intact, and `เพิ่มเติม` reveals the rest.
- [ ] No Thai text is cut by `slice`/`substring`; `excerpt()` is the only shortener and prefers a phrase boundary.
- [ ] The 30 % stress run reports zero overflow and zero off-screen primary action across the converted screens.
- [ ] `lang="th"` marks Thai text, and a screen reader announces it in Thai.
- [ ] Empty, loading and error states above all render: the empty-name em dash, a skeleton bar at the same two-line height, and the clamp on an error sentence.
- [ ] Workspace A cannot see workspace B's data — N/A: no request is made.
- [ ] Flag off ⇒ the stress run skips with its reason and no typography rule changes.

## Notes for the implementer
`word-break: normal` plus `overflow-wrap: anywhere` is already the shipped pair in `:lang(th)`; adding `line-break: loose` or a hyphenation dictionary makes Thai worse, not better. The 30 % rule comes from the pseudo-locale practice in BEYOND G5.23, which this wave does not otherwise build: the fixture is a test input, not a shipped language.
