## User story
As the owner of a private box, I want to see what it costs in time, whether it is paused, and what it last said, so that a bill I did not expect has an explanation on the same screen.

## UX flow (LabelDesk words)
1. **Deploy & test → Dedicated** — a card per box: type chip (`dev` / `prod`), size, status, domain (wrapped), and the one line a person needs: "Running for 2 h 14 m · paused at 1 h" or "Deleted after 3 h, as a dev box does." [empty: `No private boxes. Create one to get a fixed endpoint.` with a Create button when the driver is configured] [loading: one skeleton card] [error: "Private boxes could not load." with "Try again" and a link to the delivery options]
2. **Create** — a dialog: type (two radio cards stating their consequences), size, lifetime in hours (1–72, `dev` capped at 3), startup script (collapsible, 4 KB counter). While `pending`, a row shows a progress line and the panel polls every 30 s.
3. **Actions** — Pause, Resume, Delete, each behind a confirm that names what stops: "Pause this box? The endpoint stops answering and the meter stops." Delete asks for the box's name typed back, like the version delete.
4. **Usage** — a small table under the card: minutes of existence this month, requests served, and the two numbers the catalogue promised (no credit figure, because no provider is chosen). `[error: usage unavailable]` "Usage is not reported by this driver yet." — the honest sentence, not zeros.
5. **Logs** — a "Last output" fold with the last 50 lines the driver returned; with the mock driver it reads "The mock driver produces no logs." `[error]` a log read that fails shows the reason and leaves the card usable.

## Backend changes
- Models/schema: none beyond T-352.
- Routers: `apps/backend/app/routers/runtimes.py` — `GET …/dedicated/{id}/usage` returning `{minutes, requests, reported: bool}` and `GET …/dedicated/{id}/logs?tail=50` returning `{lines, reported: bool}`; both `reported: false` with the reason when the driver has no numbers.
- Services/jobs: `apps/backend/app/services/dedicated.py` — `usage(row) -> dict` summing `UsageEvent` minutes from `created`/`ready_at` when the driver reports nothing, and `logs(row, tail) -> list[str]` delegating to the driver.
- Permissions + workspace isolation: `project.models` to read; the box is project-scoped.
- Secrets/safefetch: logs are truncated to 50 lines and 8 KB, and any line matching a key-shaped token is redacted before it leaves the server.
- OpenAPI: yes — two routes.

## Acceptance criteria
- [ ] Each box renders its type, size, status, domain and running time, with `dev` consequences stated where the choice is made.
- [ ] Create, pause, resume and delete each confirm what changes; a `dev` lifetime cannot exceed 3 hours.
- [ ] Usage and logs state honestly when the driver reports nothing, and key-shaped strings are redacted.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] No flag: with `task_352` off the section is absent.

## Notes for the implementer
No credit figure on this panel: the catalogue row already says "per machine-hour" and inventing a number before a provider is chosen would be the one claim this card cannot support. Minutes come from the row's own timestamps so they are right even with the mock driver.
