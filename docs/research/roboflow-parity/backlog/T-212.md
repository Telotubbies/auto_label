## User story
As an engineer whose parts are often behind a tool or a hand, I want random black rectangles painted over training images, so that the detector learns to find a half-hidden object.

## UX flow (LabelDesk words)
1. **Wizard → step 4 → Add augmentation → Cutout** — *Rectangles per image* (1–10) and *Size as a share of the image* (1–50%), both bounded. [empty: n/a] [loading: n/a] [error: "Rectangles must be 1–10." inline]
2. **Premium note** — "Available on Pro and Enterprise."
3. **Doubling warning** — the card carries: "Many models already apply cutout while training. Using it twice can hurt — start without it and add it only after a clean baseline." [empty: n/a]
4. **Preview** — black rectangles appear at random positions; boxes stay drawn underneath.

## Notes for the implementer
Cutout is *image scope only* — a box-scoped cutout is meaningless (`aug_scope_unsupported`). Size is a percentage of the **shorter** side so a 4000×600 image does not get 400×60 slivers.
