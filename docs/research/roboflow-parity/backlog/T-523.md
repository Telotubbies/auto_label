## User story
As a reviewer reading a run, I want a chart to either show its data or say that there is none, and I want
the legend key to be readable at a glance, so that I do not mistake an empty plot for a broken page.

## UX flow (LabelDesk words)
1. **Models → Evaluation → Loss** — a run with no `/loss` series renders `No loss recorded for this run.`
   A run with series renders exactly as today.
2. **Usage & Billing → Metered activity** — a period with no usage renders `No metered usage in this
   period.` instead of a flat zero line.
3. **Any chart legend** — keys render at `text-xs` in `--foreground`, and each series colour comes from the
   theme, not a hex literal. [loading: unchanged] [error: unchanged]

## Notes for the implementer
Options considered:
1. **A sibling empty component with the chart's own height (recommended).** No layout shift, no change to
   the chart library.
2. **Recharts' own `isEmpty` prop.** It still draws the axes and gridlines, which is the defect.
3. **Hide the card.** Rejected: an absent card reads as a missing feature, not as a run without loss.

The legend fix is one shared object so the next chart cannot drift again. Do not introduce a new palette:
`classColor` in `lib/theme.ts` is the shipped source, and T-495 is making it the only one.
