## User story
As a visitor, I want the public page to show what the dataset is, what classes it has and a few real images, so that I can judge it before copying it.

## UX flow (LabelDesk words)
1. **Dataset page data** — `GET /api/public/datasets/{ws}/{project}` returns name, description, type, workspace name, licence, `images`, `classes: [{name, count}]`, citation block (`<name> · <workspace> · <year> · <licence>`), and up to 12 sample image descriptors `{id, width, height, url}` where `url` is `/api/public/datasets/{ws}/{project}/images/{id}`.
2. **Sample bytes** — `GET …/images/{id}` streams a 512 px webp/jpeg thumbnail with `Cache-Control: public, max-age=3600`; `404` once the project is private or the image is deleted. [error: 404 for both unknown and private, never "private"]
3. **Empty dataset** — `images: 0` and `samples: []`; the page still renders description, classes and licence.
4. **Rate limit** — 120 image requests per minute per IP; over the limit → 429 `Too many requests — try again shortly.`

## Backend changes
- Models/schema: none.
- Routers: `routers/public.py` (new), prefix `/api/public/datasets`: `GET /{ws}/{project}` and `GET /{ws}/{project}/images/{image_id}`; both anonymous; mount after `discovery.router` in `ROUTERS`.
- Services/jobs: `services/public_dataset.py` (new) — `resolve(db, ws_slug, project_slug) -> (workspace, project)` enforcing public + not deleted + workspace policy (`getattr(ws, "allow_public_projects", True)`), `payload(db, project)`, `thumb_path(project, image)`; reuses `imaging` for a cached 512 px thumbnail, never the original file.
- Permissions + workspace isolation: anonymous, and the only rows reachable are `visibility == "public"`, `deleted_at IS NULL`; an image id from another project or workspace is 404; the projection is an explicit key list so a new column cannot leak.
- Secrets/safefetch: none — no fetch, no signed URL (a signed URL would expire under a shared link).
- OpenAPI: yes.

## Frontend changes
- Client only: `publicApi.dataset(ws, project)` in `src/lib/api/public.ts` (new). The page is T-036.

## Acceptance criteria
- [ ] A public project's payload carries description, classes with counts, licence, citation and up to 12 sample images.
- [ ] A private, deleted or unpublished project is 404 on both routes, with no hint that it exists.
- [ ] Empty dataset still renders description, classes and licence with `samples: []`.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
- [ ] Only thumbnails are served, never originals; the rate limit returns 429.

## Notes for the implementer
Return the thumbnail path, not `security.sign_path` — a signed URL breaks when the link is shared past its expiry. The projection list is the contract; the node test asserts its keys.
