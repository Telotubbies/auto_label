## User story
As an engineer training a semantic segmentation model, I want one PNG mask per image with class ids as pixel values, so that a segmentation project can export without a polygon-to-mask script.

## UX flow (LabelDesk words)
1. **Export dialog → PNG masks** — hint: "One mask per image; pixel value = class id, 0 = background." [empty: as T-224] [error: as T-224]
2. **Segmentation project** — the mask keeps the image's own resolution and file stem (`train/masks/<stem>.png` beside `train/images/<stem>.jpg`).
3. **Detection project** — the same writer turns boxes into filled rectangles, and the chip says "boxes are exported as filled rectangles". [empty: n/a]

## Backend changes
- Models/schema: none.
- Routers: none.
- Services/jobs: `app/services/exporters.py` — `export_png_mask(m, src, out, should_stop)`: for every item, open the written image to read its size, create an `L` image filled with 0, draw each polygon (Pillow `ImageDraw.polygon`) or bbox (`rectangle`) with `value = cls + 1`, save as PNG under `<split>/masks/<stem>.png`, and write `classes.txt` (`0: background`, then one line per class with its id). Class ids come from the manifest order, so `nc` and the pixel range agree.

## Tests to write first
pytest — `apps/backend/tests/test_export_png_mask.py`:
- `test_mask_has_the_image_resolution` — a 640×480 item produces a 640×480 `L` PNG at `<split>/masks/<stem>.png`.
- `test_polygon_pixels_get_the_class_id` — a polygon covering the left half of a one-class project leaves `0` on the right and `1` on the left.
- `test_box_becomes_a_filled_rectangle` — a bbox at `0.25,0.25,0.5,0.5` fills exactly that quarter with the class id.
- `test_class_ids_follow_the_manifest_order` — two classes → ids 1 and 2, and `classes.txt` lists them in the same order.
- `test_background_is_zero` — an image with no annotations yields an all-zero mask (never skipped).
- `test_semantic_project_sees_the_format_and_detection_does_too` — `GET /versions/formats` includes it for both, per T-226's task list.

## Acceptance criteria
- [ ] One PNG per image at the image's own resolution, background 0, class ids from the manifest.
- [ ] Polygons fill their area; boxes fill their rectangle; an unannotated image still ships a zero mask.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ the chip is absent from the new dialog.

## Notes for the implementer
Open the **written** image (not the source) so the mask matches the exported JPEG's dimensions after resize. Cap at 256 classes (`L` mode cannot express 255 classes plus background) and fail with a readable message above it.
