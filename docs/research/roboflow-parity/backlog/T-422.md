## User story
As a security engineer, I want to paste a collector URL, test it before saving and see why it failed, so that
connecting Splunk is a five-minute job.

## UX flow (LabelDesk words)
1. **Settings → Audit log → `SIEM integration`** (`/:ws/settings/audit?tab=siem`) — an `Enable SIEM integration`
   switch, `Collector URL`, a protocol radio (`gRPC · port 4317, base URL` / `HTTP · port 4318, full /v1/logs path`),
   a `Headers (JSON)` textarea with the masked hint `Stored encrypted. A saved value is never shown again.`
2. **`Test connection`** uses the current form values: a small status line `Sending one test event…` then
   `Sent · 84 ms` with `Search your SIEM for audit.action = test_connection.`; a failure prints exactly one of
   `Connection refused — is the collector reachable from LabelDesk?` / `The collector rejected our credentials (401).` /
   `TLS error — the collector must present a publicly trusted certificate.` / `HTTP path mismatch — include /v1/logs.` /
   `Timed out after 5 seconds.`
3. **`Save`** persists; `last_status` under the form reads `Last event delivered 3 minutes ago` or
   `Last attempt failed: unauthorized, 2 hours ago.`
4. **`[empty]`** not configured: the switch is off, the fields are empty and `Save` is disabled until an endpoint exists.
5. **`[error]`** an invalid URL is inline under the field (`Enter an https:// URL.`); a blocked address reads
   `That address is not allowed — use a public collector endpoint.`
6. **`[loading]`** the tab skeleton is one card with three field placeholders.
