## User story
As an engineer, I want the files a run produced — best and last checkpoint, the training CSV, the plots and the
evaluation report — listed with sizes and a download link, so I can inspect a run without opening a ticket for
worker access.

## UX flow (LabelDesk words)
1. **Models → a run → Artifacts** — grouped rows: *Checkpoints* (`best.pt` marked `deployed` when it is the file
   behind the alias, `last.pt`), *Report* (`results.csv`, `evaluation.json`), *Plots* (confusion matrix, PR curve),
   *Builds* (edge presets already shipped). Each row shows size and a download button; the panel is the surface
   T-912 draws. [empty: `This run produced no downloadable files.`] [loading: five skeleton rows]
   [error: a file that disappeared from disk renders `No longer on disk` with the button disabled, never a 404
   page]
2. **Download** — the row's link is a signed short-lived URL (`security.sign_path`), so the browser fetches the
   bytes directly and the API is not in the data path.
3. **A directory checkpoint** — a family that stores a directory (HF) renders one row named `model/` with
   `Directory — download the run archive` and no per-file link.

## Backend changes
- Models/schema: none — `TrainedModel.weights` (`models/training.py:48`) and the deterministic run directory
  `DATA_DIR/runs/<model_id>/` (`adapters/ultralytics_ad.py:186`, `:229-234`) already hold everything.
- Routers: `apps/backend/app/routers/training.py` — `GET …/models/{mid}/artifacts` → `{"items": [...]}`; 404 for an
  unknown or foreign model (`_model()`, `:290-294`), 404 when the flag is off.
- Services/jobs: `apps/backend/app/services/run_artifacts.py` (new) —
  `run_dir(model_id: str) -> Path`, `list_artifacts(m: TrainedModel) -> list[dict]` where each item is
  `{"name", "kind": "checkpoint"|"report"|"plot"|"build"|"report-json", "bytes": int|None, "url": str|None,
  "note": str}`. Sources: `m.weights` (file, or directory for `family == "hf"`), `<run_dir>/weights/*.pt`,
  `<run_dir>/results.csv`, `<run_dir>/*.png|*.jpg`, the stored evaluation (`m.metrics["eval"]`, rendered as a
  download of the JSON we hold), and `m.runtime_refs["edge"]` (`routers/training.py:94-98`).
  Every candidate path goes through one guard: `path.resolve().is_relative_to(DATA_DIR.resolve())` and no symlink
  follow outside it; a path that fails is dropped, not served with a reason that leaks the location.
- Permissions + workspace isolation: `project.models` (the same gate as `get_model`, `:305-306`); the run is
  resolved through the project, so a foreign id is 404.
- Secrets/safefetch: `security.sign_path` only (`app/security.py:117`); the service never accepts a caller-supplied
  path.
- OpenAPI: yes — `python tools/export_openapi.py`, then `npm run gen:api-types`.

## Acceptance criteria
- [ ] A finished detection run lists its checkpoints, CSV, plots, evaluation report and builds with correct sizes.
- [ ] Nothing outside `DATA_DIR` is ever listed or signed, whatever the row or the disk contains.
- [ ] A missing file degrades to a named row, not a 500 and not a broken page.
- [ ] Empty, loading and error states above all render.
  (The empty list is the panel's state; a missing file is a row state.)
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
