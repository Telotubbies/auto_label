## User story
As a labeler, I want the submit button to tell me how I did and what kind of mistake it was, so that I can fix it now rather than after a reviewer has spent a cycle on it.

## UX flow (LabelDesk words)
1. **Editor → `Submit for review` on a scored image** — the click opens `Checked against the answer key` with `Your score` (largest number in the panel), `Target`, and `Attempt 1 of 3`. [loading: the dialog's body is a spinner while the score request runs] [error: "The check timed out, so this image goes to review unscored." and the image submits anyway]
2. **At or above target** — "Close enough to send." with `Send to review` (primary) and `Keep working` (ghost). [empty: nothing is listed when there are no hints]
3. **Below target with attempts left** — "Not enough yet — look at the hints and try again." with up to three hint lines and `Fix and re-check` (returns to the same image, attempt counter visible in the header chip) plus `Send anyway`.
4. **Last attempt used** — `No attempts left — this image goes to review with the score attached.` and only `Send to review` remains.
5. **An ordinary image** — the button behaves exactly as today; no dialog, no extra request.

## Acceptance criteria
- [ ] Submitting a scored image shows the score, target and attempt before anything leaves for review.
- [ ] Below target with attempts left returns to the same image with the counter visible; the last attempt sends with the score attached.
- [ ] At most three hints render and none names a box or a coordinate.
- [ ] Empty, loading and error states above all render: no-hints empty, the scoring spinner, and the timeout/409 sentences.
- [ ] Workspace A cannot score workspace B's image: the request goes to this project's route and a foreign id renders the 404 sentence.
- [ ] Flag off ⇒ `Submit for review` sends immediately, exactly as today.

## Notes for the implementer
Keep one dialog, not a wizard: `Fix and re-check` closes it so the canvas keeps focus and the labeler redraws immediately. Never show the answer key, the key's count, or a diff preview — only the score, the target and the three closed-vocabulary hints.
