## User story
As a labeler reading metadata all shift, I want no text below 13 px (12 px only inside chips and table headers) so that filenames, counts and statuses stay legible on a 1440 screen and at 200% zoom.

## UX flow (LabelDesk words)
1. **Any screen** — metadata (captions, counts, hints, breadcrumbs, rail labels) renders at `text-sm` (14/20); `text-xs` (12/16) is allowed only inside a chip or a table header. Nothing is below 12 px, and no arbitrary size is introduced. The class rail, the job tray, the breadcrumb and the stage rail are the first places checked.
2. **Editor** — the class list, object count and hotkey digits stop rendering at 10–11 px; the editor card (T-498) owns its own block, this card owns the shell and the workspace screens.
3. **Zoom to 200%** — nothing in the shell drops below the floor, so the layout reflows instead of shrinking text.
