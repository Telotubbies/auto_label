## User story
As a labeler, I want a contrast lift and one key that hides every outline, so that I can inspect the pixels under a box without touching what is saved.

## UX flow (LabelDesk words)
1. **Editor → Display popover** (bottom bar, `Editor.tsx:1232-1249`) — brightness, contrast, a new **Gamma** slider (`0.5–2.0`, default 1.0) and an **Auto contrast** checkbox. Turning auto on greys the manual contrast slider and normalises the image on the client; turning it off restores the manual value.
2. **Reset** — restores brightness 100%, contrast 100%, gamma 1.0 and auto off in one click, without touching annotations.
3. **Show annotations switch** — the same popover gains a switch, and `h` toggles it. Hidden means every shape, handle and mask overlay is invisible; the image, the cursor and the tools stay usable. [empty: an image with no annotations shows the switch disabled with "Nothing to show"]
4. **Hidden notice** — while hidden, a pill sits above the canvas: "Annotations hidden" with a **Show** button and the reminder `h`. Clicking Show restores them.
5. **Persistence** — all five values live in the T-120 session bag, so they survive image changes and a reload of the same tab; a new tab starts at defaults.
6. **Honesty** — the popover repeats the line "Display only — saved annotations are unchanged" and nothing in this card can mark the image dirty.

## Acceptance criteria
- [ ] Brightness, contrast, gamma and auto contrast change only the rendered canvas, and the reset restores every control.
- [ ] `h` hides and shows every annotation, handle and mask; while hidden a pill offers Show.
- [ ] The values survive `→` navigation and a reload of the same tab; a new tab starts at defaults.
- [ ] Nothing in this card marks the image dirty or writes to the API.
- [ ] Empty, loading and error states above all render: an image with no annotations disables the switch with a reason.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — no endpoint.
- [ ] No flag: options inside the existing popover.
- [ ] Keyboard-only path: `h` → Tab to Show → `h` again.

## Notes for the implementer
Gamma is expressed as a CSS `filter` the browser can already do — a per-pixel canvas pass would cost a full re-render of a 6000 px image on every slider tick. Auto contrast picks a fixed pair from the image's own histogram once per image, not per frame.
