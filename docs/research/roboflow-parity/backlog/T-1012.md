## User story
As a workspace admin, I want to filter models by family, quantisation and licence, see what fits the
selected host, and download one from a sheet that states the gate and the disk after, so that I do not
download 30 GB to discover it does not run.

## UX flow (LabelDesk words)
1. **Models tab** — filters (family, size band, quantisation, licence, `Fits this host`, `Installed`),
   then a dense table: name, params, variant chips, download size, licence badge (link), gate badge,
   engine target, estimated VRAM, state (`Not installed` / `Installed` / `Downloading 43%`), action.
   [loading: five skeleton rows] [error: "Models did not load for this host." + Retry].
2. **Variant choice** — a row can offer several variants; a segmented control picks one and the size,
   VRAM estimate and engine badge update. Default: the smallest variant that fits.
3. **Download sheet** — model + variant, the file list with bytes, total, disk before/after, gate and
   token state, licence link, and `Download`. A block replaces the button with its reason: "Needs 41 GB,
   host has 28 GB free." / "This model is gated; this host has no Hugging Face token."
4. **Gated but token present** — the sheet adds "The operator accepted this licence on the host's
   Hugging Face account." and keeps the licence link.
5. **After confirm** — sheet closes, the row reads `Queued`, and the job card from T-1009 appears at the
   top of the tab. [error: 409 for a busy host or an installed variant, inline in the sheet].
6. **Installed** — the row action becomes `Installed` with a check; a `Manage on host` link opens the
   assets panel (T-1013). [empty: no match → "No model matches these filters." + Clear filters; no host
   → "Pick a host to see what fits."].
7. **Non-commercial** — the badge and the sheet say `Non-commercial licence`; the row is downloadable
   and the badge is never hidden.
8. **375 px** — filters collapse into a sheet; the table scrolls; variant chips wrap.

## Tests to write first
node — `apps/frontend/tests/inference-models.test.mjs`:
- `test_default_variant_is_the_smallest_that_fits` — three variants, two fit → the smaller fitting one;
  none fit → the smallest, with the row marked does-not-fit.
- `test_filters_combine` — family + `Fits` + `Installed` returns the intersection, and `Clear filters`
  restores all.
- `test_row_state_prefers_the_job_over_the_catalogue` — an active download job for the variant renders
  `Downloading 43%`, not `Not installed`.
- `test_block_copy_names_the_numbers` — disk block → "Needs 41.0 GB, host has 28.0 GB free."; gated →
  the `HF_TOKEN` sentence; non-commercial → the badge sentence.
- `test_installed_row_has_no_download_action` — `rowState` returns `installed` and the action list has
  only `Manage on host`.
- `test_bytes_render_in_gb_with_one_decimal` — `gib(41_000_000_000)` → `38.2 GB` (one decimal, no
  scientific notation).

## Acceptance criteria
- [ ] Filters combine and Clear restores; no match and no host have distinct empty states.
- [ ] Variant choice updates size, VRAM and engine; the default is the smallest that fits.
- [ ] The sheet shows the file list, total, disk after, gate/token state and licence link.
- [ ] A blocked download names the shortfall or the missing token; the button is disabled, not warned.
- [ ] Confirming creates the job and the row/card reflect `Queued` without a reload.
- [ ] Non-commercial and gated badges are visible in the row and the sheet.
- [ ] 375 px: no horizontal page scroll; filters usable; sheet full-height.
- [ ] No new token, hex, font size or icon library; glass on chrome only.

## Notes for the implementer
Do not hide a non-commercial or gated model from the list: the catalogue's job is to say what the model
is, and hiding it makes the licence a surprise later. Show file paths? No — the sheet lists file names
and sizes, not the full repo paths; the plan endpoint returns them for the admin, and the UI may show
the basename only.
