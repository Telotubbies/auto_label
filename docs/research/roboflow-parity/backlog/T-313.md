## User story
As a developer, I want the code I copy to match the server I chose, so that a self-hosted install does not reach a hosted URL and a copied snippet does not leak a key into a public repository.

## UX flow (LabelDesk words)
1. **Deploy & test → endpoint card** (right pane) — the URL renders in a wrapped `code` block with `[overflow-wrap:anywhere]`, so a long project path breaks instead of clipping. `Copy` sits at the card's top-right and copies the URL alone. [empty: no ready model → the card shows "Train a model to get an endpoint." and the tabs are disabled] [loading: the URL line is a skeleton the same height as the final line] [error: copy refused → the URL is selectable and the button says "Select and copy"]
2. **Runtime selector** — one `Select` above the tabs, seeded from T-310's catalogue: `Hosted API`, `Your own server`, `Batch job` (when available), `Edge device` (disabled). Changing it rewrites every snippet's base URL and moves the recommended tab. A disabled runtime appears with its reason and cannot be selected.
3. **Language tabs** — `cURL`, `Python`, `JS`. The recommended tab for the selected runtime carries a small "Recommended" chip. Each body is monospace, indented, and the first line names the runtime in a comment: `# POST http://localhost:8010/predict`.
4. **Auth note** — one line under the tabs: "Send your workspace key as `Authorization: Bearer …`. The snippet shows `$LABELDESK_API_KEY`; the key itself is never printed here." A "Manage keys" link goes to `/:ws/settings/api`.

## Backend changes
None: the URL is composed in the browser from `API_ORIGIN` and the runtime's host, and the response shape is T-310's envelope. No schema, router or service change.

## Tests to write first
pytest — `none: no backend surface`.
node — `apps/frontend/tests/deploy-snippets.test.mjs`:
- `test_the_host_follows_the_runtime` — `hostFor("hosted", "http://localhost:8010")` is `API_ORIGIN`-relative, `hostFor("self_hosted", "http://localhost:8010")` is that host, and both snippets contain the result.
- `test_no_snippet_contains_a_secret` — with `hasKey: true` the three bodies contain `LABELDESK_API_KEY` (or `process.env`) and never a 32-character hex string or the word `Bearer ` followed by a literal.
- `test_the_self_hosted_snippet_posts_to_predict` — the self-hosted cURL contains `POST` and `/predict` with `-F "file=@image.jpg"`.
- `test_a_disabled_runtime_cannot_be_selected` — `hostFor("edge", …)` returns `null` and `snippets` throws a named `RuntimeUnavailable` the card renders as a disabled tab set.
- `test_the_recommended_tab_follows_the_runtime` — `hosted → "curl"`, `self_hosted → "python"`, `batch → "python"`.

## Acceptance criteria
- [ ] Switching the runtime rewrites every snippet's host in one render; no snippet keeps the previous host.
- [ ] A long endpoint URL wraps at 1440 px and at 375 px, and nothing is clipped or scrolls horizontally out of the card.
- [ ] No snippet, tooltip or `title` attribute contains a workspace key; the auth note names the environment variable only.
- [ ] A runtime the catalogue disables is selectable-but-disabled with its reason, and its snippets are not generated.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — the card reads only T-310's payload.
- [ ] No flag: nothing renders until T-314 mounts the card.

## Notes for the implementer
Exactly three tabs — `cURL`, `Python`, `JS`. Do not add a fourth language and do not print an example response body here; the response shape lives in T-318's reference. `API_ORIGIN` is empty on a same-origin deployment (`lib/api/client.ts:6`), so the hosted snippet must render a path (`/api/v1/models/…`), not an empty host.
