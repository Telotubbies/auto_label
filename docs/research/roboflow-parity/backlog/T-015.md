## User story
As a new user, I want one screen where I say what I need and get a project out of it, so that I never meet an empty project list as my first impression.

## UX flow (LabelDesk words)
1. **Assistant** (`/:ws/assistant`) — centred column (max 720): thread above, composer pinned at the bottom of the column. Composer has a `+` menu with `Attach images`, `Use camera`, `Create an asset`, and a `Send` button. [empty: no brief → three starter rows above the composer] [loading: two skeletons, composer disabled with `Loading the conversation…`] [error: banner `Could not load the conversation` + `Retry`; the page keeps its geometry].
2. **Send a message** — Enter sends, Shift+Enter breaks the line; the draft clears on send and returns if the request fails. [loading: a three-dot typing row anchored under the last user bubble].
3. **Proposal row** — under the reply: title, one metadata line (type · classes), primary `Create project`, ghost `Change details` (opens the New project form pre-filled, which already exists on the workspace home). [error: 402 shows the plan sentence inline on the row; 422 shows the name error and keeps the row].
4. **Attach images / camera** — the `+` menu items route to the existing Upload screen of the project if one exists, otherwise they show `Create a project first — that is one click away.` with the proposal row focused. Camera opens the same capture surface used by the playground (`features/playground/useCamera.ts`) once a project exists.
5. **Mobile 375** — thread full width, composer above the safe area, `+` menu as a bottom sheet; no horizontal scroll.
