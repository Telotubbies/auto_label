## User story
As a night-shift operator, I want one counter that says how much is waiting and one badge that says my verdicts are local-only, so that I stop timing the shift around the uplink and never mistake a buffered reject for a lost one.

## UX flow (LabelDesk words)
1. **Streams wall** (`/:ws/:project/streams`) — a `SpoolCard` above the wall reads `รอส่ง 1,284 เหตุการณ์ · 412 MB · เก่าสุด 3 ชม.` with a `ส่งเดี๋ยวนี้` button for a manager. [empty: `ไม่มีอะไรค้างส่ง`] [loading: `กำลังอ่านสถานะบัฟเฟอร์`]
2. **The drain** — pressing the button shows `[loading: กำลังส่ง 1,284]` with a rate, then `ส่งครบแล้ว · ไม่มีรายการถูกปฏิเสธ`; a partial drain names the rejected count and links the rejected rows. [error: `เวลาอุปกรณ์คลาดเคลื่อน — เรียงตามเวลาอุปกรณ์` when a device clock is off by more than five minutes]
3. **The link badge** — while the spool holds anything, the wall and the stream header carry `คำตัดสินถูกเก็บในเครื่องก่อน` beside the status chip, so nobody reads a green `Live` as "the plant has it". [error: a disk that cannot be written keeps `บันทึกชั่วคราวไม่สำเร็จ — พื้นที่ดิสก์เต็ม` visible until the next successful write]
4. **The policy** — `เพดานดิสก์` (64–20480 MB) and the drop order (`รูปภาพก่อนคำตัดสิน`, fixed order, read-only) in a `Modal` behind `แก้ไขเพดาน`; saving applies to the next drop, not retroactively. [error: `เพดานต้องอยู่ระหว่าง 64 และ 20480 MB`]

## Backend changes
- Models/schema: none new — T-673 shipped `SpoolItem`; the policy is written to `Project.settings["spool"]`.
- Routers: `app/routers/spool.py` (new), prefix `/api/ws/{ws}/projects/{project}/spool`, `dependencies=[Depends(require_flag("task_store_forward"))]`; `GET /status` → `{"items", "bytes", "oldest_age_s", "dropped_images", "ceiling_mb", "clock_skew_s"}`; `PATCH /policy` `{ceiling_mb}` → 200 (400 outside 64–20480); `POST /drain` `{limit?: int ≤ 500}` → `{"drained", "rejected", "remaining", "rate_per_s"}` (200 even when some rows are rejected; the body names the count).
- Services/jobs: `app/services/spool.py` gains `drain(db, project, limit=50) -> dict` — walks `state='pending'` ordered by `device_ts, created`, skips an item whose `StreamEvent` id already exists, restores the blob to `DATA_DIR/snapshots/<project>/<event>.jpg`, inserts the event row with the spooled id, marks the item `sent`; an item whose insert raises is marked `pending` with `attempts += 1` and counted as rejected. `clock_skew(db, project)` returns the largest `abs(device_ts - created)` over pending rows. One line in `app/worker.py` beside `retention.enqueue_if_due()` calls `spool.drain_due()` so a reconnect (a quota that frees) drains without a click.
- Permissions + workspace isolation: `GET /status` needs `project.streams`; `PATCH /policy` and `POST /drain` need `c.need("admin")`; every query filters `project_id` **and** `workspace_id`, so a spool row from another workspace is invisible and an id-addressed drain of a foreign project is 404.
- Secrets/safefetch: none — blobs are local JPEGs and the payload is the event dict.
- OpenAPI: yes — three new routes and their schemas.

## Acceptance criteria
- [ ] The wall shows buffered events, bytes and the oldest age, and `ส่งเดี๋ยวนี้` drains them in device-time order with a rate and a rejected count.
- [ ] A drained event keeps its original id and is never duplicated by a second drain.
- [ ] The badge `คำตัดสินถูกเก็บในเครื่องก่อน` appears while anything is buffered and disappears when the spool is empty.
- [ ] Empty, loading and error states above all render, including the clock-skew sentence and the full-disk sentence.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no counter, no badge and the wall header is today's.

## Notes for the implementer
Drain only while `metering.remaining(...) > 0`, and stop the batch at the first insert the meter refuses so the next poll retries instead of burning the queue. The drop order is fixed to images-first and is shown read-only: making it configurable invites "drop the verdicts and keep the pictures", which is the exact liability this card removes. Copy: `streams.spool.buffered`=`รอส่ง {events} เหตุการณ์ · {size} MB · เก่าสุด {age}`, `streams.spool.draining`=`กำลังส่ง {n}`, `streams.spool.drained`=`ส่งครบแล้ว · ไม่มีรายการถูกปฏิเสธ`, `streams.spool.drainedRejected`=`ส่งครบแล้ว · {n} รายการถูกปฏิเสธ`, `streams.spool.skew`=`เวลาอุปกรณ์คลาดเคลื่อน — เรียงตามเวลาอุปกรณ์`, `streams.spool.localOnly`=`คำตัดสินถูกเก็บในเครื่องก่อน`, `streams.spool.empty`=`ไม่มีอะไรค้างส่ง`, `streams.spool.loading`=`กำลังอ่านสถานะบัฟเฟอร์`, `streams.spool.ceiling`=`เพดานดิสก์`, `streams.spool.ceilingRange`=`เพดานต้องอยู่ระหว่าง 64 และ 20480 MB`, `streams.spool.diskFull`=`บันทึกชั่วคราวไม่สำเร็จ — พื้นที่ดิสก์เต็ม`, `streams.spool.drainNow`=`ส่งเดี๋ยวนี้`.
