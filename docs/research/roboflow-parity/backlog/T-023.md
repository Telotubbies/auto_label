## User story
As a project owner, I want to write the blurb visitors read and see the project's public link the moment it exists, so that publishing is not followed by a hunt through settings.

## UX flow (LabelDesk words)
1. **Project settings → General** — a new *Description* block above Name: a 6-row textarea, counter `0/600`, hint `Visitors and teammates read this first.` and a `Save description` button that is disabled until the text changes. [empty: no description → placeholder `What is this dataset for, and what is in it?`] [loading: skeleton lines while the project loads] [error: `Could not save — your text is kept.` with `Retry`].
2. **Public link row** — under the block: `Public link` + `/d/:ws/:project` with a copy button, shown only when `visibility == "public"`; when private, one line `Private. Make it public from the project menu.` [empty: not public → the sentence, no URL]
3. **Workspace home card** — the description's first line appears as the card's subtitle (one line, truncate at 2 lines with an explicit `more`), replacing nothing else on the card.
4. **Overview** — when the project overview lands (area E), it reads the same `description` field; this card does not build a second editor there.

## Backend changes
- Models/schema: `projects.description TEXT DEFAULT ''` — `ADD COLUMN` `{"description": "TEXT DEFAULT ''"}` appended to `PROJECTS` in `app/schema/dataset.py`; `Project.description` mapped column.
- Routers: `ProjectPatch` gains `description` (≤600, trimmed; newlines kept); `project_out` returns `description` and `publicPath` (`/d/{ws}/{slug}` when public, else null).
- Services/jobs: none.
- Permissions + workspace isolation: description edit needs `project.settings` (manager) — the same gate as the rest of General; a project slug from another workspace 404s in `project_ctx`.
- Secrets/safefetch: none. HTML is never rendered from this string: React escapes it (assert in the test).
- OpenAPI: yes.

## Frontend changes
- Route: none; the block lives on `/:ws/p/:project/settings?tab=general`.
- Nav entry: none.
- Components: `features/project/DescriptionCard.tsx` (new) — textarea, counter, save, public-link row; mounted by `ProjectSettings.tsx`; the home card subtitle is one line inside `Home.tsx`'s card body.
- API client: `patch(api.P(ws, slug), {description})` — existing helper, no new function.
- Feature flag: none.

## Acceptance criteria
- [ ] Description saves with newlines preserved and is capped at 600 characters in UI and API.
- [ ] The public link row appears only for a public project and copies `/d/:ws/:project`.
- [ ] Empty, loading and error states above all render (placeholder, skeleton, failed-save retry).
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag none: nothing else on the settings page or the project card changes.
- [ ] The string is rendered as text only (no HTML injection path).
