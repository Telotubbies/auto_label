## User story
As a Thai-first labeler, I want the empty states, primaries and errors in real Thai next to the English, so that the product reads as written for my shift rather than translated word by word.

## UX flow (LabelDesk words)
1. **Home, project overview, Upload, Annotate, Editor, Dataset, Versions, Train, Models, Deploy** — each screen's title, primary, empty line, no-match line and error line comes from one deck, so the same concept has the same word everywhere (`Dataset` is never `Browse` in one place and `Images` in another).
2. **A Thai browser, labeler surfaces only** (Home queue, board lanes, editor header, empty states) — the deck's Thai line renders: `ยังไม่มีภาพ — อัปโหลด 20 ภาพ หรือเริ่มจากชุดตัวอย่าง 40 ภาพ`, `เริ่มติดป้าย`, `ภาพถัดไป`. A Thai line wraps to two lines and then shows `เพิ่มเติม` (T-473's rule).
3. **A copy change** — one file, one test: the deck is the source, screens import it, and no screen keeps a duplicate sentence.
4. **An error** — the deck's error line names what survived and what did not, and never shows a raw server string as the whole message. [error: an unexpected server message is appended after the deck's sentence, never replacing it]
