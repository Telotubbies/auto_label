## User story
As an ML engineer training classifiers, I want top-1, top-5, per-class precision/recall and a confusion
matrix from a held-out split, so that a classifier's evaluation is not a single training-time number.

## UX flow (LabelDesk words)
1. **Models → a classifier → Evaluation** — instead of the current sentence, the panel shows *Top-1*,
   *Top-5*, then *Per-class precision / recall / F1* and a confusion matrix by predicted class.
   [empty: a class with no examples in the split reads "no examples" in its row, never 0.000] [loading: the
   panel's usual skeleton; classification adds no new spinner] [error: "Evaluation failed: <reason>" with
   *Try again*, exactly as for detection]
2. **Thresholds** — top-1 and top-5 are reported as ratios with the count beside them ("0.912 · 748 of 820").
3. **A confidence slider** — classification has one knob too: a *minimum confidence* slider that moves rows
   from a class to *unclassified* and updates the strip live, so a buyer sees the abstain rate.
4. **Export** — the confusion matrix and the per-class table export to CSV like every other chart.

## Backend changes
- Models/schema: none — the report rides `trained_models.metrics["eval"]` as it does today.
- Routers: none new. `GET {P}/models/{mid}` (`apps/backend/app/routers/insights_models.py:44`) and
  `GET {P}/insights/training` already return the whole report; the classify branch simply stops being
  `_empty`.
- Services/jobs: `apps/backend/app/services/evaluate.py` — replace the early return at `:38-39` with
  `_evaluate_classify(...)`: predict the test (fallback valid) split through `resolve(...)`, take the
  adapter's top-k classes and scores, then compute `accuracy_top1`, `accuracy_top5`, per-class
  precision/recall/F1 with support, a `confusion` block in the same shape the detection path emits
  (`{"labels", "matrix", "files"}`), `latency_ms`, and `split_images` — so every existing frontend consumer
  keeps one shape. Unsupported adapters (`out` has no `top`/`scores`) raise a typed
  `NotEvaluable("this model does not return class scores")` that the handler stores as `eval_error`.
- Permissions + workspace isolation: unchanged (the read gate stays `project.review`).
- Secrets/safefetch: none. Dependency: none added (no `mlflow-skinny`), so no
  `THIRD_PARTY_LICENSES.md` change.
- OpenAPI: no — no route or schema change.

## Acceptance criteria
- [ ] A classifier's evaluation reports top-1, top-5, per-class precision/recall/F1 and a confusion matrix.
- [ ] The payload keeps the detection report's key names so existing consumers do not branch.
- [ ] An adapter that cannot return class scores yields a named evaluation error, not a crash and not a
      misleading zero.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
