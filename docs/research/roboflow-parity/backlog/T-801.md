## User story
As a customer with our own GPU box, I want the command, the badge and the heartbeat in the product, so that training on my hardware is a supported path instead of a wiki page.

## UX flow (LabelDesk words)
1. **Train** (`/:ws/:project/train`) — `Run on my hardware` opens a dialog: the copyable command, the expiry ("The command works for 24 hours."), and a note that only metrics leave the machine. [loading: the command area shows a skeleton until it is minted] [error: no remote topology ⇒ the sentence "This workspace trains on its own worker only." and the button disabled with the reason]
2. **Copy** — one button with a toast "Command copied"; the token is shown once and the dialog says so. [error: the clipboard refuses ⇒ the command is selected in a read-only field instead]
3. **Models list** — a run created by a remote runner carries a `Remote` badge and, while live, its heartbeat age. [error: the model request fails ⇒ today's empty/error state]
4. **Stale run** — after four silent minutes the badge reads "No heartbeat for four minutes. Last seen {time}." and the run is not failed. [loading: the model poll keeps refreshing while the run is queued or training]
5. **Interrupted and resumed** — the same model row returns to training; no second row appears.

## Backend changes
- Models/schema: none in this card.
- Routers: none — it consumes T-800's mint and state routes.
- Services/jobs: none.
- Permissions + workspace isolation: `admin` sees the mint action; the state read uses the model route's existing permission; a cross-workspace model answers 404 through the API.
- Secrets/safefetch: none on the client — the command string arrives once and is never persisted in the browser (no `localStorage`, no URL).
- OpenAPI: no.

## Acceptance criteria
- [ ] An admin mints a command from Train, copies it once, and the dialog states its 24-hour life.
- [ ] A remote run appears with a `Remote` badge, its heartbeat age, and goes stale rather than failed.
- [ ] No command or token is written to the URL, `localStorage` or a toast.
- [ ] Empty, loading and error states above all render: an unavailable remote path states why, the mint skeletons, a clipboard refusal falls back to a selected field.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no action, no badge, and Train/Models are unchanged.

## Notes for the implementer
The token is displayed exactly once and never re-fetched: a second visit to the dialog mints a new command, which is also how a lost token is recovered. Do not put the command in a URL or a toast — both survive in history and screenshots.
