## User story
As a manager, I want one page that describes the version and one primary action, with a delete that states what it destroys before I type the name, so that I cannot remove a version and its models by accident.

## UX flow (LabelDesk words)
1. **Version detail** — header `v3 · release-640` with date and status; a split bar (train/valid/test as one 100% bar with three labelled segments and counts); class counts as chips with numbers; then the panels (recipe, what changed, runs). [empty: n/a for a ready version] [loading: skeleton header + bar] [error: "Version not found — it may have been deleted." with a link back to the list]
2. **Primary action** — exactly one filled button: *Train on this version*. Everything else is a secondary menu: *Export…*, *Reuse this recipe*, *Rename*, *Delete*.
3. **Generating** — the header shows the phase progress (T-218) and the primary is *Cancel build*; no panels.
4. **Failed** — "Generation failed" + the message + *Retry* (opens the wizard prefilled) + *Delete*.
5. **Delete** — a dialog that requires typing the version name and lists consequences before the button enables: "212 generated images and 3 exports will be removed. **2 models were trained on this version and will be deleted with it** — any deployment using one of them loses its model and stops answering until you point it at another." [empty: the confirm button stays disabled] [error: 409 "some files could not be deleted; retry"]
