## User story
As a quality engineer running a good-only station, I want to set the station's threshold from a set of images I
have already judged good and bad, so that I stop guessing a number and can say what the setting costs in missed
defects versus false alarms.

## UX flow (LabelDesk words)
1. **Project · Anomaly station** — the station card gains `Calibrate` beside its threshold. [empty: a station
   with no judged anomalies → "Judge at least 5 bad images to calibrate", button disabled with the reason]
2. **Calibration sheet** — left: the judged set (image, verdict, score at the current threshold); right: a slider
   bound to the threshold with a live line "Catches 18 of 20 bad · 6 of 300 good flagged". The slider snaps to the
   recommended point, and a `Use recommended (0.62)` button applies it. [loading: scores compute once, sheet
   shows a skeleton row per image; the slider is disabled until ready] [error: "Could not score this set — 3
   images unreadable", lists them, the current threshold is unchanged]
3. **Apply** — the station threshold updates, the sheet closes, the card shows "Threshold 0.62 · calibrated
   17 Nov" and the station's next inference uses it. [error: save fails → the sheet stays open with Retry and the
   old value]
4. **Re-open** — the sheet remembers the last judged set and shows the last calibration date; a `Recalculate`
   action re-scores without changing anything.
5. **Threshold moved by hand later** — the card label changes to "calibrated 17 Nov · changed since".

## Backend changes
- Models/schema: `AnomalyStation` gains `calibrated_at: datetime | null` and `calibration: JSON | null`
  (recommended threshold, counts, set hash) — one block in `app/schema/training.py`; no backfill.
- Routers: `GET /api/projects/{id}/anomaly/stations/{station_id}/calibration` → scores for the judged set +
  the recommended threshold; `PUT …/calibration` applies `{threshold}` and stamps the date. Both 404 across
  workspaces.
- Services/jobs: `services/anomaly.py` — `calibration_curve(scores, verdicts)` returns per-threshold
  caught/flagged counts and the recommended point (max caught subject to false-alarm budget, default 1 % of
  good). Pure function, no model call.
- Permissions + workspace isolation: `project.train` for writes, `project.read` for the GET; station id from
  another project → 404.
- Secrets/safefetch: none.
- OpenAPI: yes — two routes + schema; regenerate.

## Tests to write first
pytest — `apps/backend/tests/test_anomaly_calibration.py`:
- `test_curve_counts_match_a_known_set` — 20 bad at scores 0.4–0.9, 300 good at 0.1–0.5 → caught/flagged pairs
  asserted at three thresholds.
- `test_recommended_point_respects_the_false_alarm_budget` — budget 1 % of good → the returned threshold is the
  lowest that catches the most bad within budget.
- `test_fewer_than_five_bad_is_refused` — 4 judged bad → 422 naming the minimum, nothing stored.
- `test_apply_stamps_the_date_and_keeps_history` — apply → `threshold`, `calibrated_at`, `calibration` set.
- `test_cross_workspace_station_is_404` — station from workspace B → 404 on GET and PUT.
node — `apps/frontend/tests/anomaly-calibration.test.mjs`:
- `calibrationLine` — 18/20 and 6/300 → the exact shipped sentence.
- `thresholdState` — calibrated then hand-changed → the "changed since" label; never calibrated → no label.

## Acceptance criteria
- [ ] A calibration recommends a threshold from judged images and shows what it catches and flags.
- [ ] Applying it changes the station's threshold and the station uses it on the next run.
- [ ] A hand change after calibration is visible; the date is never silently stale.
- [ ] Empty, loading and error states above all render; a partial score set is named, not hidden.
- [ ] Workspace A cannot see or change workspace B's data (404).
- [ ] Flag off ⇒ no button, no route, manual threshold unchanged.

## Notes for the implementer
"Judged" means the station's existing verdict field; do not add a second labelling concept. The false-alarm
budget is 1 % of judged good images, as a named constant, and the sheet must print it.
