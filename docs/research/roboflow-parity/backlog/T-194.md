## User story
As a reviewer, I want the version screen to read as a list on the left and one version on the right, with a five-step recipe wizard that never hides an earlier answer, so that I can freeze a dataset in one pass and come back to a page that describes it.

## UX flow (LabelDesk words)
1. **Versions** (`/:ws/:project/versions`) — left list, right detail, one page header whose primary is *Generate new version*. [empty: "No versions yet." + "Generate first version"] [loading: 6 skeleton rows at 40 px and a detail skeleton] [error: "Could not load versions — retry" + reference id]
2. **Wizard shell** — a modal, 720 px max, step strip `1 Source · 2 Split · 3 Preprocessing · 4 Augmentation · 5 Output`, footer `Back · Continue · Create version`. Every step stays reachable; earlier steps are never a separate page. [empty: n/a] [loading: the Create button reads "Generating…" and keeps width] [error: server 400 lands on the owning step]
3. **Wizard → step 5** — summary: "N source images · split 70/20/10 · resize 640×640 fit · 3× output ≈ 210 train" plus the version name field (optional, placeholder `v{n}`). [empty: name optional] [loading: n/a] [error: n/a]
4. **Close** — Escape or Cancel closes and creates nothing; re-opening starts at step 1 with defaults.
