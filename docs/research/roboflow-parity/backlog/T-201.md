## User story
As a reviewer with a fixed camera, I want to crop every frame to one region of interest, so that the model stops learning from the operator's dashboard in the corner.

## UX flow (LabelDesk words)
1. **Wizard → step 3 → Crop card** — four percent fields (*Left, Top, Right, Bottom* of the kept region) and an overlay on the step's thumbnail: a dimmed mask outside the rectangle. [empty: full frame (0/0/100/100)] [loading: n/a] [error: "Right must be larger than left." inline on the same row]
2. **Drag on the overlay** — dragging inside the thumbnail sets the four values; keyboard users type them. [error: "Crop must keep at least 5% of the frame." when the box collapses]
3. **Preview** — objects fully outside disappear; a partially kept object shows clipped, and the legend line reads "2 objects clipped".
4. **Remove** — the card's overflow menu.

## Notes for the implementer
Store the crop as fractions of the source, not pixels — the pool mixes 800×600 phone shots and 4000×3000 stills. Round the pixel box with `round()` on both edges and clamp to the image bounds before cropping so no zero-width slice reaches Pillow.
