## User story
As whoever is on support, I want one command that prints what the client and the server each think
they are, so that "it does not work" arrives as a table of ticks and crosses instead of a screenshot.

## UX flow (LabelDesk words)
1. **Terminal** — `labeldesk doctor` prints one line per check as it completes: server reachable, API
   version match, key valid with its scopes, workspace plan and credits left, queue depth and the oldest
   queued job, DB dialect, artifact root free space. [empty: n/a] [loading: one line per check, in
   order, with a spinner on the running one] [error: each failed check prints one sentence and the fix
   ("key revoked — create one in Settings → API Keys"), exit 1; never a traceback].
2. **`--json`** — the same checks as one object, for a support ticket.
3. **Settings → Workspace → Diagnostics** — the same table, read-only, for an admin who cannot open a
   terminal. [error: 403 for a `member`, the tab is hidden by role].

## Backend changes
- Models/schema: none.
- Routers: `routers/workspaces.py` gains `GET /diagnostics` (`workspace.update`) returning
  `{version, db: {dialect}, artifacts: {root_basename, free_bytes}, jobs: {queued, running,
  oldest_queued_age_s}, workers: {count, stale}}`. No absolute paths, no hostnames, no secrets.
- Services/jobs: `app/services/runtime_state.py` gains `diagnostics(db, ws) -> dict` built from
  `config.DATABASE_URL` (dialect only, via `sqlalchemy.engine.url.make_url(...).get_backend_name()`),
  `shutil.disk_usage(config.DATA_DIR)`, `Job` counts, and the worker table when T-972 has landed.
- Permissions + workspace isolation: `workspace.update`; job counts are filtered by `ws.id`.
- Secrets/safefetch: none — the shaper drops any path except the basename of `DATA_DIR`.
- OpenAPI: yes (the diagnostics route).

## Frontend changes
- Route: none (a card in `/:ws/settings/workspace`).
- Nav entry: none.
- Components: `src/features/settings/Diagnostics.tsx` (new) — the check table.

- Feature flag: `task_986`; off ⇒ the card and the route are absent, and `labeldesk doctor` prints only

## Acceptance criteria
- [ ] `labeldesk doctor` prints one line per check and exits 1 when any fails.
- [ ] The diagnostics payload carries no absolute path, hostname or secret.
- [ ] The same table is reachable in Settings for an admin and hidden for a member.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
