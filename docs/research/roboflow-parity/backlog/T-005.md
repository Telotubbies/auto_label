## User story
As the reviewer of any area-5 PR, I want the train entry's refusals, the model row's contents, the
evaluation report and the deployment alias pinned so a training/registry/eval card cannot change a
status code, drop a metric or make a model unaddressable.

## UX flow (LabelDesk words)
1. **Models** — every project model in one table: name, version, architecture, metrics, latency and
   licence; a row opens the run with its live graphs and, when evaluated, the full evaluation panel.
   [empty: train prompt] [loading: stage stepper]
2. **Train** — pick a version, a family/size, epochs, image size, batch and an optional minute cap; the
   estimate prints next to the form; Start submits and the run appears with a job id.
3. **Refusals** — a version that is not generated answers 400 with the fix; an unsupported
   task × family answers 400; an exhausted credit allowance answers 402 before anything is queued.
4. **Evaluation** — after a run the evaluation stages report `done`; a failing evaluation keeps the
   model ready with `eval_error`; the stored report carries the confusion matrix with per-cell images
   and the per-image detections the panel re-derives from.
5. **Deploy** — `production` / `staging` aliases point at one ready model, keep the previous model for
   rollback, and the hosted API resolves `production@<project>`.
6. **Anomaly** — a good-only station trains on normal images only and refuses too few of them.

## Notes for the implementer
`POST …/train` charges credits before creating the row, so the 402 assertion must set `credits_used`
first and then assert `SELECT count(TrainedModel)` is unchanged — not just the status code.
The version-not-ready message is the documented HAVE copy; keep it exact (`training.py:242-243`).
Do not assert `train/options` family *names*: the catalogue is expected to grow (area 5 adds families);
assert the shape and the reason string, never the list.
Migration-sensitive HAVE facts: every run is addressable by `TrainedModel.id` alone (`F5.50`), so no
card may introduce a composite/legacy alias requirement on `GET …/models/{mid}`; `license` is copied
from the family at creation (`training.py:274`); `history` is the array the charts read
(`model_out`, `training.py:99-103`); `eval.confusion.images` is what the panel's drill-down signs
(`_eval_images`, `training.py:131-143`).
