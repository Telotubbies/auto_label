## User story
As an integrator at a plant that will not open an outbound video path, I want to pair a camera or a station box that sends detections and events instead of frames, so that a sixty-camera site fits a twenty-megabit uplink.

## UX flow (LabelDesk words)
1. **Stream detail → `โหมดอุปกรณ์`** (a section on the shipped stream page, renderable by a follow-up card) — the compatible package, the device model and firmware line it needs, and `จับคู่อุปกรณ์`. [empty: an unpaired stream keeps today's server decode and says `ประมวลผลบนเซิร์ฟเวอร์`]
2. **`จับคู่อุปกรณ์`** — shows a one-time token exactly once (`คัดลอกโทเคนนี้ตอนนี้ — จะไม่แสดงอีก`), then the device reads `จับคู่แล้ว` with its firmware and model version. [loading: `กำลังสร้างโทเคน` under a second] [error: `โทเคนนี้ถูกใช้แล้ว — สร้างใหม่`] [error: `เพิกถอนการจับคู่แล้ว`]
3. **Events arrive** — `POST /api/edge/events` with the token creates events that carry `ประมวลผลบนอุปกรณ์` and no snapshot unless the payload includes one; the timeline, the rules and the alarm queue read them like any other event.
4. **A rejected package** — `แพ็กเกจถูกปฏิเสธโดยอุปกรณ์ — ACAP เวอร์ชัน 4` names the mismatch at pairing, never a silent disconnect.
5. **A paired stream** — the server-side model picker is disabled with `ประมวลผลบนอุปกรณ์ — ไม่สามารถเปลี่ยนโมเดลจากที่นี่`, because the model now lives on the box.

## Backend changes
- Models/schema: `app/models/edge_agent.py` (new) — `EdgePairing(id, workspace_id, project_id, stream_id, token_hash, token_hint, device JSON {model, firmware, package}, state ('pending'|'paired'|'revoked'), last_seen, created, updated)` with `UniqueConstraint(stream_id)` and `Index(token_hash)`. Register in `models/__init__.py`; `create_all` creates it, no `ADD COLUMN`.
- Routers: `app/routers/edge.py` (new) — `POST /api/ws/{ws}/projects/{project}/streams/{sid}/edge/pair` (manager) → `{pairing_id, token, device_hint}` (the token is returned once and never again); `DELETE …/edge/pair`; `GET …/edge/pair` → state without the token; `POST /api/edge/events` (no session, `Authorization: Bearer <token>`) → 202 `{accepted}`. 401 unknown or revoked token, 422 a payload outside the envelope, 404 a foreign stream or pairing, 429 over the rate limit.
- Services/jobs: `app/services/edge_ingest.py` (new) — `issue(db, stream, user_id)` (32-byte urlsafe token, `hmac`-SHA-256 hash stored, hint = first 6 chars), `verify(db, token)` (constant-time compare over the hash, checks `state == "paired"` and `workspace`/`project`), `ingest(db, pairing, payload)` (validates the T-695 envelope subset: `event{id, ts, kind, rule, summary}`, `objects[]` capped at 50, `model{ref}`; inserts `StreamEvent` with the device id when it is a valid opaque id, `rule` carrying `{"edge": true, "kind": …}`, no snapshot unless a base64 frame under 200 KB is present) and `touch(db, pairing)` for `last_seen`. No job kind.
- Permissions + workspace isolation: pairing needs `c.need("admin")` on the stream's project; the ingest route has no session and is isolated by the token's own `workspace_id`/`project_id` — the token resolves to exactly one stream and one tenant, and any mismatch is 401, never a 403 that confirms a stream exists.
- Secrets/safefetch: `services/secretbox.py` seals nothing here (the token is a hash, not a recoverable secret) but the hashing rules follow it; the inbound path is rate-limited per token (60 requests/minute through `ratelimit`) because a metadata ingest is an unauthenticated-shaped endpoint with a bearer secret.
- OpenAPI: yes — four routes and their schemas.

## Acceptance criteria
- [ ] A stream is paired with a one-time token that is shown once and stored only as a hash.
- [ ] A paired device posts an envelope and one event appears on its stream with the device marker and no server-side decode.
- [ ] An unknown, revoked or mismatched token is 401, and a malformed payload is 422 naming the field.
- [ ] Empty, loading and error states above all render — with no pairing the stream page keeps today's `ประมวลผลบนเซิร์ฟเวอร์` behaviour.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ pairing 404, ingest 401, and every stream decoded on the server as today.

## Notes for the implementer
Owner-hold: BEYOND §4 names this as a non-goal; do not schedule until the owner overrules it. It ships behind `task_edge_analytics` and stays dark by default. If it is ever unheld: pair one stream at a time, return the token exactly once, store only a hash, rate-limit the token at 60/minute, and never trust a payload's `class`/`box` arithmetic — clamp boxes to 0–1 and cap objects at 50. The token is not a password a user can read back; a lost token means re-pair, which is the correct cost for a device credential.
