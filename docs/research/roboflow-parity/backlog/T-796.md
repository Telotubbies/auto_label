## User story
As a project lead closing a delivery, I want to publish one page of charts and prose at a link a customer can open without an account, so that a model handover has a document rather than a screen share.

## UX flow (LabelDesk words)
1. **Insights → Report** (`/:ws/:project/model-insights?tab=report`) — `New report` creates a draft owned by the project. [empty: "Add a block to start the report."] [loading: the draft loads with skeleton blocks]
2. **Publish** — freezes every block's data with the timestamp it was built from, and returns a link that needs no login. [error: a report with no block is 422 "A report needs at least one block."; a revoked link renders "This link is no longer available." with a 404 status]
3. **A later retrain** — the published page keeps its frozen numbers and prints `Data as of {time}`, so history is not rewritten.
4. **Revoke** — one action marks the link dead; new links are new tokens, so an old PDF never points at changed data.
5. **Attach to a model** — the model page and its card (T-789) can reference the report by title and link.

## Backend changes
- Models/schema: `RunReport` (`id, workspace_id, project_id, title, blocks(JSON), status draft|published, token, token_expires, created_by, created, published`) and `ReportBlock` stored inside `blocks` as `{kind, spec, frozen, frozen_at}`; new table in a new `app/models/reports.py`, no `ADD COLUMN`.
- Routers: new `app/routers/reports.py` — `GET/POST …/reports`, `PATCH …/reports/{id}`, `POST …/reports/{id}/publish`, `POST …/reports/{id}/revoke`, and the unauthenticated `GET /api/public/reports/{token}` (404 when expired or revoked).
- Services/jobs: `app/services/reports.py` (new) — `freeze(db, report)` resolves each block's data once through the existing insights services and stores it; `token_for(report)` uses `secrets.token_urlsafe(32)`; block kinds limited to `curves`, `runs_table`, `slice_chart`, `confusion`, `text`, `image`.
- Permissions + workspace isolation: `reviewer` to create and edit, `admin` to publish and revoke; the public route reads by token only and never lists a project, workspace or model id beyond the report's own title and frozen blocks.
- Secrets/safefetch: the public token is the only credential; it expires after 90 days, is revocable, and every read is written to the audit log as `report.view`.
- OpenAPI: yes — regenerate both generated files.

## Tests to write first
pytest — `apps/backend/tests/test_run_report.py`:
- `test_publish_freezes_block_data` — a `runs_table` block, then a new model is trained → the published payload still lists the old row set and `frozen_at` is set.
- `test_public_link_needs_no_session` — publish, then fetch `/api/public/reports/{token}` with no cookie → 200 and only title + blocks.
- `test_revoked_link_is_404` — revoke then fetch → 404 with the stated detail.
- `test_expired_link_is_404` — a token with `token_expires` in the past → 404.
- `test_publish_without_blocks_is_422` — an empty draft → 422.
- `test_public_route_leaks_no_ids` — the payload contains no workspace id, project id, model id or signed image URL unless the block is an `image` block the author added.
- `test_other_workspace_report_is_404` — workspace B edits A's report id → 404.
- `test_flag_off_is_404` — flag off → 404 on every route, public included.
- `test_view_is_audited` — one public read writes one `report.view` audit row.

## Acceptance criteria
- [ ] A report is a document of ordered blocks that can be edited while a draft and frozen on publish.
- [ ] A published report is readable at a token link with no session, and the page shows the timestamp its data was frozen at.
- [ ] Revoking or expiring the token makes the link answer 404, and every read is audited.
- [ ] A report with no block cannot be published.
- [ ] Empty, loading and error states above all render as API states: a draft with no block returns its block list empty, a revoked token is a 404.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no report routes and the public link path is not mounted.

## Notes for the implementer
Freeze on publish, never render live data at the public route: a reader's PDF must not change because someone retrained. The public payload is an allow-list of fields — build it explicitly instead of serialising the ORM row, or a later column becomes a leak.
