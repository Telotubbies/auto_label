## User story
As a labeler, I want to fix one corner of an existing polygon, so that a five-vertex mistake does not cost a full redraw.

## UX flow (LabelDesk words)
1. **Editor canvas — polygon selected** — each vertex is a dot; dragging one moves it (T-124). Hovering an edge shows a hollow insert dot at the nearest point on that edge.
2. **Insert a vertex** — double-click the edge (or the insert dot) adds a vertex there without changing the outline. `Enter` still closes a polygon being drawn; on an existing polygon it adds no vertex.
3. **Remove a vertex** — `Alt`-click a vertex, or right-click it and choose **Remove point**. A polygon with three vertices refuses: toast "A polygon needs at least three points". Removing keeps the ring closed and the remaining vertices in order.
4. **Drag an edge** — dragging the edge midpoint moves both of its endpoints by the same delta (an edge translate), never bends the neighbouring edges.
5. **Editor → Objects tab → Geometry** — with a polygon selected, the panel lists its vertices with index, `x%`/`y%` and a **Remove** button per row, plus **Add point**. This is the keyboard-only path: Tab into the list, `Enter` on a row selects the vertex, `Remove` deletes it, and the canvas never needs a pointer. [empty: an image label has no geometry block] [error: removal below three points is disabled with the reason in `title`]
6. **Saved shape** — the polygon is still `{kind: "polygon", points: [...]}` with 3–10,000 normalised points; no schema change.

## Acceptance criteria
- [ ] Double-clicking an edge inserts a vertex exactly under the pointer and leaves the outline unchanged.
- [ ] `Alt`-click and the Objects-panel Remove button both delete a vertex; a triangle refuses with a readable reason.
- [ ] Dragging an edge midpoint moves only that edge's two endpoints.
- [ ] Every edit is one undo step, marks the image dirty and survives a reload with the same coordinates.
- [ ] Empty, loading and error states above all render: no polygon selected → no vertex list; a locked annotation → the list is read-only.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] No flag: an option inside the existing editor.
- [ ] Keyboard-only path: Tab to the vertex list → select a row → `Remove` → `Ctrl+Z` → `Ctrl+S`.

## Notes for the implementer
Insert must land *on* the edge (linear interpolation at the projected point), not at the raw pointer, or a double-click near a long edge visibly dents the outline. The minimum is three points for a polygon and the message names the limit.
