## User story
As an ML engineer with one GPU, I want to know whether a model will fit before I download it, install the
engine with a plan I can read, and send the chosen segmenter straight to auto-label, so that the hub
answers "will this run here?" instead of showing a catalogue.

## UX flow (LabelDesk words)
1. **Inference hub** (`/:ws/inference`) — four tabs, the host card states GPU, VRAM and disk as the worker
   reported them. [empty: a host that has reported nothing says so, with the command to register it].
2. **Calculator** — pick a GPU preset, a model and a batch size; the result gives VRAM, throughput and the
   assumptions in plain words. [error: a combination that cannot fit says "does not fit" before install].
3. **Engines** — select an engine, review the plan (versions, disk, time, what will be skipped), then
   confirm. The install job shows progress and a log. [error: an incompatible host is blocked with the
   reason before the button exists].
4. **Models** — filter by task, family, licence and fit; the licence badge is visible on the row.
5. **Download** — a model with a disk check; the progress card says what will be reclaimed.
6. **Segmentation** — the catalogue lists segmenters with VRAM and provisioned state; "Use for auto-label"
   opens the auto-label dialog with the model preselected.
7. **Auto-label** — the dialog shows the model, the class prompts and the preview before the batch.
8. **Back to the hub** — the installed engine and the model now show their provisioned state.

## Backend changes
- None; engine and model jobs run on the harness's instant `engine_apply` / `model_pull` handlers, which
  write the same rows and log lines the real worker writes. No download, no network, no Ollama.
- OpenAPI: no.

## Frontend changes

- API client: none.

## Acceptance criteria
- [ ] The calculator names its assumptions and refuses a combination that cannot fit.
- [ ] The engine plan is readable before confirmation; confirming shows progress and ends in a provisioned
      state.
- [ ] The model catalogue shows licence and fit; a download is blocked when disk is insufficient.
- [ ] "Use for auto-label" opens the dialog with the model preselected and the prompts filled.
- [ ] Steps ≤ 10 and time ≤ 240 s; numbers recorded.
- [ ] Empty, loading and error states: no host inventory, a busy install, an incompatible host, a failed
      download with a retry.
- [ ] No console error; no request to `huggingface.co`, `pypi.org` or a registry (asserted by the socket
      guard); no Ollama string in the UI.
- [ ] Workspace isolation: a hub enabled for A is absent in B; B's route answers 404.
- [ ] Flag off ⇒ the rail entry and every hub route are absent with the "not available" sentence.
