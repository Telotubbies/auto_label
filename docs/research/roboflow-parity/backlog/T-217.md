## User story
As a reviewer, I want each row in the version list to say what it froze and how it differs from the previous version, so that I can pick the right one without opening three of them.

## UX flow (LabelDesk words)
1. **Versions list** — each row: `v3 · release-640`, date, "212 images · 96 source", a single delta chip against the previous version (`+6` or `−2` generated images), a one-line recipe digest ("640×640 fit · 3× · 4 aug"), and a status pill while it is not ready. [empty: "No versions yet." + "Generate first version"] [loading: six 64 px skeleton rows] [error: "Could not load versions — retry" + the request's reference id]
2. **Generating row** — progress bar with the phase word from the job (`Preprocessing · 42%`), a Cancel action, and the row still selectable so the request stays inspectable.
3. **Failed row** — status pill + "Generation failed" + the error line truncated to two lines; selecting it shows the full message and a Retry that opens the wizard prefilled from its settings.
4. **Completion** — when a row flips from generating to ready while the screen is open, one toast fires: "Version v3 is ready — 212 images." (never repeated on refetch).
5. **Export in flight** — the row shows a small "export…" chip from the export job map; no link unless the role may export.

## Notes for the implementer
The delta compares **generated image counts**, newest vs the next older row in the list — not source images — and hides itself on the oldest row. Round nothing: `stats.images` is already an integer.
