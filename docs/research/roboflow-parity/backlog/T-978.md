## User story
As an ML engineer, I want to group a sweep of runs under a name, so that "the october retrain" is one
thing I can open, tag and hand to a reviewer instead of twelve job ids.

## UX flow (LabelDesk words)
1. **Project → Experiments → "New experiment"** — name, optional note, optional tags; the first
   experiment in a project is offered as `default` so training always has somewhere to land. [empty:
   "no experiments yet — every training run lands in `default`" with the create button] [loading:
   skeleton rows] [error: duplicate name — "an experiment called `qa-sweep` already exists here" with a
   link to it].
2. **Row menu** — rename, edit tags, edit note, archive. Rename keeps the id, so a run's link never
   breaks. [error: a blank or > 120-char name is refused inline, not by a server round-trip].
3. **Attach** — a training run or a batch inference run records the experiment it belongs to; the
   experiment page lists those runs newest first.

## Backend changes
- Models/schema: new table `experiments` in `app/models/project.py` — `id`, `workspace_id` (FK,
  indexed), `project_id` (FK, indexed), `name` (120), `note` (Text, default ""), `tags` (JSON, default
  list), `archived_at` (Float, nullable), `created_by`, `created`, `updated`; unique
  `(project_id, name)`. Registered in `models/__init__.py`.
- Routers: `app/routers/experiments.py` (new), prefix `/api/ws/{ws}/projects/{project}/experiments`:
  `GET ""` (list, `?include_archived=0|1`), `POST ""`, `GET /{id}`, `PATCH /{id}`
  (`name|note|tags`), `POST /{id}/archive`, `POST /{id}/restore`. Name rules: 2–120 chars, trimmed,
  409 on duplicate with the existing id in the body.
- Services/jobs: `app/services/experiments.py` (new) — `ensure_default(db, project, user_id)`,
  `get(db, project, id)`, `attach(db, project, run_or_job, experiment_id)` (writes the column area 1
  owns), `out(exp)`.
- Permissions + workspace isolation: read `project.read`; create/rename/archive `project.train`; every
  query filtered by `project_id` from `project_ctx` so a foreign id is a 404.
- Secrets/safefetch: none.
- OpenAPI: yes.

## Acceptance criteria
- [ ] An experiment can be created, renamed, tagged, noted, archived and restored; the id never changes.
- [ ] A duplicate name is a 409 that names the existing experiment.
- [ ] Every run started in a project without an experiment lands in `default`, created on demand.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
