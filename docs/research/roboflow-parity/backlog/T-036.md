## User story
As a visitor from a shared link, I want a real dataset page — what it is, its classes, its licence and a few images — with one obvious action to copy it, so that the link is worth sharing.

## UX flow (LabelDesk words)
1. **Dataset page** (`/d/:ws/:project`, signed out) — landing shell: workspace crumb, project name as H1, type chip, `128 images · 4 classes`, description (paragraphs as written), class chips with counts, licence block and a citation line with `Copy citation`, then a 12-image sample grid (click a tile → lightbox with the caption `Sample from this dataset`).
2. **Primary action** — `Copy this dataset into my workspace` in the header and repeated once under the samples. Signed out → `/login?next=<page>`; signed in → the copy dialog (T-037).
3. **States** — [loading: title skeleton, chip row skeleton, 12 tile skeletons] [error: `This dataset is not available.` with `Browse public datasets` — used for 404 and for a project that was unpublished] [empty: dataset with no images → `No sample images yet.` while description, classes and licence still render]
4. **Not signed in, private link** — same not-available screen; the page never says whether the project exists.
5. **Mobile 375** — title wraps to two lines max with `more`; samples become a 2-column grid; CTA is full width above the fold.

## Acceptance criteria
- [ ] The page renders description, type, class counts, licence, citation and up to 12 samples from the public payload only.
- [ ] The CTA is the single loud element; signed-out visitors are sent to login and return to the same page.
- [ ] Empty, loading and error states above all render (including unpublished → not available).
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — the page shows nothing the endpoint did not return.
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
- [ ] 375 px: no horizontal scroll, title capped at two lines.

## Notes for the implementer
This is not an app screen: no rail, no top bar job tray. Use the landing shell. A private project must be indistinguishable from a missing one.
