## User story
As a plant IT engineer, I want to pair a 15-inch panel to one station with a six-digit code, so that the panel can show that station and nothing else without handing the floor a login.

## UX flow (LabelDesk words)
1. **Pairing is created on the station page** — `POST …/kiosk/devices` returns a six-digit code valid for ten minutes; the station page T-671 already draws shows it with `พิมพ์รหัสนี้บนแผงภายใน 10 นาที`. [empty: `ยังไม่มีแผงที่ผูกกับสถานีนี้`] [error: `สร้างรหัสไม่สำเร็จ — ลองอีกครั้ง`]
2. **The panel pairs** — it posts the code and its own label once and keeps the returned token in its own storage; the server stores only a hash. [error: `รหัสไม่ถูกต้องหรือหมดอายุ — ขอรหัสใหม่ที่หน้าสถานี`]
3. **The panel boots** — `GET /boot` returns the station, its line and site, the shift in force, the locale `th`, the open lot, the last unit, the reason list, one sample crop per defect class and the camera state, in one call. [loading: `กำลังเชื่อมต่อสถานี`] [error: `เชื่อมต่อสถานีไม่ได้ — แจ้งผู้ดูแล`]
4. **The panel records a disposition** — `POST /disposition` writes through T-710's lot record; a closed lot is 409 with the same sentence the desktop screen shows. [error: `ล็อตนี้ปิดแล้ว — ยังบันทึกไม่ได้`]
5. **A revoked panel** — every route answers 403 `แผงนี้ถูกยกเลิกแล้ว — แจ้งผู้ดูแลระบบ`, and the panel clears its token.

## Backend changes
- Models/schema: `app/models/kiosk.py` (new) — `KioskDevice(id, workspace_id, project_id, station_id, name, token_hash, pair_code, pair_expires, locale, paired_by, paired_at, last_seen, revoked, created)`; register in `models/__init__.py`; `create_all` makes the table, no `ADD COLUMN`.
- Routers: `app/routers/kiosk.py` (new) — admin side under `/api/ws/{ws}/projects/{project}/kiosk` (`POST /devices` → `{id, code, expires}`, `GET /devices`, `DELETE /devices/{id}`), all `require_flag("task_station_kiosk")`; panel side under `/api/kiosk` (`POST /pair` `{code, name}` → `{device, token}` once, `GET /{id}/boot`, `POST /{id}/disposition`, `POST /{id}/heartbeat`), authenticated by `X-Kiosk-Token` through a `kiosk_ctx` dependency. 401 for a wrong code or token, 403 for revoked, 409 for a closed lot, 422 for an unknown disposition or a station-less device.
- Services/jobs: `app/services/kiosk.py` (new) — `new_pair(db, station, user_id)` (code from `secrets.randbelow`, `pair_expires = now() + 600`), `pair(db, code, name)` hashing the token with `security.api_key_hash`, `boot(db, device) -> dict`, `disposition(db, device, body, user_id)` delegating to `lots.record`, `touch(db, device)`. Defect sample crops come from `Image` rows whose annotations carry the class, one per class, through `security.sign_path`. No job.
- Permissions + workspace isolation: creating and revoking a device needs `project.settings` and the station must belong to this workspace; the panel routes derive the workspace from the device row and never accept a workspace, project or station id from the client — a device id from another workspace is 401/404, never a cross-tenant read.
- Secrets/safefetch: `services/secretbox.py` is not used — the device token is a bearer credential, not a provider secret, so it is stored as `security.api_key_hash` and compared by exact hash lookup like `ApiKey`; the boot payload contains signed frame URLs and no token, secret or credential. No URL is fetched.
- OpenAPI: yes — two routers and their schemas.

## Tests to write first

- `test_pairing_returns_a_token_once_and_stores_only_its_hash` — create a device on `labeldesk-demo/ppe-detection`, pair with the code → 200 with a `token`; the stored `token_hash` is not the token and the same code cannot pair twice.

- `test_heartbeat_records_last_seen` — heartbeat moves `last_seen` forward.
- `test_the_prefixes_are_hidden_while_the_flag_is_off` — both `/kiosk` prefixes are 404.

## Acceptance criteria
- [ ] A station administrator mints a six-digit code, the panel pairs once, and only a hash of the token is stored.
- [ ] One `GET /boot` gives the panel everything it draws: station, line, site, shift, locale, open lot, last unit, reasons, class crops and camera state.
- [ ] A disposition from the panel lands in the same lot record as the desktop screen, and a closed lot refuses it with 409.
- [ ] Empty, loading and error states above all render — an empty lot is `lot: null`, not a 404, and a station with no classes returns `classes: []`.
- [ ] Workspace A cannot see or change workspace B's device or station (404, not 403, for a foreign device id on the admin route; 401 for a foreign panel token — never a cross-workspace read).
- [ ] Flag off ⇒ both prefixes 404, no device can pair, and the station page is exactly today's.

## Notes for the implementer
R7: the token is the whole authorisation, so it is bound to one device row and one station, it is never returned by `GET /boot`, and revocation is checked on every request rather than cached. Store only the hash (`security.api_key_hash`), issue it once, and make the pair code expire in 600 seconds. Rate-limit `/pair` per client ip through `ratelimit.limit` so a six-digit code cannot be walked. The panel's locale is `th` on the device row, not the browser's preference: a shared panel has no account to read a preference from.
