## User story
As anyone opening a project, I want the one button in the header to name the next real task, so that I never again see "Train Model" offered on a project with no labels.

## UX flow (LabelDesk words)
1. **Header** — `PPE Detection · Object detection · 40 uploaded · 24 approved` and a single primary whose label is a sentence: `Label 40 images`, `Review 16 labels`, `Create a version`, `Train on v1`, `Test the model`. [empty: a project with no images reads `Upload 20 images` and the primary opens the upload stage]
2. **Right column (360)** — a dataset health ring (`24 approved of 40`, colour plus the number), the latest run (`v1 · mAP50 0.81 · +0.04 vs v2`), a `Blocked by` list (at most three rows, each linking to its fix) and `Recent activity` (five rows). [empty: "No run yet — train when the dataset is clean." / "Nothing is blocked."]
3. **A labeler** — the primary is `Start labelling` and links to the board filtered to their batches; the header never offers train.
4. **A project whose health report is stale** — the ring shows the age next to it ("3 days ago") and a `Run health check` link. [error: a failed health call renders "Health unavailable" with `Retry`, not a zero ring]

## Acceptance criteria
- [ ] The header renders exactly one primary and its label changes with the project's state and the caller's role.
- [ ] The aside shows the health ring with a number, the latest run with a delta, at most three blockers and five activity rows.
- [ ] Every aside row links to the screen that fixes it; no row is decorative.
- [ ] The column collapses below the board under `xl` and does not push the board off a 1024 px screen.
- [ ] Empty, loading and error states above all render: no run ⇒ the empty sentence; loading ⇒ three skeleton blocks; a failed health call ⇒ "Health unavailable" with `Retry`.
- [ ] Workspace A cannot see workspace B's data: the aside reads only the current project's payloads; a foreign slug renders not-found.
- [ ] Flag off ⇒ the grid redirect stands and no aside renders.
