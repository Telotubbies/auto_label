## User story
As a shift leader, I want pieces inspected, rejects, first-pass yield and the top reason per station for this shift, so that the number my manager is measured on is on one screen at shift start.

## UX flow (LabelDesk words)
1. **Stream analytics → `กะการผลิต`** (`/:ws/:project/insights?tab=stream`) — a shift picker (`A`/`B`/`C` or the station's own windows), a date and a station filter; the tiles read `ตรวจแล้ว 1,204 · ไม่ผ่าน 41 · อัตราผ่านครั้งแรก 96.6 % · เหตุผลหลัก รอยขีดข่วน`. [loading: `กำลังคำนวณกะ`] [error: `โหลดข้อมูลกะไม่สำเร็จ`]
2. **`ยังไม่มีคำตัดสิน`** — a shift where the station ran but nobody confirmed reads `กะนี้ยังไม่มีคำตัดสิน — สถานีทำงานแต่ยังไม่มีใครยืนยัน`, never `0 %` and never `100 %`. [empty: that sentence per station]
3. **The comparison** — each tile carries the delta against the previous shift (`+0.4 % จากกะก่อน`) and a link into the events filtered to that station and shift. [empty: the first shift of a day reads `ไม่มีกะก่อนหน้าให้เทียบ`]
4. **`ส่งออก CSV`** — the shift as a CSV with one row per station and shift, reconciled against an MES. [error: `ส่งออกไม่สำเร็จ — ลองอีกครั้ง`]
5. **A station with no shift windows** — reads `ยังไม่ได้ตั้งหน้าต่างกะ` and is grouped under `ทั้งวัน`, so the board works before anyone configures a calendar.

## Backend changes
- Models/schema: none — the shift windows ride in `PlantStation.shift` (`{"template": "A", "windows": [{"code": "A", "from": "06:00", "to": "14:00"}, …]}`, written by `PATCH /plant/stations/{id}` from T-670).
- Routers: `app/routers/shift.py` (new), prefix `/api/ws/{ws}/projects/{project}/shift`, `dependencies=[Depends(require_flag("task_shift_board"))]`; `GET ""?date=&tz_offset=&station=` → `{shifts: [codes], rows: [{station_id, station, shift, inspected, rejected, yield, top_reason, previous_yield, decided}], totals}`; `GET "/csv"` with the same filters → a CSV download through `services/csvsafe`. 422 for a bad date or a `tz_offset` outside ±840.
- Services/jobs: `app/services/shift.py` (new) — `window_for(station, at, tz_offset)` (an all-day window when the station has none, midnight wrap supported), `rows(db, project, date, tz_offset, station=None)` grouping `StreamEvent.verdict` by station and shift, `yield = accept / (accept + reject)` with `None` when nothing was decided, `top_reason` from the counts, `previous_similar(...)` for the delta. Pure functions on plain dicts so the node test can mirror them.
- Permissions + workspace isolation: `project.streams` (the same gate as stream analytics); every row joins through the project's stations and streams, filtered by `workspace_id` + `project_id`, so another tenant's verdicts never enter a tile.
- Secrets/safefetch: none — the CSV is escaped through the existing `services/csvsafe` so a reason code cannot inject a formula.
- OpenAPI: yes — two routes and their schemas.

## Acceptance criteria
- [ ] The board shows inspected, rejected, first-pass yield and the top reason per station and shift for the chosen date.
- [ ] A shift with events but no verdicts reads the "no verdicts" sentence, never 0 % or 100 %.
- [ ] Each row carries the delta against the previous shift and links into the events behind it, and the CSV downloads.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no shift panel and the analytics page is today's.

## Notes for the implementer
Yield counts **verdicts**, not events: one verdict is one piece, and an event without a verdict is an alarm, not a part. That is why `decided == 0` must say so out loud — "no data" and "zero rejects" are the two readings that get a line manager to stop a shift. Boundaries are the station's shift windows in the viewer's `tz_offset`, so a night shift at 23:00 is the night shift and not tomorrow. Copy: `shift.title`=`กะการผลิต`, `shift.inspected`=`ตรวจแล้ว`, `shift.rejected`=`ไม่ผ่าน`, `shift.yield`=`อัตราผ่านครั้งแรก`, `shift.topReason`=`เหตุผลหลัก`, `shift.empty`=`กะนี้ยังไม่มีคำตัดสิน — สถานีทำงานแต่ยังไม่มีใครยืนยัน`, `shift.noPrevious`=`ไม่มีกะก่อนหน้าให้เทียบ`, `shift.delta`=`{d} จากกะก่อน`, `shift.export`=`ส่งออก CSV`, `shift.exportFailed`=`ส่งออกไม่สำเร็จ — ลองอีกครั้ง`, `shift.loading`=`กำลังคำนวณกะ`, `shift.error`=`โหลดข้อมูลกะไม่สำเร็จ`, `shift.noWindows`=`ยังไม่ได้ตั้งหน้าต่างกะ`, `shift.allDay`=`ทั้งวัน`.
