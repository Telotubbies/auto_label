## User story
As a Thai-first labeler, I want Thai project and class names to wrap to two lines and then show a "more" affordance, so that a name is never cut mid-word into something that reads as a different word.

## UX flow (LabelDesk words)
1. **Stage rail, project card, batch row** — a long Thai name wraps to at most two lines at line-height 1.6; if it still does not fit, a `…more` button appears and reveals the full name in a tooltip or a one-line sheet. [empty: a name with no characters renders an em dash, never an empty box]
2. **Project switcher and breadcrumb** — the existing one-line ellipsis stays for Latin names, and Thai names use the same two-line rule inside the switcher panel.
3. **Classes panel** — a Thai class name keeps its full text; the hotkey digit remains visible next to it.
4. **Long Latin identifiers** (filenames, ids) — still truncate with one ellipsis; the rule is about grapheme-safe text, not about width.

node — `apps/frontend/tests/thai-text.test.mjs`:

## Acceptance criteria
- [ ] A 40-character Thai project name renders two lines and then "more"; no character is split from its mark.
- [ ] Thai text keeps line-height 1.6 everywhere it renders; no `leading-none` on a Thai-bearing element.
- [ ] `excerpt()` is the only path that shortens a display string; `slice()` on user text fails the test.
- [ ] Latin filenames still truncate to one line with an ellipsis, unchanged.
- [ ] Empty, loading and error states above all render: an empty name renders an em dash, a loading row renders a skeleton bar of the same two-line height.
- [ ] Workspace A cannot see or change workspace B's data — N/A: no request is made.
- [ ] No flag: truncated Thai is a defect, not a variant.

## Notes for the implementer
`Intl.Segmenter` is in Node 18+ and every target browser, so no dependency is needed; fall back to `Array.from(text)` when the constructor is missing (it still cuts on code points, which is better than code units). The clamps belong on the wrapper element, never on the `<a>`/`<button>` itself, or the focus ring gets clipped.
