## User story
As a labeler, I want to grab any polygon, rotated box or keypoint on the canvas and move it, so that correcting a shape does not mean retyping numbers in a panel.

## UX flow (LabelDesk words)
1. **Editor canvas** — with the select tool and one shape selected: a box keeps the existing Transformer; a polygon gets a vertex dot per point plus a translucent body drag; a rotated box gets eight handles on its rotated corners/edges; a keypoint annotation gets one grabbable dot per placed joint. Handles are 6 px on screen at any zoom (`radius / zoom`).
2. **Drag a polygon body** — the whole ring translates, clamped inside the image; every vertex moves by the same delta, so the shape is identical.
3. **Drag a rotated-box corner or edge handle** — the box resizes along its own axes; the angle never changes, the opposite corner stays put, and a drag below 0.2% snaps to the minimum.
4. **Drag a joint** — only that joint moves; a dot for an occluded joint stays a hollow half-circle, and an absent joint (visibility 0) is not draggable at all.
5. **Keyboard nudge** — with an annotation selected, `←`/`→`/`↑`/`↓` nudge it 1 px of the source image, `Shift` plus the arrow nudges 10 px; with nothing selected the same keys keep navigating images. [error: a nudged shape at the edge stays clamped; the key does not block navigation afterwards]
6. **Locked rows** — a locked annotation draws no handles and ignores both drag and nudge.

## Acceptance criteria
- [ ] A polygon, rotated box and keypoint can each be moved by dragging on the canvas, and the saved JSON changes only in the expected coordinates.
- [ ] A rotated-box resize keeps its angle and its opposite corner; a sub-minimum drag snaps to the minimum instead of inverting.
- [ ] Arrow keys nudge a selected shape by 1 px (10 px with Shift) and still navigate images when nothing is selected.
- [ ] A locked annotation shows no handles and ignores drag and arrow nudges, with the existing lock message.
- [ ] Empty, loading and error states above all render: no selection → no handles; image still decoding → handles hidden until the image is ready.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — unchanged save path.
- [ ] No flag: an option inside the existing editor.
- [ ] Keyboard-only path: Tab into Objects → pick a row → arrow-nudge → `Ctrl+S` → `→` next image.
