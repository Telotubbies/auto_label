## User story
As a workspace admin, I want to change one field and see the per-GPU memory, the fits verdict and the
tokens/s estimate update, with the assumptions always visible, so that I can answer "will this model run
on our card" without a spreadsheet.

## UX flow (LabelDesk words)
1. **Calculator tab** — two columns at ≥ 1024 px: form left, results right. At 375 px the form stacks
   above the results behind a `Show estimate` button.
2. **Model source** — `Preset model` (catalogue list from the Model tab's data once T-1010 lands; until
   then a short built-in list of Qwen2.5-VL 7B, Llama 3.1 8B, Gemma 2 9B, a 70B and `Custom`) or
   `Custom`. Choosing a preset fills params, layers, KV heads, head dim and context and makes them
   read-only with an `Edit as custom` action.
3. **Inputs** — params (B), active params (B, MoE, collapsed under `Advanced`), precision (select),
   context, batch, concurrent users, prompt/output tokens, GPU preset (select, ends with `Custom`),
   GPU count, tensor parallel, engine (`vLLM`, `llama.cpp`, `SGLang`, `TensorRT-LLM`, `Custom overhead`).
   [error: a field out of range → inline sentence under the field, focus moved to it, no request].
4. **Results** — verdict chip `Fits` (success) / `Does not fit` (warning tone, not error); per-GPU table
   with weights, KV cache, activations, framework overhead, total, usable; a second row for `All GPUs`;
   then `Decode` (memory-bound, compute-bound, estimate with `90–220 tok/s`) and `Time to first token`.
   [loading: results keep the previous numbers with a subtle `Updating…` pill; a first load shows three
   skeleton rows] [error: "The estimate did not run." + `Retry`, with the server's sentence when it is a
   422].
5. **Assumptions panel** — collapsed by default on desktop, expanded on mobile; every default and factor
   with its value, and a `How this is calculated` link to the three sources (new tab,
   `rel="noreferrer"`). Copy at the top: "Estimate, not a benchmark."
6. **Copy as text** — copies the input summary and the result table as plain text for a chat or an email.
7. **Empty** — before the first estimate: one line "Set a model and a card to see whether it fits." and
   nothing else. No auto-run on mount.

## Tests to write first
node — `apps/frontend/tests/inference-calc.test.mjs`:
- `test_form_errors_mirror_the_server_ranges` — context 0, batch 0, TP 3 with 4 KV heads, usable 1.5
  each produce the same sentence the 422 carries; a valid form produces `{}`.
- `test_a_preset_fills_the_geometry_and_can_be_detached` — `presetToForm('qwen2.5-vl-7b')` fills five
  fields with `source: 'preset'`; `toRequest` marks them fixed; `detach` keeps the values and switches
  `source: 'custom'`.
- `test_verdict_copy_is_a_sentence_not_a_bare_boolean` — `fits: true` → "Fits on this card with 2.9 GB
  spare."; `false` → "Does not fit: 12.4 GB short." (uses the numbers from the result).
- `test_copy_text_includes_every_input_and_the_range` — the copied string contains the context, batch,
  TP and both the estimate and the range, and ends with "Estimate, not a benchmark."
- `test_custom_gpu_reveals_three_fields` — `preset === 'custom'` yields VRAM, bandwidth and TFLOPS in
  `fieldErrors` as required; a preset does not.

## Acceptance criteria
- [ ] One field change updates the result without a full-page reload; an invalid field never sends.
- [ ] Per-GPU rows and the total are visible; the verdict is a sentence with the spare or shortfall.
- [ ] Assumptions and the three source links are always reachable, and "Estimate, not a benchmark."
      is on the panel.
- [ ] Empty state before the first run; loading keeps the previous numbers; error offers Retry.
- [ ] 375 px: no horizontal scroll, form above result, table scrolls with a sticky label column.
- [ ] Light/dark pass, focus visible on glass, AA contrast at 12 px, no new token or hex.

## Notes for the implementer
Debounce the request at 250 ms and cancel the previous one; the endpoint is cheap but the form is not a
metronome. Do not compute the maths in the browser "to save a round trip": the API is the only place
the formulas live. Format GiB to one decimal and tok/s to an integer; never show a decimal that implies
precision the estimate does not have.
