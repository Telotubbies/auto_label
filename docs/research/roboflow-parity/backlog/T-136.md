## User story
As a labeler, I want to grab several shapes at once, so that a conversion or a re-order applies to the group instead of one box at a time.

## UX flow (LabelDesk words)
1. **Canvas, select tool (the hand)** — plain drag on empty canvas still pans. `Shift` + drag draws a marquee rectangle and selects every annotation it intersects; the rectangle is dashed in the primary colour and disappears on release. [empty: a marquee over nothing clears the selection]
2. **Shift + click** — adds or removes one shape from the selection, on the canvas and in the Objects list. `Ctrl/Cmd` + click does the same, so both habits work.
3. **Selection readout** — the Objects header reads "3 selected" instead of the plain count, and each selected row is highlighted. The canvas draws a filled outline on each selected shape, and the primary selection (last clicked) keeps the transform handles from T-124.
4. **Objects list keyboard** — `Shift` + `↑`/`↓` extends the selection by a row, `Shift+Home`/`Shift+End` to the ends; `Esc` collapses back to the primary selection, then clears it.
5. **Editing with several selected** — hide, lock and delete from a row act on the whole selection after one confirm ("Hide 3 objects?"), and deleting is one undo step. Transform handles still belong to the primary only; dragging one shape while three are selected moves just that shape.
6. **Where selection resets** — changing image, changing tool to a drawing tool, or clicking empty canvas clears the whole set.

## Acceptance criteria
- [ ] A marquee selects every shape it touches and `Shift`/`Ctrl`-click adds or removes one, on the canvas and in the list.
- [ ] The list header and every selected row show the multi-selection; the primary keeps the transform handles.
- [ ] Hide, lock and delete act on the whole selection behind one confirm and undo in one step.
- [ ] Selection clears on image change, on switching to a drawing tool and on an empty-canvas click; `Esc` collapses then clears.
- [ ] Empty, loading and error states above all render: a marquee over empty space clears rather than keeping a stale set.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — no endpoint.
- [ ] No flag: an option inside the existing editor.
- [ ] Keyboard-only path: focus the Objects list → `Shift+↓` → `Delete` → confirm.

## Notes for the implementer
`selId` stays the primary selection so the existing Transformer, geometry panel and keyboard relabel keep working; `selIds` is additive. Marquee uses intersection, not containment — a partially covered box is what the user meant to grab.
