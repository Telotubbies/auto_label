## User story
As a project owner, I want publishing to require a licence and an explicit confirmation that the images are safe to show, so that private or personal data cannot go public by a single mis-click.

## UX flow (LabelDesk words)
1. **Publish** — `POST /projects/{p}/publish {license, pii_ack}` → `{visibility: "public", publicPath: "/d/:ws/:project"}`; audit `project.publish`.
2. **Reverse** — `POST /projects/{p}/unpublish` → `{visibility: "private"}`, `publicPath: null`; audit `project.unpublish`. The public page 404s from the next request.
3. **Refusals** — licence outside the allowed set → 422 `Choose a licence for published data.`; `Proprietary` → 422 `Proprietary datasets cannot be published.`; missing `pii_ack` → 422 `Confirm the content check before publishing.`; a workspace whose policy forbids public projects → 403 `This workspace does not allow public projects.` (enforcement arrives with 7-F7.60; read the flag defensively and leave the comment naming that card).
4. **Unchanged data** — publishing never changes images, classes or annotations; unpublishing never deletes anything.

## Backend changes
- Models/schema: none owned here. `projects.visibility` and `license` exist; `allow_public_projects` is 7-F7.60's column — this card only reads it via `getattr(ws, "allow_public_projects", True)`.
- Routers: `routers/publishing.py` (new), prefix `/api/ws/{ws}/projects`: `POST /{project}/publish`, `POST /{project}/unpublish`; both return `{visibility, license, publicPath}`.
- Services/jobs: `services/publishing.py` (new) — `ALLOWED_LICENSES = ("CC BY 4.0", "CC BY-SA 4.0", "CC0 1.0", "MIT", "Public Domain")`, `publish(db, ctx, project, license, ack)`, `unpublish(db, ctx, project)`, each writing its audit row; one commit.
- Permissions + workspace isolation: `project.settings` (manager) plus `workspace.project.create` is not required; a project slug from another workspace 404s before any change; the audit row is written under the caller's workspace.
- Secrets/safefetch: none.
- OpenAPI: yes.

## Frontend changes
