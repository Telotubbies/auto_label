## User story
As a video labeler, I want to drag an action's span on its class row, so that I can see at a glance what overlaps what.

## UX flow (LabelDesk words)
1. **Project → Video → a video row → Actions tab** — the page keeps its frame list under **Frames**, and gains **Actions**: a player on top and a multi-row timeline below, one row per project class that has segments plus an empty row per remaining class. Header: filename, duration, playhead time, and a save state. [empty: a video with no segments shows the rows and the hint "Drag on a class row to mark an action"] [loading: the video is still extracting → a progress line, the tab disabled] [error: segments failed to load → message + retry]
2. **Drag on a class row** — a draft bar follows the pointer; releasing creates the segment with that class (T-146), and the header reads "Saving…" then "Saved". A drag shorter than 0.2 s is discarded.
3. **Refine** — drag either edge of a bar to move it; drag the middle to move the whole span; the playhead can be scrubbed and `i` / `o` set the selected segment's in/out points at the playhead. `Delete` removes the selected segment after a confirm.
4. **Playback** — `Space` plays and pauses, `←`/`→` step one frame, and the playhead follows the video; a segment under the playhead is highlighted in every row it exists in.
5. **Overlaps** — two classes may overlap; the timeline stacks them and the tooltip names both. Two segments of the same class that overlap are drawn with a warning stripe and a one-line note, but are not blocked (a hand-off moment is legitimate).
6. **Zoom** — `+`/`-` change the pixels-per-second (1× to 20×), and the ruler labels adapt (`0:00`, `0:05`, …); the whole video always fits at 1×.
7. **Review** — with `project.review`, each segment carries a small approve/reject control; rejecting asks for a reason (T-148 shows the review list).

## Acceptance criteria
- [ ] Dragging on a class row creates a segment of that class, and a sub-0.2 s drag creates nothing.
- [ ] A bar's edges and body can be dragged; `i`/`o` set in/out at the playhead; `Delete` removes after a confirm.
- [ ] One row per project class, overlaps across classes stack, and same-class overlaps are marked without being blocked.
- [ ] `Space`, `←`/`→` and the zoom keys work, and the header never says "Saved" while a write is pending.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ the Actions tab is absent and the Frames view is unchanged.
- [ ] Keyboard-only path: open Actions → Tab to a row → `i` → `→` x10 → `o` → `Ctrl+S`-equivalent save lands automatically.

## Notes for the implementer
Pixels per second is the single source of truth for every geometry calculation — put it in `segmentMath.ts` and never compute an x from a percentage in the component. Debounce a body drag's PATCH to the release, but persist an edge drag on pointer-up only, so 60 PATCHes a second never happen.
