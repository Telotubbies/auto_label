## User story
As a line operator wearing gloves on a shared 15-inch panel, I want one picture, one instruction in Thai and two targets big enough for a thumb, so that I decide one piece without a menu, a scroll or a word of English.

## UX flow (LabelDesk words)
1. **`/kiosk` with no token** — the panel shows one centred field: `พิมพ์รหัส 6 หลักจากหน้าสถานี` and a numeric keypad of 48 px keys, then stores the token. [loading: `กำลังเชื่อมต่อสถานี`] [error: `รหัสไม่ถูกต้องหรือหมดอายุ — ขอรหัสใหม่ที่หน้าสถานี`]
2. **`/kiosk` with a token** — a full-bleed frame on `.canvas-well`, the strip above it reads `สถานี {station} · กะ {shift} · ล็อต {lot}` (or `ยังไม่มีล็อตที่เปิดอยู่`), the verdict badge sits on the picture, and two 96 px buttons sit below: `ผ่าน` and `ไม่ผ่าน`. Nothing else is on the screen and nothing scrolls at 1024×768. [empty: `ยังไม่มีภาพ — กล้องกำลังทำงาน`] [error: a 401 clears the token and returns to pairing]
3. **`ไม่ผ่าน`** — the picture is replaced by a grid of defect tiles, each a real crop of that class with its Thai name under it, 96 px tall; tapping one records the reject and returns to the next unit. [error: `เลือกประเภทของเสียก่อน` if the tile was double-tapped into a save race, and no second write happens]
4. **Camera offline** — the whole panel becomes the reason and the person to call: `กล้องออฟไลน์ — โทรหา {name} {phone}` on a destructive surface, with `ลองอีกครั้ง` as the only action, because a blank screen makes an operator improvise. [error: `ไม่ได้รับเบอร์ผู้ดูแล — แจ้งหัวหน้ากะ` when the station has no supervisor set]
5. **A successful save** — `บันทึกแล้ว` for 800 ms, then the next unit; the counters under the strip move by one and never jump.

## Backend changes
- Models/schema: none — T-715 shipped the device and T-710 the record.
- Routers: none — the panel reads `GET /api/kiosk/{id}/boot` and writes `POST /api/kiosk/{id}/disposition` and `POST /api/kiosk/{id}/heartbeat`.
- Services/jobs: none.
- Permissions + workspace isolation: the only credential is the device token in `X-Kiosk-Token`; the route is public (outside `WorkspaceGate`), so a missing or foreign token is 401 and the panel shows pairing, never a workspace's data.
- Secrets/safefetch: none — the token lives in the panel's own storage and is sent only to `/api/kiosk`.
- OpenAPI: no — no route changes (T-715 generated them).

## Frontend changes
- Route: `apps/frontend/src/routes/public.routes.tsx` — one `<Route path="/kiosk" element={<Kiosk />} />` before the wildcard, deliberately outside the authenticated tree so a panel never needs a person to sign in.
- Nav entry: none.
- Components:
  - `apps/frontend/src/features/kiosk/Kiosk.tsx` (new) — pairing, boot, the frame, the two verdict targets, the defect-tile grid, the offline panel, the 5-second boot poll.
  - `apps/frontend/src/features/kiosk/kioskView.ts` (new, pure) — `phase(boot)`, `stripLine(boot)`, `decisions(boot)`, `tiles(boot)`, `offlineLine(station)`, `targetClass(size)`.
  - `apps/frontend/src/lib/i18n.ts` — the keys below, added in Thai first because this is the one surface with no language switch.
- API client: `apps/frontend/src/lib/api/kiosk.ts` (new) — `kioskPair(code, name)`, `kioskBoot(id, token)`, `kioskDisposition(id, token, body)`, `kioskHeartbeat(id, token)`.
- Glass: only the thin top strip is `Glass strength="chrome"`; the frame is solid on `.canvas-well`; the verdict targets are the shipped `Button` at `h-24 w-full text-sm` with the success and destructive roles; defect tiles are `Card` with `classColor(i)` as the left rule and `chipTone('status', 'ng')` on the name. No hover-only affordance — focus and pressed states are visible, every target is at least 48 px, no new token, no hex, no icon library beyond `lucide-react`.
- Feature flag: `task_station_kiosk`; off ⇒ `/kiosk` redirects to `/login` and no device can boot.

## Acceptance criteria
- [ ] A paired panel boots straight into its station, shows one frame and two verdict targets, and never needs a menu, a scroll at 1024×768 or an English word.
- [ ] Every target is at least 48 px, the defect tiles carry real crops in the station's order, and one gesture decides one piece.
- [ ] A camera offline replaces the picture with the reason and the supervisor's number, and no affordance is hover-only.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see workspace B's station — a foreign device id is 404, not 403, and a foreign or expired token is 401 and shows pairing (never a cross-workspace read).
- [ ] Flag off ⇒ `/kiosk` redirects to `/login` and the panel cannot pair.

## Notes for the implementer
The kiosk renders `t()` with the device locale (`th`) rather than the account preference, because a shared panel has no account. Targets: verdict 96 px tall, defect tile 96 px tall, keypad key 48 px — never a hover state as the only signal. Copy: `kiosk.pair`=`พิมพ์รหัส 6 หลักจากหน้าสถานี`, `kiosk.pairFailed`=`รหัสไม่ถูกต้องหรือหมดอายุ — ขอรหัสใหม่ที่หน้าสถานี`, `kiosk.connecting`=`กำลังเชื่อมต่อสถานี`, `kiosk.strip`=`สถานี {station} · กะ {shift} · ล็อต {lot}`, `kiosk.noLot`=`ยังไม่มีล็อตที่เปิดอยู่`, `kiosk.pass`=`ผ่าน`, `kiosk.fail`=`ไม่ผ่าน`, `kiosk.pickClass`=`เลือกประเภทของเสีย`, `kiosk.classMissing`=`เลือกประเภทของเสียก่อน`, `kiosk.saved`=`บันทึกแล้ว`, `kiosk.empty`=`ยังไม่มีภาพ — กล้องกำลังทำงาน`, `kiosk.offline`=`กล้องออฟไลน์ — โทรหา {name} {phone}`, `kiosk.noSupervisor`=`ไม่ได้รับเบอร์ผู้ดูแล — แจ้งหัวหน้ากะ`, `kiosk.retry`=`ลองอีกครั้ง`, `kiosk.closed`=`ล็อตนี้ปิดแล้ว — ยังบันทึกไม่ได้`.
