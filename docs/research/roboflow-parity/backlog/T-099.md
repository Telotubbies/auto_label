## User story
As a reviewer, I want to open a near-duplicate cluster, see the frames side by side and tag or remove the
extras, so that "these 7 are the same still" becomes a two-click fix instead of a guess.

## UX flow (LabelDesk words)
1. **Dataset · Health · Duplicates** — the cluster list from T-098 with a threshold slider and the summary
   line; restricted to reviewers. [empty: "No near-duplicates at this threshold"]
2. **Dataset · Health · Duplicates · cluster** — a side sheet shows the images in one row with split chips
   and a checkbox each; the first image is marked "Keep" by default. [loading: 3 image skeletons]
   [error: an image whose file is unreadable shows a placeholder with "cannot compare"]
3. **Cluster sheet** — **Tag as duplicate** adds `duplicate` to the ticked images; **Open in editor** opens
   one image in its project editor; **Remove from project** uses the existing count-bearing confirm.
   [error: a remove that fails on a locked file reports the survivors]
4. **Cluster sheet** — after an action the cluster recomputes in place; when it drops below two images the
   sheet closes with "Cluster resolved" and the list count updates. [empty: list becomes the empty copy]
