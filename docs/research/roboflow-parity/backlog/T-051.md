## User story
As a maintainer, I want one box-IoU function, so that a fix to the maths lands once instead of in four
files that already drifted apart in signature.

## Tests to write first
pytest — `apps/backend/tests/test_boxes.py` (new):
- `test_identical_boxes_are_one` — `box_iou((0,0,10,10),(0,0,10,10)) == 1.0`.
- `test_disjoint_boxes_are_zero` — touching edges give 0.0, not a negative or a ZeroDivision error.
- `test_half_overlap_is_one_third` — `(0,0,10,10)` vs `(5,0,10,10)` → 1/3 within 1e-9.
- `test_zero_area_box_is_zero` — a 0×0 box never raises (`union > 0` guard).
- `test_symmetry` — `box_iou(a,b) == box_iou(b,a)` for a shuffled pair.
- `test_existing_callers_keep_their_numbers` — the four modules' own suites already assert scores; run
  `test_evaluate.py`, `test_health.py`, `test_suspects.py`, `test_insights_models.py` unchanged and
  expect them green with no edit.
