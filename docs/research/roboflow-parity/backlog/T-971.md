## User story
As a reviewer comparing two runs, I want to see which interpreter, library versions and GPU each run
used, so that a metric jump has a suspect instead of a shrug.

## UX flow (LabelDesk words)
1. **Model detail → Environment** — a small table: python, the six packages that matter (torch,
  ultralytics, cuda runtime, numpy, opencv, pillow), CUDA/driver, GPU name, container image digest,
  worker id. [empty: a run recorded before this shipped — "environment not recorded"] [loading:
  skeleton rows while the model loads] [error: the worker reported nothing — "the worker did not
  report its environment"; no invented versions].
2. **Compare two models** — a one-line diff above the metric table ("torch 2.6.0 → 2.7.0"), only when
  both sides recorded one.
3. **Copy** — "copy as requirements" puts a pinned list on the clipboard, refused when the record is
  empty.

## Backend changes
- Models/schema: `trained_models.env_fingerprint` JSON, nullable, default NULL — one `ADD COLUMN`
  block in `app/schema/training.py` beside `TRAINED_MODELS`. Backfill: none (older rows stay NULL and
  render the "not recorded" state).
- Routers: `routers/remote.py` `complete` accepts an optional `env` object on the worker payload
  (≤ 4 KB, whitelisted keys only) and copies it onto the model; `routers/training.py` `model_out`
  returns `env` (the whitelisted subset) and never the raw blob.
- Services/jobs: `app/services/env_fingerprint.py` (new) — `capture() -> dict` for the local worker
  (importlib.metadata versions, `torch.version.cuda`, `torch.cuda.get_device_name`, image digest from
  `LD_IMAGE_DIGEST` when set), `sanitise(raw) -> dict` (whitelist + drop paths/URLs through
  `errors.safe_text`).
- Permissions + workspace isolation: `project.models` to read (same gate as the model row);
  404 for a foreign model id.
- Secrets/safefetch: none — nothing is fetched; paths and URLs are stripped, never stored.
- OpenAPI: yes.

## Acceptance criteria
- [ ] A remote-completed run stores and shows python, package versions, GPU and worker id.
- [ ] A run recorded before this ships shows "environment not recorded" and no copy button.
- [ ] No filesystem path, URL or secret reaches the payload (stripped through `safe_text`).
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.
