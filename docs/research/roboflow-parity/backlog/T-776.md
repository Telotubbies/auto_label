## User story
As a labeler stuck mid-task, I want the changelog since my last visit, a search over the docs and a report button that already knows where I am, so that I do not lose the canvas to ask a question.

## UX flow (LabelDesk words)
1. **Help button in the top bar** (every screen) — opens a side sheet with three tabs; `F1` opens it too. The button is always in the same place, which is what the accessibility rule about consistent help asks for. [loading: the sheet opens instantly with a spinner only in the tab body]
2. **`What's new`** — dated entries with a title, two lines of text and a deep link into the exact setting ("Open Settings → Privacy"). Entries newer than the last visit carry a dot; opening the tab clears it. [empty: "No updates since you joined."]
3. **`Docs`** — a search field over a shipped index of page titles and headings; five results at most, each opening a panel beside the current screen without navigating away from the canvas. [empty: "Nothing matches — try a shorter word."] [error: "The docs index could not load." with `Open the docs site`, never a blank tab]
4. **`Something is wrong`** — a textarea plus a read-only summary of route, workspace and the last twenty console lines. `Send report` returns "Report sent — reference FB-<id>. The details were copied to your clipboard as a backup." [error: "The report could not be sent — the details are on your clipboard."]
5. **Flag off** — no Help button, no `F1` binding, and the feedback route 404s.

## Backend changes
- Models/schema: `app/models/support.py` (new) — `HelpFeedback(id, workspace_id, user_id, route, console_tail, note, user_agent, created, state)`; register the module in `app/models/__init__.py`.
- Routers: `app/routers/help.py` (new) — `POST /api/ws/{ws}/feedback` (201 with `{reference}`; 422 when the note is empty or the console tail is over 8 kB), `GET /api/ws/{ws}/feedback` (owner/admin: the last fifty rows for this workspace).
- Services/jobs: `app/services/help.py` (new) — `redact(lines) -> str` (drops anything matching a bearer token, `ld_…` / `ld_pub_` / `ld_test_` key, `password`, `secret` or an `Authorization` header), `file_report(db, c, body) -> HelpFeedback`, `reference(row) -> str`.
- Permissions + workspace isolation: any member may file into their own workspace; the list needs `workspace.audit`; every read filters `HelpFeedback.workspace_id == c.ws.id` and another workspace's reference is 404.
- Secrets/safefetch: `services/help.redact` is mandatory on the server as well as the client — a paste is untrusted input.
- OpenAPI: yes.

## Tests to write first
pytest — `apps/backend/tests/test_help_feedback.py`:
- `test_a_report_returns_a_reference` — member login → `POST /feedback` with a note and a two-line console tail → 201 with `FB-` prefix and one row stamped with the workspace and user.
- `test_tokens_in_the_tail_are_redacted` — a tail containing `Authorization: Bearer abc`, `ld_pub_xxx` and `password=hunter2` → the stored `console_tail` contains none of the three values and still has the surrounding lines.
- `test_an_empty_note_is_422_and_an_oversized_tail_is_422` — `note=""` → 422; a 9 kB tail → 422.
- `test_a_labeler_cannot_read_the_list` — labeler `GET /feedback` → 403; owner → 200.
- `test_a_foreign_reference_is_404` — workspace B's feedback id under workspace A → 404.
- `test_flag_off_hides_both_routes` — with `task_in_product_help` off → `POST` and `GET` both 404.

node — `apps/frontend/tests/help-panel.test.mjs`:
- `test_docs_search_returns_five_at_most` — `searchDocs('a')` on a fixture of twelve entries returns five, each with a title and a path.
- `test_an_empty_query_returns_nothing` — `searchDocs('')` is `[]` and the tab renders its hint instead of every page.
- `test_unseen_counts_only_newer_entries` — `unseen(entries, lastVisit)` counts the entries dated after the visit and zero when the visit is now.
- `test_the_display_redactor_matches_the_server` — `redactForDisplay(['Bearer abc', 'ok line'])` keeps the second line and replaces the first.

## Acceptance criteria
- [ ] The Help panel opens from the top bar and with `F1` on every screen without leaving the current page.
- [ ] `What's new` marks unseen entries and clears the mark when read; deep links land on the named setting.
- [ ] Docs search returns at most five results and an unmatched query shows the no-match line, not an empty pane.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no button, no key binding, routes 404, and the top bar is unchanged.

## Notes for the implementer
Bind `F1` and the button, not `?`: the editor already owns `?` for its shortcut overlay (`Editor.tsx:785`), and a second listener would make one press do two things. The console tail is captured by wrapping `console.error`/`console.warn` at app start, not by reading a devtools buffer — redact on both sides, and never send a screenshot, because capturing one needs a dependency this card does not add.
