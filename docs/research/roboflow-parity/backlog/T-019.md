## User story
As a labeler, I want the tool rail to offer only shapes my project trains on, so that I never draw work the model discards.

## UX flow (LabelDesk words)
1. **Editor** (`/:ws/p/:project/annotate/:imageId`) — the tool rail lists, per type: detection `Select · Box · Polygon · Smart polygon`; instance segmentation `Select · Polygon · Brush · Smart polygon`; semantic segmentation `Select · Polygon · Brush · Smart polygon`; classification `Select` only, with the class chips filling the rail (no canvas drawing); keypoints `Select · Keypoints`; action recognition `Select · Segment`; anomaly `Select · Good`. The default tool is the first drawing tool.
2. **Keyboard** — the number shortcuts map to the visible tools only (`B` box, `P` polygon, `K` keypoints, `M` brush, `1–9` classes); a hidden tool's key does nothing and is absent from the shortcut sheet.
3. **A shape converted by the server** — after a save that returns `converted_from: "polygon"`, a one-time inline hint sits over the canvas: `Saved as a box — detection learns boxes.` and disappears on the next edit. [error: `This project type does not store keypoints.` for a refused shape; the shape is not added]
4. **Empty project** — rail identical, canvas shows `Upload images to start labelling.` (existing empty state, unchanged). [loading: rail renders while the project payload resolves, tools default to Select until the type arrives]

## Acceptance criteria
- [ ] The rail and the shortcut sheet show the same per-type tool list, with no dead keys.
- [ ] A classification project offers no drawing tool and applies labels by clicking a class chip.
- [ ] Empty, loading and error states above all render (rail before type resolves; refused-shape message; conversion hint).
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids) — the editor keeps using the existing scoped image routes.
- [ ] Flag none: every project gets the correct rail; no other editor behaviour changes.
- [ ] An unknown future type falls back to the detection tool set rather than an empty rail.

## Notes for the implementer
