## User story
As a manager watching a 40-minute training run, I want the curve to advance epoch by epoch, so I can stop a run
that has clearly diverged instead of finding out an hour later.

## UX flow (LabelDesk words)
1. **Insights → Training** — select the run that is `training`; its chips and curves advance roughly every 4 s with
   no reload. [empty: a run that has not logged epoch 1 yet keeps `No metrics logged` until the first epoch]
   [loading: the first fetch keeps its skeletons; later refreshes do not flash a skeleton over live curves]
   [error: a failed refresh keeps the last good curve and raises the existing `Training curves could not be
   loaded` banner only after the retry in the query itself has failed]
2. **Wait a minute without touching the page** — the curves keep advancing; the run list's own progress poll is
   unchanged (`Models.tsx:265-268`).
3. **Switch to another tab and come back** — polling paused while the document was hidden and resumes on focus;
   the first render after returning is already current.
4. **Every selected run is finished** — polling stops completely; the tab behaves exactly as today (a single
   focus refetch after 60 s of staleness).
