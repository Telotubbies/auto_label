## User story
As a video annotator, I want one row per tracked object with its keyframes and an exit, so that I can follow one object through the clip and fix a wrong join without hunting frame by frame.

## UX flow (LabelDesk words)
1. **Project → Video → a video → `Tracks`** — a right-hand `Card` with one row per track: class dot, class name, "4 keyframes · 12 derived", frame range, and `Previous` / `Next` keyframe buttons that move the timeline. [empty: "No tracked objects yet — draw an object on two frames and interpolate."] [loading: three skeleton rows] [error: "These tracks did not load." + `Retry`]
2. **`Outside the frame from here`** — sets the exit at the current frame; the row shows `Outside from frame 120` and the derived count after that frame drops to zero. [error: "That frame is before the track's first keyframe."]
3. **Row menu (`Scissors` / `Merge`)** — `Split track here` names the new track, `Merge into` offers the other tracks and asks for confirmation. [error: "Those tracks share no frame, so merging them would hide a gap."]
4. **`Interpolate`** — the toast reports skipped tracks: "18 frames · 24 annotations · 1 track outside the frame".
5. **A video with no frames** — the whole panel shows the empty line and `Interpolate` stays disabled.

## Notes for the implementer
The track list must not become a second annotation editor: it navigates and it renames identity, and every geometry edit stays on the canvas. Use `classColor` for the dot so the identity on this list and the box on the timeline cannot disagree.
