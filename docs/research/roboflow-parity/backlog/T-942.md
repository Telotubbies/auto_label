## User story
As an integrator, I want to send my own question with the image to a vision model I deployed, so that one served model can answer more than the question it was trained with.

## UX flow (LabelDesk words)
1. **Model detail → Try it** — a text field labelled "Question" appears for a vision-language model, pre-filled with the model's default sentence as placeholder; the existing image picker stays. [empty: the field shows the placeholder and the run uses the default] [loading: "Thinking…" on the run button, the previous answer stays visible and dimmed] [error: the adapter's message verbatim, e.g. "the vision endpoint is not reachable", with the endpoint address redacted]
2. **Deploy & test** — the snippet builder adds `&prompt=<your question>` for this family only.
3. **Hosted predict** — `prompt` is accepted for a `vlm`-family model; for any other family the same parameter returns 422 naming it as unsupported, instead of being silently ignored.

## Backend changes
- Models/schema: none.
- Routers: `apps/backend/app/routers/predict_vlm.py` (new) — `POST /api/v1/models/{ref}/invoke` accepting the same image body as `_hosted_infer` plus `prompt: str` (max 2000 chars), 422 when the model's family is not `vlm`, 402 when the plan's `ai_calls` is exhausted. `if body.prompt: ...` then delegates to the existing `_hosted_infer` (`apps/backend/app/routers/training.py:623`) — one call path, not two.
- Services/jobs: `apps/backend/app/adapters/vlm_ad.py` already takes `prompt`; the route passes it through `Resolved.predict(im, prompt=..., classes=...)`. The prompt is not persisted except in the audit note, truncated to 200 chars.
- Permissions + workspace isolation: the same `key_ws(db, api_key, request, "infer")` dependency as `hosted_predict`; `_hosted_model` keeps the workspace filter.
- Secrets/safefetch: none — the adapter talks to the operator-configured VLM URL through its existing client.
- OpenAPI: yes — `python tools/export_openapi.py`, `npm run gen:api-types`.

## Acceptance criteria
- [ ] A VLM model answers a caller-supplied question through the served endpoint, with the image unchanged.
- [ ] A model of any other family returns 422 naming `prompt` as unsupported, before any credit is charged.
- [ ] The prompt never appears in the response, and at most 200 characters of it reach the audit note.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.

## Notes for the implementer
Overlap: none. `prompt` must not be added to the existing `hosted_predict` route: its signature is the documented contract in `Deploy.tsx`, and widening it would change every generated snippet for every family.
Redact the operator's VLM URL from any error the caller sees; the adapter's message is useful internally and is written to the audit row instead.
