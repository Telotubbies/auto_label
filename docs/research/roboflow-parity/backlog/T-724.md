## User story
As a store manager in a promotion changeover, I want every tag on a shelf-edge photo compared with the branch's own price list, so that the print-and-replace list is the mismatch list rather than a walk down the aisle.

## UX flow (LabelDesk words)
1. **`ตรวจราคา`** (`/:ws/:project/ops/price`) — the master is imported once from the branch's CSV; the screen then takes a shelf photo and returns three counts. [empty: `ยังไม่มีรายการราคาในระบบ — นำเข้าไฟล์ CSV ก่อน`] [loading: `กำลังเทียบราคา`] [error: `เทียบราคาไม่สำเร็จ — ลองอีกครั้ง`]
2. **Import** — a CSV of `sku,name,price`; a duplicate SKU inside the file stops the import and names the line. [error: `SKU ซ้ำในไฟล์ที่บรรทัด {n}`]
3. **The result table** — one row per tag: `ตรง`, `ไม่ตรง` (with the shelf price and the master price side by side) or `อ่านไม่ได้`, each with its crop. [empty: `ยังไม่มีป้ายราคาในภาพนี้ — ถ่ายใหม่ให้เห็นป้ายชัด`]
4. **No text reader on this machine** — the screen still lists tags that a person or the OCR pack annotated, and states `ยังไม่ได้ติดตั้งตัวอ่านข้อความบนเครื่องนี้ — ใช้เฉพาะป้ายที่บันทึกไว้` above the table. [error: that sentence, in the warning tone, never a silent zero]
5. **Export** — `ส่งออกรายการที่ต้องแก้` downloads a CSV with the image, the box, the SKU and both prices. [error: `ส่งออกไม่สำเร็จ — ลองอีกครั้ง`]

## Backend changes
- Models/schema: `app/models/retail.py` (new) — `PriceMasterEntry(id, workspace_id, project_id, sku, name, price_satang, currency, updated)` with `UniqueConstraint(project_id, sku)`, `price_satang` an integer (never a float); register in `models/__init__.py`; `create_all` makes the table, no `ADD COLUMN`.
- Routers: `app/routers/retail.py` (new), prefix `/api/ws/{ws}/projects/{project}/price`, `dependencies=[Depends(require_flag("task_price_check"))]`; `POST "/master/import"` (multipart CSV, ≤ 2 MB) → `{imported, replaced}`; `GET "/master?q="` (first 100); `GET "/capabilities"` → `{reader: {available, reason}}`; `POST "/check"` `{image_id}` → `{rows: [{box, sku, shelf_price, master_price, status, crop}], counts}`; `GET "/check/{image_id}.csv"`. 400 for a malformed row or a duplicate SKU (naming the line), 404 for a foreign image, 422 for a price that is not a number.
- Services/jobs: `app/services/pricecheck.py` (new) — `parse_master(data) -> list[dict]` (BOM-tolerant, `services.csvsafe.cell` on write), `read_tags(image) -> list[dict]` from the stored OCR annotations (`keyvalue` with key `ราคา`/`price` plus `sku`), `compare(tags, master) -> list[dict]` with `status` `match|mismatch|unreadable`, `capabilities()` (the reader is unavailable because no OCR engine ships — the same shape as the zxing/asyncua optional drivers), `mismatch_csv(rows)`. No job.
- Permissions + workspace isolation: `project.read` to check, `project.settings` to import a master; the image and the master are resolved through `workspace_id` + `project_id`, so a foreign image is 404.
- Secrets/safefetch: none — the CSV is a local upload and no URL is fetched; the export is escaped so a SKU beginning `=` cannot run in a spreadsheet.
- OpenAPI: yes — five routes and their schemas.

## Tests to write first

- `test_a_master_imports_and_a_duplicate_sku_names_the_line` — a three-row CSV imports `{imported: 3}`; a file with `A100` twice is 400 whose detail contains the line number and no row is written.
- `test_a_matching_tag_reports_the_same_price` — a master `A100 → 2500` satang and an OCR `keyvalue` tag for `A100 25.00` → one row `status: "match"` with both prices in satang.
- `test_a_mismatch_carries_both_prices` — master 2500, tag 2900 → `status: "mismatch"`, `shelf_price: 2900`, `master_price: 2500`.
- `test_a_tag_with_no_price_is_unreadable_not_an_error` — an annotation with no `ราคา` value → `status: "unreadable"` and no exception.
- `test_an_image_with_no_tags_is_an_empty_answer` — `rows: []`, `counts` all zero, 200.
- `test_the_capability_says_the_reader_is_missing` — `GET /capabilities` reports `available: false` with the sentence, and the check route still works.
- `test_the_csv_export_escapes_a_formula_sku` — a SKU `=1+1` is quoted and cannot execute.
- `test_the_routes_are_hidden_while_the_flag_is_off` — 404 for all five.
- `test_an_image_from_another_workspace_is_404` — 404 and no rows.
node — `apps/frontend/tests/price-view.test.mjs`:

## Acceptance criteria
- [ ] A price master imports from CSV and a duplicate SKU is refused with its line number.
- [ ] A check returns one row per tag with match, mismatch or unreadable and both prices where both exist.
- [ ] An image with no tags is an empty answer and a missing text reader is stated, never a silent zero.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's master or image (404, not 403).
- [ ] Flag off ⇒ no route, no nav item, no master table read, and the OCR surfaces are unchanged.

## Notes for the implementer
Money is integer satang everywhere and formatted only in the UI; never store or compare a float. The text reader is genuinely absent in this deployment — do not fake a read from the file name or invent an OCR engine in this card: `read_tags` joins what the OCR pack (task_32) or a person already stored, and `capabilities()` tells the truth about it, exactly like the optional `zxing-cpp` and `asyncua` drivers. Copy: `price.title`=`ตรวจราคา`, `price.import`=`นำเข้ารายการราคา`, `price.emptyMaster`=`ยังไม่มีรายการราคาในระบบ — นำเข้าไฟล์ CSV ก่อน`, `price.dup`=`SKU ซ้ำในไฟล์ที่บรรทัด {n}`, `price.match`=`ตรง`, `price.mismatch`=`ไม่ตรง`, `price.unreadable`=`อ่านไม่ได้`, `price.shelf`=`ราคาหน้าร้าน`, `price.master`=`ราคาในระบบ`, `price.empty`=`ยังไม่มีป้ายราคาในภาพนี้ — ถ่ายใหม่ให้เห็นป้ายชัด`, `price.reader`=`ยังไม่ได้ติดตั้งตัวอ่านข้อความบนเครื่องนี้ — ใช้เฉพาะป้ายที่บันทึกไว้`, `price.export`=`ส่งออกรายการที่ต้องแก้`, `price.exportFailed`=`ส่งออกไม่สำเร็จ — ลองอีกครั้ง`, `price.loading`=`กำลังเทียบราคา`, `price.error`=`เทียบราคาไม่สำเร็จ — ลองอีกครั้ง`.
