## User story
As an AI agent host, I want to discover what this workspace allows, read a project and its labels, and be
stopped by a confirmation before anything is written, so that connecting an agent is a scoped, auditable
decision rather than a leap of faith.

## UX flow (LabelDesk words)
1. **Connect** — an HTTP MCP client with a `write` key reaches `/mcp`; `whoami` returns the workspace and
   the key's scopes.
2. **Discover** — `tools/list` matches the key's scopes: the `read`-only key sees fewer tools than the
   `write` key. [error: a revoked key's next call is refused with a tool error, not a 500].
3. **Read** — `get_project`, `search_images` and `get_labels` return the seeded project's real counts.
4. **Write with confirm** — a label write without `confirm: true` returns its dry run and changes nothing;
   with `confirm: true` it writes one label and the audit row appears.
5. **Spend** — `run_auto_label` without confirmation returns the cost preview and enqueues nothing; the
   harness's instant handler runs it only after confirmation.
6. **Guard** — a cross-workspace id answers 404 as a tool error; a call outside the key's scope is absent
   from the list and refused if invoked anyway.

## Acceptance criteria
- [ ] An agent completes the read journey in ≤ 5 calls and ≤ 60 s against the stub API.
- [ ] Every write and spend tool answers a dry run first and changes nothing until confirmed.
- [ ] The write leaves exactly one audit row naming the tool, the key and the workspace.
- [ ] A revoked key stops working mid-session; a publishable key cannot use the server.
- [ ] A cross-workspace id is a tool error with no data leak; a scope-denied tool is absent and refused.
- [ ] Empty, loading and error states: an empty project returns an empty list, not an error; a malformed
      argument is a tool error naming the field.
- [ ] Workspace isolation: two seeded workspaces; every cross read fails and no write lands.
- [ ] Flag off ⇒ the endpoint answers 404 and the tool list is not reachable; the journey is skipped with
      a named reason.
