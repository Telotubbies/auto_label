## User story
As the design and quality leads, I want one audit of the version wizard, the diff, the export and the
dataset insights, so that a frozen dataset is auditable by reading a screen rather than trusting a number.

## UX flow (LabelDesk words)
1. **Dataset → Versions** (`/dataset?tab=versions`) — the list with delta chips and the one primary.
2. **Wizard** — five steps, the source counts, the split validation, the ordered preprocess pipeline and
   its per-step preview, the summary.
3. **Version detail** — split bar, class counts, recipe summary, diff list, guarded delete.
4. **Export** — the format menu, the job, the download and its size.
5. **Insights** (`/insights`) — charts as filters, table view, CSV, staleness named.

## Acceptance criteria
- [ ] The wizard's five steps are all reachable and the validation message appears at the field that
      caused it.
- [ ] The diff list is readable without opening a second screen and names added and removed images.
- [ ] The export's one primary is Train; export is secondary and its progress is not a page-blocking
      spinner.
- [ ] axe: 0 critical/serious; chart legend text meets 4.5:1; colour is not the only series key.
- [ ] Every chart offers a table view and a CSV; an empty series says so (the A7 contract).
- [ ] The 10 heuristics are scored per screen; no score < 3; the two worst are named.
- [ ] Findings are S1–S4 with evidence; each S1/S2 has a proposed fix card title.
- [ ] P2 and P4 walk the area; SUS-8 and any dead end are recorded.
- [ ] Empty, loading and error states: no versions, a busy wizard step, a failed export with a retry.

## Notes for the implementer
The wizard is one screen with five states; score each step, then score the detail page separately. Do not
merge the two scores.
