## User story
As the owner, I want the last wave's findings, the native-Thai list and one release note that says plainly
what is measured, what is not, and what is still open, so that the go/no-go is a decision I can make in one
read.

## UX flow (LabelDesk words)
1. **Full re-run** — all 13 journeys (smoke and nightly), all 7 audits, the performance report and the Thai
      lint; each result is compared with its previous wave number.
2. **Trends** — steps, time, errors and SUS-8 per persona are shown against Q1–Q3; a drop of 10 points is a
      regression finding.
3. **Dedupe and severity** — as in Q1–Q3; the file also closes findings fixed since their wave.
4. **Release checklist** — no open S1/S2, axe clean, budgets met or attributed, Thai list with the native
      reviewer, R7 items closed, the gate green with numbers.
5. **Go/no-go memo** — `docs/qa/releases/q4.md`: what shipped, the measured table, the open items, the
      owner decisions still pending, and the honest limits from the program §12.

## Acceptance criteria
- [ ] Every journey and audit has a Q4 result and a Q1–Q3 comparison; a missing result is a finding.
- [ ] The trend table shows steps, time, errors and SUS-8 per persona; every 10-point drop is filed.
- [ ] Every previously filed S1/S2 is closed with a test name or carried into the memo with a reason.
- [ ] The release checklist is complete; an open S1 means "not shippable", stated in the first line.
- [ ] The memo names what the program cannot prove (no real users, fake workers, manual screen reader,
      Thai review pending) without softening it.
- [ ] Owner decisions still pending are listed with the default that shipped meanwhile.
- [ ] Empty, loading and error states: their Q4 results are included, not only the happy paths.
- [ ] Workspace isolation: a leak anywhere is S1 and the memo says "not shippable".
- [ ] The gate is green with numbers in the memo; no claim without command output.

## Notes for the implementer

release, the PR and the push. Keep the memo under two pages; the tables carry the detail.
