## Notes for the implementer
`ProjectSettings` is not a blind swap: today it skips the request entirely for a workspace admin
(`enabled: !admin`). `useProjectPermissions` has no such switch, so add the `enabled` guard *inside* the
hook as an optional `enabled` argument if the extra request for admins matters, or accept one extra
`GET /permissions` for admins and say so in the report. Do not silently start 403-ing for managers.
