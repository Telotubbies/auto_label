## User story
As an ML engineer watching a run, I want the credits consumed and the last lines the worker wrote, so that a run that looks stuck is diagnosable without leaving the page.

## UX flow (LabelDesk words)
1. **A running run → detail card** — "1.2 of 3 credits · 36 min GPU · epoch 14 of 40", the two cost numbers updating with the poll, the epoch from the existing progress.
2. **Log panel** — a disclosure *Worker log* opens the last 200 lines in a monospace block with a *Follow* toggle and a *Copy* action. [empty: nothing written yet ⇒ "The worker has not logged anything yet."] [loading: the panel shows three grey lines] [error: "The log could not be read" + Retry, the run card unaffected]
3. **A quiet run** — if the last line is older than the watchdog's limit the panel prints "No output for 12 min — the run may be stalled." in amber.
4. **Sanitised lines** — absolute paths, URLs and tokens never appear: the panel shows "[path hidden]" where the API redacted one.

## Backend changes
- Models/schema: none — the worker already writes `Job.result.stages` and `Job.error`; the log lives in a new append-only JSON field `job.result.log_tail` (last 50 lines) written by the handler's `mark()` helper.
- Routers: `GET {P}/jobs/{jid}/log?lines=200` → `{lines: [{t, text}], truncated: bool, last_at: float, stalled: bool}`; **404** for a foreign job; `lines` clamped to 1..500.
- Services/jobs: `handlers/training.py::run_train` appends `{"t": seconds, "text": ...}` for each stage and each epoch line (epoch, loss, mAP if present), capped at 50 entries and 400 chars per line. `errors.safe_text` (already exists) sanitises each line before it is stored — no raw exception text, no path. `services/train_failure.stalled` computes `stalled` from `job.result.heartbeat` (remote) or `started` (local) against `config.REMOTE_JOB_TIMEOUT_S`.
- Permissions + workspace isolation: `c.perm("project.models")` (the same grant that already sees eval payloads); foreign job or project → 404.
- Secrets/safefetch: none — sanitisation is `errors.safe_text`, no outbound call.
- OpenAPI: yes — regenerate both files.

## Acceptance criteria
- [ ] A running (and a finished) run shows credits used, GPU minutes and epoch in one line.
- [ ] The log tail is readable, copyable, and free of absolute paths, URLs and tokens.
- [ ] A quiet run says so in amber before the watchdog kills it.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no spend line, no log route, today's progress card only.

## Notes for the implementer
Store the tail, not a stream: 50 entries × 400 chars is the whole budget, and it rides the existing `Job.result` JSON. Do not add a file-backed log — a second storage path would need its own sweeper.
