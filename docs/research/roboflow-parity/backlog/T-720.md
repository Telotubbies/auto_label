## User story
As a security lead, I want the incident row to say "acknowledged by Somchai at 14:12" or "waiting, tier 2 in 8 minutes", and to set who is paged second, so that I can prove an alert was handled instead of hoping it was.

## UX flow (LabelDesk words)
1. **The incident row** — on `/:ws/:project/streams/:sid` each event carries its ladder chip: `รอรับทราบ · ขั้นถัดไปใน 8 นาที` or `รับทราบแล้วโดย สมชาย เมื่อ 14:12`. [empty: an event that never went to a channel reads `ไม่ได้แจ้งเตือน` and carries no chip] [error: `สถานะการรับทราบไม่พร้อม — ลองอีกครั้ง` in place of the chip only]
2. **Settings → Alerts → `นโยบายการยกระดับ`** — the LINE channel card gains a ladder editor: tier 1 is the channel itself, then up to two more rows, each a channel select and a wait in minutes. [empty: `ยังไม่มีขั้นที่ 2` with an add button] [error: `ต้องมี channel secret ของ LINE ก่อนตั้งนโยบายยกระดับ` blocks saving and links to the token field]
3. **Saving the ladder** — the card shows the compiled sentence `ขั้นที่ 1 ทันที · ขั้นที่ 2 หลัง 10 นาที ในกลุ่ม หัวหน้ากะ`. [loading: `กำลังบันทึกนโยบาย`] [error: `บันทึกไม่สำเร็จ — {reason}` and the form keeps its values]
4. **A delivery list row** — the history gains its tier and its ack column, so an unanswered alert is visible without opening the stream. [error: `อ่านประวัติไม่สำเร็จ — ลองอีกครั้ง`]
5. **A channel without a secret** — the editor is dimmed with the lock line rather than hidden, so the user knows why.

## Backend changes
- Models/schema: none — T-714 shipped the ack row and the delivery columns.
- Routers: none — the page reads `GET /alerts` (with the new delivery fields), patches `settings.escalation` through the existing `PATCH /alerts/{cid}` and reads `GET /alerts/{cid}/deliveries`.
- Services/jobs: none.
- Permissions + workspace isolation: the settings card is admin-only as today (`c.need("admin")`), the stream chip is `project.streams`; a delivery id from another workspace is 404 through T-714.
- Secrets/safefetch: none — the page never reads a secret, only the masked preview the API returns.
- OpenAPI: no — no route changes.

## Acceptance criteria
- [ ] An event row states whether it was acknowledged, by whom and when, or when the next tier fires.
- [ ] The ladder editor saves up to three tiers with their waits and prints the compiled sentence.
- [ ] A channel without a secret shows the dimmed editor with the reason instead of failing silently at send time.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's channel or delivery (404, not 403).
- [ ] Flag off ⇒ no chip, no editor, and the Alerts page is unchanged.
