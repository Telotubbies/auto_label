## User story
As a plant quality engineer, I want one station page that lists its cameras, its model, its threshold and today's rejects, so that I can answer "what is on this cell and how did it do today" without opening four projects.

## UX flow (LabelDesk words)
1. **Sites** (`/:ws/sites`) — a two-level tree: site → line → station, each station row reading `กล้อง 2 · โมเดล yolo26n · NG วันนี้ 14`. [empty: `ยังไม่มีไซต์ — เริ่มจากเพิ่มไซต์แรกของโรงงาน`] [loading: `กำลังโหลดโครงสร้างโรงงาน`] [error: `โหลดโครงสร้างไม่สำเร็จ — ลองอีกครั้ง` with a `ลองใหม่` button]
2. **New site / new line / new station** — three dialogs from the tree's `เพิ่ม` menu; the station dialog asks for project, model, threshold (0–1), reject action and reason codes. [error: `โมเดลนี้ไม่พร้อมใช้งาน — เลือกโมเดลที่เทรนเสร็จแล้ว`]
3. **Station page** (`/:ws/stations/:stationId`) — header with the line breadcrumb and a `Glass` action bar; three `Card` sections: cameras (attach / detach, each row an eye link into the stream), model and threshold (a `Select` of the project's streaming models, a range input, a save), and reason codes (chips with add/remove).
4. **An empty station** — the cameras card shows a single `เพิ่มกล้องเข้าสถานี` row instead of a chart, and the counters read `—`, never 0. [empty: `ยังไม่มีกล้องในสถานีนี้`]
5. **Streams wall grouping** (`/:ws/:project/streams`) — when a stream has a station, the wall gains a station filter and each row reads `ไลน์ 2 · Press · Infeed`; with no station the row reads `ยังไม่ผูกสถานี`. [empty: `ยังไม่มีกล้องในโครงการนี้` unchanged]

## Backend changes
- Models/schema: none new — T-670 shipped the tables. This card only reads them through that API; `stream_out` gains `"station": {"id", "name", "line", "site"}` (empty when unattached) so the wall can group without a second request.
- Routers: `GET /api/ws/{ws}/projects/{project}/streams` and `/{sid}` gain the `station` object in `stream_out` (`app/routers/streams.py`, one join on `PlantStation`/`PlantLine`/`PlantSite`); no new route.
- Services/jobs: `services/plant.py` gains `station_label(db, station) -> {"site", "line", "name"}` used by `stream_out`; no job.
- Permissions + workspace isolation: the wall already filters by `workspace_id` + `project_id`; the station join is filtered by the same workspace, so a station in another workspace never appears and a direct `GET /streams/{sid}` from another workspace stays 404.
- Secrets/safefetch: none — camera sources render through the existing `displaySource()`/`creds.mask_source()` masking, and a station page shows no source at all.
- OpenAPI: yes — `stream_out` changes shape; regenerate both generated files.

- `test_group_streams_by_station_keeps_unattached_last` — an unattached stream lands in the `ยังไม่ผูกสถานี` bucket after every named station.

## Acceptance criteria
- [ ] `/ :ws/sites` shows site → line → station and each row reads camera count, model and today's rejects; a station opens at `/:ws/stations/:stationId`.
- [ ] A station page attaches and detaches a camera, saves a model, a threshold and reason codes, and an empty station shows the attach row instead of a chart.
- [ ] The streams wall groups and filters by station and labels an unattached camera `ยังไม่ผูกสถานี`.
- [ ] Empty, loading and error states above all render, including the retry button on the tree's error state.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no `Sites` nav entry, both routes redirect, and the wall shows no station filter and no station label.

## Notes for the implementer
The tree loads three lists in one `useQuery` each (`sites`, `lines`, `stations`) keyed by the site/line id; do not add a combined endpoint. Every user-visible string is a key in `lib/i18n.ts`: `plant.nav.sites`=`ไซต์`, `plant.empty.sites`=`ยังไม่มีไซต์ — เริ่มจากเพิ่มไซต์แรกของโรงงาน`, `plant.loading`=`กำลังโหลดโครงสร้างโรงงาน`, `plant.error`=`โหลดโครงสร้างไม่สำเร็จ — ลองอีกครั้ง`, `plant.action.addCamera`=`เพิ่มกล้องเข้าสถานี`, `plant.empty.cameras`=`ยังไม่มีกล้องในสถานีนี้`, `plant.model.unavailable`=`โมเดลนี้ไม่พร้อมใช้งาน — เลือกโมเดลที่เทรนเสร็จแล้ว`, `plant.delete.blocked`=`ลบสถานีไม่สำเร็จ — ยังมีกล้องผูกอยู่`, `streams.station.unattached`=`ยังไม่ผูกสถานี`.
