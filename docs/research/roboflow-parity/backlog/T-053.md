## User story
As a reviewer, I want review comments and upload errors to read in normal English, so that approving an
image does not stamp a line of garbage into the project's comment history.

## UX flow (LabelDesk words)
1. **Upload dialog** — `no images found (supported: jpg, png, bmp, webp, tif — loose or in a .zip)`;
   `max 2000 files per request — the web uploader sends batches`. [error: these strings are the error]
2. **Annotate board → review action** — approving writes `✓ ` + note; rejecting writes `✗ Rejected: ` +
   note, into `Comment.text`. [empty: no note → today the comment is still written with the prefix only;
   keep that behaviour] [error: none new]
3. **Annotation editors** — `polygon needs 3–10,000 normalised points`, `keypoints need 3–3000 flat
   normalised x,y,v values (v in 0,1,2)`, `obb angle must be a finite number of radians within ±2π`,
   `could not find an object at those points — try clicking nearer its centre`.

## Notes for the implementer
The file is valid UTF-8; the *characters* are wrong. Do not "fix the encoding" of the file, and do not
rewrite it with a different codec — edit the seven literals in place and leave every other byte alone.
Existing rows in `Comment` already contain the corrupt glyph; this card does not backfill them (that is a
data decision for the PM, not a cleanup).
