## User story
As a shift supervisor, I want the project rail to read top to bottom like the work does, so that "Dataset, Versions, Insights, Model insights" stop being four siblings I have to decode.

## UX flow (LabelDesk words)
1. **Any project screen** — the rail opens with the project swatch, name, type and `24 approved`, then the five stages with their numbers, counts and state dots, then a rule, then `Insights`, `Classes & tags`, `Streams`, `Project settings`.
2. **The current stage** — its row is the only tinted pill, and the stage's own page header owns the primary button. No `Train Model` anywhere in the chrome.
3. **A stage the role cannot act on** — dimmed row, lock icon, `aria-label` ending "locked, request access", and a tooltip with the same sentence. Clicking it opens the request-access sheet, it does not redirect silently. [error: a role with no project permission at all gets the existing "You do not have access" panel, not an empty rail]
4. **A count changes while I work** — the stage dot pulses once (opacity only) and the count updates; under `prefers-reduced-motion` neither animates.
5. **Below 1024 px** — the panel collapses to the existing compact strip, which now renders the same five stages with numbers and counts.

## Acceptance criteria
- [ ] Five numbered stages render with count, state word and one line of text; the secondary group holds exactly four entries.
- [ ] The active stage is the only tinted row, and the page header owns the primary button.
- [ ] A locked stage is dimmed, focusable, announced as locked and opens request-access — never a silent redirect.
- [ ] Below 1024 px the compact strip renders the same five stages with numbers and counts.
- [ ] Empty, loading and error states above all render: a project with no data shows `—` counts and `not started`; while facts load, each row keeps its height with a skeleton count; a failed facts call shows the rail with `Retry` and no fake zeros.
- [ ] Workspace A cannot see workspace B's data: the rail reads only the current project's payload; a foreign slug renders "Project not found" instead of a rail.
- [ ] Flag off ⇒ the v2 grouped panel and its top-bar buttons render unchanged.

## Notes for the implementer
The stage dot is a `<span aria-hidden>` inside the row's accessible name — not a `<button>` — because it is not clickable. If a future count needs its own target, it gets a real button with its own label; the 44 px hit area comes from a `::before` inset so the visual height stays 32 px.
