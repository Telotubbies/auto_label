## User story
As a project manager, I want to compose the labeling screen from parts and mark what is required, so that adding a severity field is a form edit instead of an engineering ticket.

## UX flow (LabelDesk words)
1. **Project → Settings → Labeling interface** — a template gallery (`Inspection`, `Defect with severity`, `Document fields`) then the control list, each row editable: label, kind, required, help, default, options. [empty: "No extra fields yet — start from a template or add one."] [loading: three skeleton rows] [error: "This form did not load." + `Retry`]
2. **`Add field`** — appends a control of the chosen kind with a generated key; reordering is drag between neighbours.
3. **`Preview on an image`** — opens the editor with `?preview=form`, rendering the form beside a real image without saving anything. [loading: the preview's image spinner]
4. **`Save`** — a removal that labels still use returns 412 and the row stays with "This field is used by 3 labels — remove it from them first."
5. **Editor, a class selected** — `FormPanel` renders the controls for that annotation: required marker, help text, default value, and a validation message on submit. [error: "severity is required." blocks the save and focuses the field]

## Acceptance criteria
- [ ] A manager composes controls from a template, marks required ones, previews on a real image and saves.
- [ ] Removing a field that labels still use is refused inline with the API count sentence, and the row stays.
- [ ] The editor renders the form beside the canvas, blocks a save on a missing required field and focuses it.
- [ ] Empty, loading and error states above all render: no-fields line, skeleton rows, the preview spinner and the 412/422 messages.
- [ ] Workspace A cannot see workspace B's form: the builder and the panel call this project's route only.
- [ ] Flag off ⇒ no tab, no panel, no save guard and no request.

## Notes for the implementer
Five kinds, no conditional logic: `text`, `number`, `select`, `checkbox`, `rating` cover the inspection, defect and document cases the group file names. Preview must be the real editor, not a mock — a form that renders in settings and not in the canvas is the bug this card exists to prevent.
