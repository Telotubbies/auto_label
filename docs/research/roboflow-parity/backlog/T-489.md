## User story
As a keyboard or motor-impaired user, I want every rail row, dot and row action to be reachable in a predictable order with a 44 px target, so that I can work all shift without a mouse.

## UX flow (LabelDesk words)
1. **Project rail** — Tab enters at the project switcher, then stage 1→5, then the secondary group, then Settings; Shift-Tab reverses exactly. The active stage is focusable once, not twice.
2. **Stage dots and row actions** — each visual 32 px control has a 44 px hit area via a `::before` inset; the visual size is unchanged.
3. **Screen readers** — a stage dot is announced inside its row as "Annotate, 16 to review, needs you"; a table row action is announced as "Assign 4 images"; no icon-only button lacks a name.
4. **Focus visible** — the ring is 2 px offset 2 at ≥ 3:1 on every surface, including on glass and inside a dialog, and it is never clipped by an overflow container. [error: a focused row inside a scroll container scrolls into view because `scroll-padding` accounts for the 56 px bar]
5. **Zoom 200% and forced colours** — no control disappears; the ring becomes the system highlight and the lock icon keeps its text label.

## Acceptance criteria
- [ ] Tab order through the rail is switcher → stage 1…5 → secondary → Settings, and Shift-Tab is the exact reverse.
- [ ] Every icon-only control has an accessible name; every stage dot's name carries the state word and the count.
- [ ] Row actions and rail rows expose a 44 px hit area while keeping their 32 px visual height.
- [ ] The focus ring is visible on glass, inside dialogs and inside scroll containers, and 200% zoom hides no control.
- [ ] Empty, loading and error states above all render: the same labels are used in a skeleton row (`Annotate, loading`) and in a locked row (`Train, locked, request access`).
- [ ] Workspace A cannot see workspace B's data — N/A: no request is made.
- [ ] No flag: an accessibility fix that can be switched off is not a fix.

## Notes for the implementer
The dot stays `aria-hidden` and the accessible name lives on the row: a dot with its own label makes a screen reader read the stage twice per visit.
