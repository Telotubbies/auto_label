## User story
As a quality manager or security lead, I want to mark a clip as evidence with a reason and an expiry, so that retention cannot delete it and an auditor can see who holds it and until when.

## UX flow (LabelDesk words)
1. **Event detail → `คลิป`** (`/:ws/:project/streams/:sid`, the shipped event preview) — the player with the trigger marked, `ดาวน์โหลด MP4`, and `เก็บเป็นหลักฐาน`. [loading: `กำลังประกอบคลิป 12 วินาที`] [error: the 409 shortfall sentence, verbatim from T-680]
2. **`เก็บเป็นหลักฐาน`** — a sheet asks `เหตุผลการเก็บ` and `เก็บกี่วัน` (1–365, default 90), then the panel reads `สมชาย เก็บถึง 17 ก.พ. 2570`. [error: `เก็บได้ 1 ถึง 365 วัน`] [error: `ต้องระบุเหตุผลการเก็บ`]
3. **Held clips list** (`เก็บไว้` on the stream page) — every held clip with its camera, its event time, who holds it and its expiry, plus `ปล่อยคลิป`. [empty: `ยังไม่มีคลิปที่ถูกเก็บ`]
4. **Deleting the stream** — the confirm text now reads that held clips survive; after the delete the held list still opens its files. [error: a hold whose file is gone reads `ไฟล์ของคลิปนี้หายไปแล้ว` and offers no download]

## Backend changes
- Models/schema: `app/models/clips.py` (new) — `EvidenceClip(id, workspace_id, project_id, stream_id nullable, event_id, path, reason, held_by, hold_until, camera_name, station_name, event_ts, summary, created)` with `Index(workspace_id, hold_until)`. Register in `models/__init__.py`; `create_all` creates it, so no `ADD COLUMN` block.
- Routers: `app/routers/clips.py` (T-680 created it) gains `POST /{sid}/events/{eid}/hold` `{reason, days}` → the hold (200); `DELETE /holds/{hid}`; `GET /holds?stream=&project=` → the list. 400 short reason, 422 `days` outside 1–365, 404 no clip to hold, 409 already held by the same caller.
- Services/jobs: `app/services/evidence.py` (new) — `hold(db, event, reason, days, user_id) -> EvidenceClip` (copies the MP4 to `DATA_DIR/clips/held/<id>.mp4` and stores a self-contained row so the hold survives the stream), `release(db, hold, user_id)`, `list_holds(db, project, stream=None)`, `expire(db, now) -> {"removed", "bytes"}`. `app/services/retention.py` calls `evidence.expire(db)` once per pass so an expired hold is removed on the retention tick, not by a new job.
- Permissions + workspace isolation: the hold needs `project.review`; the list needs `project.streams`; `DELETE /holds/{hid}` needs `project.review` and only the holder or a manager may release — a foreign workspace id is 404 through the same workspace + project filter, and `stream_id` is nullable so a hold outlives its stream without leaking another tenant's row.
- Secrets/safefetch: none — one local file copy under `DATA_DIR`, with the `retention._inside` escape check.
- OpenAPI: yes — three routes and their schemas.

- `test_an_expired_hold_is_removed_on_the_retention_tick` — `evidence.expire` past `hold_until` deletes the file and the row and returns the bytes freed.
- `test_the_hold_routes_are_hidden_while_the_flag_is_off` — 404 with the flag off.
- `test_a_hold_from_another_workspace_is_404` — read, release and hold with a foreign id are 404, never 403.

## Acceptance criteria
- [ ] A clip plays with its trigger marked and downloads as MP4; a short pre-roll still states its shortfall.
- [ ] `เก็บเป็นหลักฐาน` stores a reason, a holder and an expiry, and the row reads who holds it and until when.
- [ ] Deleting the stream keeps every held clip openable, and releasing or expiring one removes its file.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no clip section, no held list and no hold route.

## Notes for the implementer
Hold is a **copy**, not a flag on the event: that is what lets it survive `delete_stream`, which erases every event file by design (`routers/streams.py:342-384`). Default the expiry to 90 days, hard-cap 365, and never let a release delete a file another hold points at. Copy: `streams.clip.hold`=`เก็บเป็นหลักฐาน`, `streams.clip.holdReason`=`เหตุผลการเก็บ`, `streams.clip.holdReasonRequired`=`ต้องระบุเหตุผลการเก็บ`, `streams.clip.holdDays`=`เก็บกี่วัน`, `streams.clip.holdRange`=`เก็บได้ 1 ถึง 365 วัน`, `streams.clip.heldUntil`=`{who} เก็บถึง {date}`, `streams.clip.heldEmpty`=`ยังไม่มีคลิปที่ถูกเก็บ`, `streams.clip.heldMissing`=`ไฟล์ของคลิปนี้หายไปแล้ว`, `streams.clip.release`=`ปล่อยคลิป`, `streams.clip.released`=`ปล่อยคลิปแล้ว`, `streams.clip.heldTab`=`เก็บไว้`.
