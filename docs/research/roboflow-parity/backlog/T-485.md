## User story
As a labeler starting a shift, I want the first screen to open with the work waiting for me, so that I stop reading five KPI cards and a tour button before I find the queue.

## UX flow (LabelDesk words)
1. **`/:ws`** — 40 px title with one primary (`New project`, role-gated), then **Needs you**: at most four `TaskRow`s (`PPE Detection · Annotate · 40 to label · Start labelling`). Each row's left bar carries the stage colour and the label carries the stage word, so colour never means two things. [empty: "You're all caught up." with one sentence naming what will appear here]
2. **Below the queue** — project cards with the five-count pipeline line (`40 · 16 · 1 · 1 · —`) and one stage chip for the next step; a slim usage strip; then one **At a glance** block (images, annotated, models, deployments) — not two blocks with the same name.
3. **A workspace with no projects** — one empty state with one primary (`Create your first project`) and one shortcut (`Start from the demo set`); the getting-started checklist no longer competes with it. [error: a failed `/home` call shows "Could not load your queue" with `Retry` and leaves the project grid usable]
4. **A labeler** — the queue shows only annotate/review rows; `New project` is absent, not disabled.
5. **Recent activity** — below the fold, five rows, linked to `/w/activity`.

## Acceptance criteria
- [ ] The queue renders above every statistic and above the project grid.
- [ ] At most four queue rows, each with project, stage, count and one action; the action lands on the right filtered screen.
- [ ] Project cards carry the five-count pipeline line; a project with no versions shows `—` in that slot.
- [ ] Exactly one block is titled `At a glance`; the tour entry no longer sits above real work.
- [ ] Empty, loading and error states above all render: caught-up copy, a queue skeleton of four rows, a failed `/home` with `Retry` while the grid stays usable.
- [ ] Workspace A cannot see workspace B's data: the queue comes from `/ws/{ws}/home`; a hand-typed foreign slug never mounts the page.
- [ ] Flag off ⇒ today's KPI-first order renders unchanged.

## Notes for the implementer
Colour carries the stage in the row's left bar and in the chip's text, never as the only signal: all four stage accents are tonal violet, exactly as the reviewed frame resolved it. Do not add a fifth KPI card to make the counts look symmetric — the strip is a summary, not a dashboard.
