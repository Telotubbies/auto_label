## User story
As an ML engineer, I want to prove the model sees my object on a sample image before I read any code, and
then copy an endpoint I trust, so that "ship it" is a test, not a leap.

## UX flow (LabelDesk words)
1. **Models** (`/:ws/p/:project/models`) — "Deploy" is the one primary; the deployed model is named.
2. **Deploy & Test** (`/:ws/p/:project/deploy?tab=test`) — the test pane leads: a drop zone plus "Use a
   sample"; the endpoint card is secondary. [empty: no production model says so and links to Train].
3. **Sample image** — boxes appear with a class chip and a latency readout; the confidence slider
   re-filters without a new request.
4. **Per-class toggles** — hiding a class removes its boxes and updates the visible count.
5. **Copy snippet** — cURL / Python / JS tabs; the URL wraps and is never clipped; the copy button does not
   cover the first line. [error: copying without a key points at "Manage keys" instead of failing silently].
6. **Cold start** — a slow first request says it paid the cold start rather than looking slow.
7. **Predict failure** — a 503 names the model, the retry and the reference id; the page keeps the image.

## Acceptance criteria
- [ ] A sample image produces at least one box with a class name and a latency; no upload is required.
- [ ] The threshold slider filters the boxes client-side; the request count stays at one.
- [ ] The endpoint URL is fully readable at 1440 and 375; the copy button never covers the first line.
- [ ] Steps ≤ 8 and time ≤ 120 s; numbers recorded.
- [ ] Empty, loading and error states: no model, a slow prediction with a skeleton, a 503 with a retry.
- [ ] The cold-start sentence appears only when the response says it paid one.
- [ ] No console error; keyboard only: sample, slider, snippet tab and copy.
- [ ] Workspace isolation: a model from workspace A is not testable in B; its predict answers 404.
- [ ] Flag off ⇒ the page is the shipped deploy surface; the card adds no flag.

## Notes for the implementer
The fake adapter returns two class names from the seeded project so the per-class toggles are real. Assert
the copied text's host and path, not the whole snippet, so the snippet renderer may evolve.
