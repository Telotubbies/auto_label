## User story
As an ML engineer in a review, I want one table that shows baseline, pruned and quantised side by side with the production model's numbers, so that the trade-off is a slide I can paste rather than a notebook I have to re-run.

## UX flow (LabelDesk words)
1. **Model → `ปรับแต่ง` tab** (the shipped model screen) — the form (prune ratio, calibration source, steps) and, below it, the last report. [empty: `ยังไม่ได้ปรับแต่งโมเดลนี้`] [loading: `กำลังอ่านรายงาน`]
2. **`เริ่มปรับแต่ง`** — three stage rows fill in as they finish, with a `Progress` per stage and `ยกเลิก (เก็บชิ้นงานล่าสุด)` while running; cancelling keeps the last completed artifact and says so. [error: the calibration warning `คาลิเบรตด้วยภาพ 12 ภาพ — แนะนำ 200 ภาพ` sits above the table and does not block the run]
3. **The report table** — rows `ก่อนปรับ` / `หลังตัด` / `หลังควอนไทซ์`, columns mAP50-95, median latency, p95, size; a `ไม่ได้วัด` cell carries its reason on hover, never a zero. [error: `อ่านรายงานไม่สำเร็จ — ลองอีกครั้ง`]
4. **`เทียบกับตัวที่ใช้งานจริง`** — one extra row for the model the project's `production` alias points at, and a delta line `เล็กลง 62% · เร็วขึ้น 3.1× · mAP −0.004`.
5. **A model with no production alias** — the compare row reads `ยังไม่มีโมเดลที่ใช้งานจริงให้เทียบ` and the rest of the table is unchanged. [empty: the compare column is absent, not blank]

## Acceptance criteria

- [ ] The report shows mAP, median and p95 latency and size per stage, with `ไม่ได้วัด` and its reason where the worker could not measure.
- [ ] `เทียบกับตัวที่ใช้งานจริง` adds the production row and a delta line, and reads the no-alias sentence when there is nothing to compare.

- [ ] Flag off ⇒ no `ปรับแต่ง` tab and the model page is today's.

## Notes for the implementer
The delta line is the deliverable: size percent, speed multiple and the mAP difference to three decimals, in that order. Never compute a delta against a `null` stage — show the row without a delta instead, because `0.000` reads as "nothing changed" when the truth is "we did not measure it". Copy: `optimise.tab`=`ปรับแต่ง`, `optimise.start`=`เริ่มปรับแต่ง`, `optimise.cancel`=`ยกเลิก (เก็บชิ้นงานล่าสุด)`, `optimise.stage.baseline`=`ก่อนปรับ`, `optimise.stage.pruned`=`หลังตัด`, `optimise.stage.int8`=`หลังควอนไทซ์`, `optimise.saving`=`เล็กลง {p}% · เร็วขึ้น {x}× · mAP {d}`, `optimise.empty`=`ยังไม่ได้ปรับแต่งโมเดลนี้`, `optimise.loading`=`กำลังอ่านรายงาน`, `optimise.error`=`อ่านรายงานไม่สำเร็จ — ลองอีกครั้ง`, `optimise.compare`=`เทียบกับตัวที่ใช้งานจริง`, `optimise.noProduction`=`ยังไม่มีโมเดลที่ใช้งานจริงให้เทียบ`, `optimise.notMeasured`=`ไม่ได้วัด`.
