## User story
As an ML engineer, I want one stable name per run that I can paste into a ticket, and to see what a model's licence allows before I download its weights, so that "which run do you mean" and "may I ship this" are both answered on the row.

## UX flow (LabelDesk words)
1. **Models → row menu** — *Copy model reference* (writes `ppe-detection-v3-yolo26n-t2`), *Copy model id* (the raw id, for the API), *View evaluation*, *Download weights*. Each copy action confirms inline ("Copied") for two seconds, never with a toast queue.
2. **Detail header** — the reference renders in monospace under the name, selectable, with the same copy affordance. It is assigned when the run starts, so a queued row already shows it and the number is never reused after a failure.
3. **Weights and licence** — beside *Download weights*, one *Licence* link opens a panel: the family licence, the one-sentence permission ("AGPL-3.0: you may self-host only if your service is also AGPL-3.0, or under a commercial agreement."), and a copyable attribution line. Downloading a third-party-licensed model shows a one-time confirm that repeats that sentence.
4. **Legacy reference** — pasting `ppe-detection/3` (the old shape) into the API still resolves when the version has exactly one successful model. [error: several models and no alias ⇒ **409** "several models train on v3 — pass the model reference instead"] [error: the first run failed ⇒ **404** "no model is aliased to v3"]
5. **A failed first run burns its number** — the list shows `…-t1` as failed and the next successful run is `t2`; no row ever changes its reference.

- **States** — [empty: a legacy row without a stored reference copies its id instead] [loading: the licence panel opens from cached data with no spinner].

## Backend changes
- Models/schema: `trained_models.ref VARCHAR(140) DEFAULT ''` (unique per workspace via a `UNIQUE(workspace_id, ref)` index added in the model's `__table_args__`), and a new table `model_aliases` — `id` pk, `project_id` FK cascade, `version_id` FK cascade, `alias` `VARCHAR(64)` (the `{project}/{number}` string), `model_id` `VARCHAR(32)` (plain, no FK), `created` `FLOAT`, `UNIQUE(project_id, alias)`.
- Routers: `POST {P}/train` assigns `ref` at enqueue: `f"{project.slug}-v{version.number}-{variant}-t{n}"` where `n = count(models of this version, any status) + 1`; `model_out` returns `ref`. Resolution: `_hosted_model` accepts a bare `ref` (workspace-scoped lookup) and the legacy alias; the alias rule is one row per version, written **only** by a run that registers a model.
- Services/jobs: `services/model_refs.py` (new) — `next_ref(db, project, version, variant) -> str`, `alias_for(db, project, version) -> ModelAlias | None`, `resolve_legacy(db, ws, ref) -> TrainedModel` raising `LookupError` (404) / `ValueError("ambiguous")` (409). `handlers/training.py` writes the alias inside the `register` stage, after weights exist.
- Permissions + workspace isolation: ref lookup is workspace-scoped — a ref of another workspace is 404, never 403; `Copy` is a UI action with no server call.
- Secrets/safefetch: none.
- OpenAPI: yes — `ref` on the model payload (regenerate both files).

## Tests to write first
pytest — `apps/backend/tests/test_model_refs.py`:
- `test_ref_is_assigned_at_enqueue_and_is_parseable` — start → `ref` matches `^{slug}-v\d+-[\w-]+-t\d+$` while the model is still `queued`.
- `test_numbers_are_never_reused_after_a_failure` — model 1 fails, model 2 registers → refs end `-t1` and `-t2`.
- `test_refs_are_unique_per_workspace` — two projects with the same slug shape (different slugs) and the same version number → both refs distinct.
- `test_legacy_ref_resolves_to_the_single_model` — one successful model → `_hosted_model("ppe-detection/3")` returns it.
- `test_legacy_ref_is_409_when_the_version_has_several_models` — two models on v3 → 409 "several models"; the response names the model-reference form.
- `test_a_failed_first_run_creates_no_alias` — first run fails → `model_aliases` empty, `GET` via the legacy ref → 404.
- `test_ref_from_another_workspace_is_404` — workspace B's ref → 404, the body never echoes it.
node — `apps/frontend/tests/model-ref.test.mjs`:
- `test_ref_is_stable_and_parseable` — `modelRef({project:'ppe-detection', version:3, variant:'yolo26n', ref:'ppe-detection-v3-yolo26n-t2'})` returns the stored ref, not a recomputation.
- `test_missing_ref_falls_back_to_the_id` — an old row without `ref` returns the id so a copy never yields `undefined`.
- `test_licence_advice_covers_the_three_families` — AGPL, Apache-2.0 and "unknown" each return a distinct permission sentence and never an empty string.
- `test_agpl_download_needs_a_confirm` — `needsLicenceConfirm('AGPL-3.0')` true; `('Apache-2.0')` false.

## Acceptance criteria
- [ ] Every run has a stable, parseable reference from the moment it is queued, and no number is reused.
- [ ] The reference and the raw id are both copyable from the row and the header.
- [ ] The legacy per-version reference resolves only when unambiguous; several models is a 409, a failed first run is a 404.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no reference line, no copy actions, no licence panel; the legacy ref is unreachable.

## Notes for the implementer
The reference is store-and-echo: compute it once at enqueue, never in a renderer. The alias row is written only after weights exist, and only for the *first* successful run of a version — a later run must not repoint it.
