## User story
As a reviewer, I want to see the transformed sample with the boxes and polygons drawn on it, so that I can tell a cropped object from a lost one before I spend a generation.

## UX flow (LabelDesk words)
1. **Wizard → step 3 → Preview** — a fixed 16:9 panel showing the sample; a *Labels* toggle draws the transformed annotations as an SVG overlay in the class colours. [empty: "No image to preview yet — upload and approve one image."] [loading: shimmer inside the same box, no spinner] [error: "Preview failed — generation still works." with a retry link]
2. **Sample picker** — a small select listing the pooled image names, defaulting to the image with the most annotations ("most labels first"). [empty: one image ⇒ the select is disabled] [error: "That image belongs to another project." if a stale id is sent]
3. **Hover an annotation** — a tooltip with the class name and the shape kind ("polygon · 12 points", "box · 34% × 21%"). Never colour alone: the legend under the panel names every visible class.
4. **After a step change** — the panel keeps the previous frame at 40% opacity while the new one loads, so the comparison is visible.

## Notes for the implementer
The payload's annotations are normalised — one `viewBox="0 0 1 1"` on the SVG with `preserveAspectRatio="none"` removes every pixel conversion. Use Okabe-Ito via `classColor(index)`; never invent a colour here.
