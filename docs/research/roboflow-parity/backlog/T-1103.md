## Why
Between 2026-11-17 and 2026-11-18 the merge captain fixed each of the following by hand, more than once:
- UTF-8 mojibake (Thai cp874 bytes in place of `·` or `→`) and a UTF-8 BOM added at the start of `.ts` / `.tsx` / `.mjs` files;
- leftover conflict markers, and a union merge that dropped a closing `}` or `})`;
- duplicate identical `import` lines after a merge;
- tests that pin an exact count of things another card is expected to add (operation count, tool list);
- `node_modules` missing in the main checkout.

## Changes
`tools/check_hygiene.py` (new) plus `tools/tests/test_check_hygiene.py` (new), wired into the gate through the tools suite. The checker scans the tracked files under `apps/` and `packages/`:
- a UTF-8 BOM in any text source file → error;
- known mojibake sequences (`เธ`, `โ’`, `ยท`) in source files that are meant to be English → error. Files named in an allow-list (Thai locale files) are exempt;
- conflict markers (`^<<<<<<< `, `^=======$`, `^>>>>>>> `) → error;
- the same `import ... from 'x'` line twice in one TS/TSX file → error;
- raw colours (`#rgb`/`#rrggbb`, `rgb(`, `rgba(`) in `apps/frontend/src/**/*.tsx` outside `index.css` and the token files → error. Read design/labeldesk-v3/VISUAL-OVERRIDE.md first and allow-list what it allows.

Each error prints `path:line: rule: hint`, and the command exits 1.

## Tests first
- One failing fixture per rule (write it into tmp_path), then one clean fixture.
- Run the checker on the current tree. If it finds real hits, fix them in this card, or list them in the report if a fix would mean changing product behaviour.
- The checker must take less than 10 s on the repository.
