## User story
As an engineer on an older stack, I want a Darknet layout and a RetinaNet CSV, so that I can train without writing a converter.

## UX flow (LabelDesk words)
1. **Export dialog → Darknet** — helps the user know what they get: a `data/` folder with `train.txt`, `valid.txt`, `test.txt`, `obj.names`, `obj.data` and `labels/<file>.txt` in normalised `class cx cy w h`. [empty: split with no images ⇒ that list file is empty, not missing] [error: as T-224]
2. **Export dialog → RetinaNet** — `annotations.csv` per split with `path,x1,y1,x2,y2,class` in pixels, plus `classes.csv`. [error: as T-224]
3. **Both** — the ZIP's README names the format and the class order, and the class list order is the manifest's order, never sorted.

- [ ] Empty, loading and error states above all render.

## Notes for the implementer
No round-trip importer exists for either format, so the test asserts the written bytes, not a re-import. Write the label file with `\n` line endings and no trailing newline, the convention every Darknet loader tolerates.
