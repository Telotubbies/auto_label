## User story
As a maintainer, I want the account and security pages in their own file, so that changing a session row
does not mean scrolling past eleven unrelated pages and reviewing a diff inside a 1,168-line file.

## UX flow (LabelDesk words)
None: no visible change. The tab list, the URLs (`/:ws/settings?tab=…`), the copy, the loading skeletons
and the error panes are identical, and the pages keep their current order.

## Notes for the implementer
Move, do not refactor. If a shared helper (`TableLoading`, `TableError`, `describeDevice`) is used by a page
that stays behind, put it in a `SettingsChrome.tsx` and import it from both files; do not duplicate it and
do not "improve" it in this card. Split by `git mv`-equivalent edits so a reviewer can read the diff as a
move: new file first, then the deleted block, in two commits if that helps.
