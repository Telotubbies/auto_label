## User story
As an ML engineer, I want to freeze exactly the images I chose, see what changed against the last
version, and download the format a trainer expects, so that two people training on "v2" mean the same
data.

## UX flow (LabelDesk words)
1. **Dataset → Versions** (`/:ws/p/:project/dataset?tab=versions`) — the version list shows name, date,
   images, approved and the delta against the previous version.
2. **Generate New Version** — step 1 names what enters (approved images, filters), step 2 the split
   percentages with inline validation, step 3 preprocessing, step 4 augmentation, step 5 the summary.
   [error: 100/0/0 is refused inline, not on submit].
3. **Create Version** — the dialog is busy, then the new version appears selected with its number.
4. **Version detail** — the split bar, class counts, recipe summary and the diff list ("+6 / −2").
   [empty: a version with zero approved images is refused before it is created].
5. **Export** — the format menu lists COCO and YOLO; the request runs as a job with progress, then the
   download link appears with the file size.
6. **Download** — the archive opens and its manifest names the same image count as the detail page.

## Acceptance criteria
- [ ] The created version appears with the right image and approved counts and a computed number/name.
- [ ] The diff list names images added and removed against the previous version.
- [ ] The export produces a real download with a non-zero size and a manifest whose count matches.
- [ ] Steps ≤ 10 and time ≤ 240 s; numbers recorded.
- [ ] Empty, loading and error states: no versions yet, a busy create, an empty version refused, an export
      that fails once and retries.
- [ ] Keyboard only: the whole wizard is reachable, including the format menu and the download.
- [ ] No console error; the download is a signed URL and carries no absolute machine path.
- [ ] Workspace isolation: a version created in workspace A is absent from B and its export URL 404s.
- [ ] Flag off ⇒ the shipped versions surface is unchanged; the card adds no flag.

## Notes for the implementer
Read the archive's manifest from the downloaded file (unzip in the test), not from the API: the point is
that the file the user gets is the version they saw. Keep the fixture dataset at 24 approved images so the
split numbers are stable.
