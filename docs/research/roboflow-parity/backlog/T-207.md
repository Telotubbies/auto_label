## User story
As an engineer with forty messy class names, I want to find/replace them by pattern and see the result before applying, so that taxonomy cleanup is one action instead of forty edits.

## UX flow (LabelDesk words)
1. **Wizard → step 3 → Classes card** — the per-class table (Keep/Omit + Rename) plus a *Find and replace* disclosure with two fields and a *Preview* button. [empty: "This project has no classes yet."] [loading: the preview row shows "matching…"] [error: "That pattern is not a valid regular expression." under the Find field]
2. **Preview** — a table of *before → after* rows, with a count chip ("12 of 40 classes change") and *Apply*. [empty: "No class name matches that pattern."]
3. **Apply** — writes the rename map and closes the disclosure; *Reset* reverts both the map and the regex.
4. **Regex controls appear only above three classes** (below that, manual editing is faster): "Find and replace appears when a project has more than three classes."
5. **Count line** — "3 classes → 2 · 412 boxes → 398" from the preview response.
