## User story
As the person building the ten screens, I want a header with one action slot, a chip that never relies on colour and an error sheet that says what survived, so that ten screens cannot invent ten versions of the same block.

## UX flow (LabelDesk words)
1. **Every screen** — the page header is a 124 px block: `h1` at the shipped `text-2xl` (24/32), one line of description, one action slot on the right. The gradient band stays only on the project overview, where it is the screen's single expressive moment.
2. **A chip** — class, split, status or saved view: `text-xs`, name plus optional dot, never colour alone; `Chip` renders a `<span>` unless it is pressable, in which case it renders a `<button>`.
3. **Empty state** — one sentence, one primary, one "why" link that opens the help text; no illustration. [empty: the empty state is the empty state — no nested empty marker]
4. **Error sheet** — a failed bulk action opens a sheet naming what succeeded, what did not, the reason per group and a `Retry failed` action, with a reference id when the server supplied one. [error: a second failure replaces the sheet's body, it does not stack a toast on top]
5. **Inline alert** — warning and error tones use the shipped role classes (`bg-warning/15 text-warning`, `bg-destructive/15 text-destructive`, the idiom `StatusPill` already uses), never a bare red background, and always include the word (`Failed`, `Warning`).
