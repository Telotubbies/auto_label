## User story
As a reviewer working a queue of 200 images, I want Next image in the header next to Approve, so that I can clear the queue with one hand on the arrow key and one on the approve key.

## UX flow (LabelDesk words)
1. **Editor header** — filename, split chip, review-state chip, save state (`Saved` / `Unsaved` / `Saving…`), then `Next image →` and `Approve` / `Reject` at the right edge; `Back to board` is an icon button on the left. [error: a failed save keeps `Unsaved` visible and offers `Retry`; Next image is disabled until the save settles so an edit is never dropped]
2. **Approving** — `Approve` (or `A`) advances to the next image in the same queue; a toast names what happened ("Approved · 12 of 16"). Reject asks for a reason only when T-129's sheet is enabled.
3. **Floating glass toolbar, bottom centre** — `Smart Polygon`, `Label Assist`, a divider, then `Display` and the zoom stepper. The rail no longer holds Smart Polygon, so it stops being the loudest control in the panel. [error: Label Assist with no ready model is dimmed with the reason "No trained model yet", not hidden]
4. **Metadata** — nothing below 12 px: class hotkeys, object counts, thumbnail captions and the dashed-AI legend move to 12/13 px.
5. **Keyboard, no pointer** — `B` draw, `→` next, `A` approve, `Escape` back to the board; the shortcut list lives in the palette/modal, not printed on screen.

## Acceptance criteria
- [ ] The header shows filename, split, review state, save state, `Next image →`, `Approve` and `Reject`, and nothing else is a primary.
- [ ] Approve advances to the next image and reports progress ("Approved · 12 of 16"); `→` and `A` do the same without a pointer.
- [ ] `Smart Polygon` and `Label Assist` live in the bottom floating toolbar with display and zoom; the rail holds neither.
- [ ] No metadata in the editor shell renders below 12 px.
- [ ] Empty, loading and error states above all render: a save failure keeps `Unsaved` with `Retry`, the last image disables Next with "Last image in this queue", and an assist with no model is dimmed with its reason.
- [ ] Workspace A cannot see workspace B's data: the next-image slice comes from the current project's `/images`; a foreign id 404s and the editor shows not-found.
- [ ] Flag off ⇒ today's header, bottom bar and rail render unchanged.
