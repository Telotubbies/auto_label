## User story
As a labeler, I want to mark a proposal wrong and have the next pass learn from it, so that a tray of identical parts is one example plus a slider instead of twenty drags.

## UX flow (LabelDesk words)
1. **Editor → floating assist toolbar → "Find all similar"** — the entry is enabled only when the selected shape is a bbox and the project has at least one class; otherwise the tooltip says "Draw or select a box first". [empty: an image with no boxes → the entry explains what is missing] [loading: proposals in flight → the tool shows "Finding similar objects…"]
2. **First pass** — pressing the tool sends the selected boxes as positive examples with the selected class and the current threshold; the proposal bar (T-151) opens with the count. Proposals render dashed, never solid.
3. **Confidence slider** — the tool's popover carries `5–95%`, default 40%, and re-filters the *existing* proposals locally: dragging it never triggers a second paid call, and the hint says so ("Filters what was found; Predict runs again").
4. **Convert to negative** — right-click a proposal → **Not this object**: it becomes a shaded negative example, the whole set refreshes once (debounced 400 ms), and the count in the popover reads "2 negatives". The same action on an existing committed annotation flips it to a negative example without deleting it.
5. **Refresh while you work** — with the tool on, every saved or deleted annotation triggers one debounced re-run; the popover shows "Refreshing…" and keeps the previous proposals visible until the new set arrives.
6. **Approve predictions** — the proposal bar's Keep all freezes the set into annotations; navigating away without approving drops them silently (documented in the popover's one-line rule), and the tool turns itself off on image change.
7. **Counter** — the popover footer reads "128 boxes of this class in the project" from the class counts, and the sheet states in one line that this is a similarity pass over one detection, not a model that learned. [error: 402 → "No AI calls left on this plan" with the Usage link; 503 → "The model is not reachable right now", the tool stays on with a Retry]

## Acceptance criteria
- [ ] Find all similar needs one or more selected boxes, runs one paid pass and hands its proposals to the proposal bar.
- [ ] The threshold re-filters existing proposals without another call; Predict is the only way to spend again.
- [ ] Not this object creates a negative example and re-runs once per burst of edits.
- [ ] Approve predictions is the only path that saves; leaving the image drops the set and disables the tool.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ no tool entry and no request; every other tool is unchanged.
- [ ] Keyboard-only path: select a box → Tab to the toolbar → Enter → Tab threshold → arrows → Tab Keep all → Enter.

## Notes for the implementer
The negative flag lives in editor state and is sent as annotation ids — never write a hidden "negative" field into the saved annotation, or exports would carry a field no format understands. The footer counter is `classes[].count`, not a training-set claim.
