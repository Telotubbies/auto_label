## User story
As a labeler, I want the left rail to be classes and objects only, so that Attributes, Comments, History and Raw stop competing with the class list I use every second.

## UX flow (LabelDesk words)
1. **Editor** — the left rail is 264 px with two tabs, `Classes` and `Objects`; the class list keeps the search field, the hotkey digits, the create row and the AI-dashed legend. [empty: no classes yet → "No classes yet — add the first one below"; a search with no hit → "No class matches" plus the create row]
2. **Objects tab** — the object list keeps its order, hide, lock and delete actions and its `Top = front` hint.
3. **Inspector button** — a button in the header opens a right inspector sheet with four sections: Attributes, Comments, History, Raw. Each section renders exactly what the old tab rendered. [error: a failed comments call shows its retry inside the section, and the sheet stays open]
4. **Keyboard** — `1–9` pick a class, `/` searches, `Escape` closes the inspector sheet and returns focus to its trigger; the sheet is reachable with Tab when open and is not in the tab order when closed.
5. **1280 px and below** — the rail collapses to icon width as it does today; the inspector sheet becomes full width below `md`.
6. **A reviewer** — the same two tabs; the review state is a header chip, not a rail tab.
