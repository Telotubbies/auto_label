## User story
As an ML engineer, I want to see the weak clusters and click straight into their worst images, so that a collectable dataset task comes out of one picture.

## UX flow (LabelDesk words)
1. **Insights → Embeddings → Colour by → Model score** — the map recolours on a viridis ramp from 0 (deep violet-low) to 1 (bright); a legend reads "per-image F1 · 0 → 1 · 312 of 480 scored". Unscored points are grey with a legend entry of their own.
2. **Model picker** — a compact select beside the colour control listing evaluated models ("YOLO26 Nano · v3 · mAP 0.61"); the choice is in the URL (`?color=model&model=<id>`) so a refresh and a shared link keep it.
3. **Lasso or click** — selecting points opens a side list sorted worst-first: thumbnail, file, F1, and *Open* which goes to the dataset image; a cluster with no scored points reads "No evaluated images in this selection."
4. **A cluster summary** — the list header counts them ("18 images · median F1 0.24") so the weak cluster has a number to quote.
5. **No evaluation** — the colour option is present but selecting it shows the T-281 note and keeps the previous colouring; the control is not silently disabled. [error: the join fails ⇒ "Model scores could not be loaded" with Retry, the map still renders in its previous colour]
6. **Too few points** — under 20 points the map keeps rendering; the colour option says "A score map needs at least 20 images to be meaningful." and stays selectable.

- **States** — [error: a failed join keeps the previous colouring and shows one line with Retry]. [empty: a selection with no scored images reads "No evaluated images in this selection."] [loading: the list shows three row skeletons while the join resolves].
