## User story
As an aerial-inspection engineer, I want a plain rows×cols grid or a fixed-aspect cut with overlap and padding, so that a small object fills a tile instead of vanishing at 640 px.

## UX flow (LabelDesk words)
1. **Wizard → step 3 → Tiling card** — a mode select: *Grid (rows × columns)*, *Fixed size (W×H, overlap)*, *Fixed aspect ratio (ratio, span)*. [empty: mode grid, 2×2] [loading: the tile count reads "…"] [error: "Tile size must be at least 224 px." next to the field]
2. **Tile count line** — grid: exact count per image ("4 tiles per image"); fixed size/aspect: "≈ 6 tiles for this image · no estimate for the whole pool — it depends on each image's size".
3. **Padding** — fixed modes expose *Pad edges with black / white*; tiles cover the right/bottom remainder with the chosen fill and never overrun the source.
4. **Too small** — an image smaller than one tile stays whole ("480×360 kept whole").

## Backend changes
- Models/schema: none.
- Routers: none (recipe value); `POST /versions/preview` reports `tiles = {count, exact}`.
- Services/jobs: `app/services/tiling.py` — `Tiling` gains `mode: "fixed" | "grid" | "aspect"` (default `"fixed"`, so inference slicing and every stored recipe keep working), `rows`, `cols`, `ratio`, `span`, `padding`; `boxes(width, height)` dispatches: grid = equal cells from integer division with the remainder in the last row/column; aspect = tile width from `ratio` and `span`, step from `overlap`, right/bottom remainder padded to the full tile size. `parse()` accepts the flat dict it accepts today and validates 224–4096 px, overlap 0–0.9, rows/cols 1–8.
- Permissions + workspace isolation: unchanged; create keeps the `task_30` gate and the "detection or segmentation only" 400.
- Secrets/safefetch: none.
- OpenAPI: no route change.
- Flag: `task_190` off ⇒ `mode: "grid"/"aspect"` is a 400 `tiling_mode_unavailable`; `mode: "fixed"` behaves exactly as today.

## Notes for the implementer
The 224 px floor is a *dataset* rule (F4.23); `MIN_TILE = 64` stays for inference slicing, so put the dataset floor in `recipe.py`, not in `Tiling.MIN_TILE`. Aspect mode with `span="width"` fixes the tile **width**; the height follows the ratio.
