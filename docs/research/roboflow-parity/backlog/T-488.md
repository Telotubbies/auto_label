## User story
As someone on a slow connection, I want the page to show the shape of what is loading instead of a spinner, so that the layout does not jump when the data arrives.

## UX flow (LabelDesk words)
1. **Home** — the queue renders four row skeletons, the project grid renders the same number of card skeletons as the last known count (or six), and `At a glance` renders four number skeletons. Heights match the real rows. [loading: `aria-busy="true"` on the region, one `role="status"` sentence for a screen reader]
2. **Project overview** — five card skeletons in the board's grid and three blocks in the aside.
3. **Stage rail** — the five rows render with a skeleton count instead of `0`, so a slow project fetch never claims "nothing uploaded".
4. **Reduced motion** — the pulse stops (the global rule already handles it); the skeleton stays visible as a static block.
5. **Error instead of load** — the skeleton is replaced by the error block, never left shimmering forever. [error: after the retry fails twice the region shows the error copy with the reference id]

## Notes for the implementer
Match the real geometry by importing the same height constant the row uses, not by copying a number — a skeleton that drifts is worse than a spinner, because it teaches the wrong layout.
