## User story
As the owner, I want every English and Thai string checked for one-term-per-concept, real Thai, no filler
and no machine translation, with the Thai list handed to a native reviewer, so that the Thai UI is a market
claim we can stand behind.

## UX flow (LabelDesk words)
1. **The catalogue** (`lib/i18n.ts`) — every key has English and Thai; a key with only English is listed.
2. **The lint** — a failing key names the file, the key and the rule; the test fails on: missing Thai,
   identical English and Thai (untranslated), a Thai string built with `slice()`, a raw number or date where
   a formatter exists, a banned marketing word, a doubled sentence across empty states.
3. **The written pass** — one term per concept across status, stage, action and object; the glossary table
   in the report is the authority.
4. **The Thai list** — every Thai string flagged "needs native review", grouped by screen, with the machine
   check that passed and the one that needs a human (tone, politeness, domain word).
5. **Findings** — S1–S4 in the program's format; each S1/S2 names a proposed fix card title.

## Acceptance criteria
- [ ] Every catalogue key is checked; the count of checked keys is printed.
- [ ] The glossary names one term per concept (status, stage, action, object) and matches the UI.
- [ ] Every Thai string is flagged for a native reviewer; the report never says "Thai approved".
- [ ] Machine Thai is treated as a failure even when it looks fluent; the UI-AUDIT examples
      (`ยัวจระเข้`, `ไม่มีความในภาพ`) are cited as the standard.
- [ ] The lint runs in `npm test` and fails on a new key without Thai.
- [ ] Empty, loading and error states: their copy is included in the pass, not skipped.
- [ ] Workspace isolation: not applicable; strings are global.
- [ ] Flag off ⇒ not applicable; the catalogue is not flag-gated.

## Notes for the implementer
Do not translate in this card and do not claim native quality. The deliverable is a list a Thai reviewer can
work through in one sitting, plus a lint that stops the next agent from adding English-only keys.
