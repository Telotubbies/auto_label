## User story
As an engineer, I want the question we ask the VLM to be a named object with versions and a production alias,
so that a prompt change is a reviewable diff instead of a string edited in a form and forgotten.

## UX flow (LabelDesk words)
1. **Workspace → Prompts** — `/:ws/prompts`: name, latest version, the aliases pointing at it, who last
   edited, and how many calls resolved it. [empty: "No prompts yet" with *Create prompt*] [error: "Prompts
   could not be loaded" with *Try again*]
2. **Create** — name, template with `{{ }}` variables, a commit message, and two optional advanced blocks: a
   JSON response schema and model settings (model, temperature, max tokens). [error: an unclosed `{{` is
   refused with the character position and the text kept]
3. **New version** — *New version* bases the editor on a chosen version, shows a side-by-side diff of the
   template, and saves version *n+1*; the old version stays readable. [loading: the diff renders after the
   base version is fetched; the editor is disabled meanwhile]
4. **Alias** — *Point production here* moves the `production` alias to the selected version; the previous
   target is shown and *Roll back* restores it.
5. **Usage** — *Used by* lists the models and playground runs that resolved this prompt, with the version each
   resolved. [empty: "not used by any model yet"]

## Backend changes
- Models/schema: new table module `apps/backend/app/models/prompts.py` (new) — `Prompt(id, workspace_id,
  project_id NULL, name, created, created_by)` unique `(workspace_id, name)`; `PromptVersion(id, prompt_id FK
  ondelete=CASCADE, version, template TEXT, commit_message, response_format JSON NULL, model_config JSON NULL,
  created, created_by)` unique `(prompt_id, version)`; `PromptAlias(prompt_id, alias, version, updated_by,
  updated)` PK `(prompt_id, alias)`. Registered in `models/__init__.py`.
- Routers: new `apps/backend/app/routers/prompts.py` (new), `P = "/api/ws/{ws}/prompts"`: `GET {P}` list,
  `POST {P}` create (version 1), `GET {P}/{name}` with all versions, `POST {P}/{name}/versions` body
  `{template, commit_message, response_format?, model_config?}`, `PUT {P}/{name}/aliases/{alias}` body
  `{version}` and `POST {P}/{name}/aliases/{alias}/rollback`, `GET {P}/{name}/usage`. 400 for a duplicate
  name, an unclosed `{{`, a version number that does not exist, or an alias outside `production|staging|
  latest-dev`; 404 for a foreign or unknown prompt.
- Services/jobs: `apps/backend/app/services/prompts.py` (new) — `resolve(db, workspace, ref)` accepting
  `<name>` (latest), `<name>/<version>` and `<name>/<alias>`, returning the `PromptVersion` or raising
  `UnknownPrompt`; `variables(template)` for the UI; `render(version, values)` doing a fixed-map substitution
  of the template's own variables (`{{x}}` only, never `str.format`).
- Permissions + workspace isolation: read `project.review` at workspace scope, write `c.need("admin")`; a
  prompt from another workspace is a 404. Prompts are workspace-scoped (`project_id` null today, so a prompt
  can be shared later without a migration).
- Secrets/safefetch: none. Dependency: none added (no `mlflow-skinny`), so no
  `THIRD_PARTY_LICENSES.md` change.
- OpenAPI: yes — regenerate both files.

## Acceptance criteria
- [ ] A prompt has immutable versions; editing always creates a new one.
- [ ] An alias resolves to a version, can be moved and rolled back, and the previous target is recorded.
- [ ] A template with an unclosed brace or an undeclared variable is refused with a position or a name.
- [ ] Empty, loading and error states above all render.
- [ ] Workspace A cannot see or change workspace B's data (404, not 403, for cross-workspace ids).
- [ ] Flag off ⇒ surface absent and the old behaviour unchanged.

## Notes for the implementer
Overlap: none. `5-F5.7`/`5-F5.9` version a training recipe; a prompt is not a recipe and must not be stored in
the workflow block JSON.
Resolution is by name plus optional version or alias, resolved once per call; never cache a resolved version
across requests or a rollback would not take effect.
