## User story
As a workspace admin, I want one list of segmentation models with their memory, licence and whether
this host is provisioned, so that auto-label uses a model that exists instead of failing at run time.

## UX flow (LabelDesk words)
The screen is T-1015; this card supplies rows and the provisioned verdict.
1. **Segmentation tab** — SAM 3.1, SAM2, YOLO26 Seg (n/s/m), Mask2Former Swin-L, each with parameter
   count, VRAM at 512 px and 1024 px, licence badge, source link and a state chip.
2. **State chips** — `Ready` (checkpoint and adapter present), `Missing checkpoint` (named path),
   `Adapter not installed`, `Not supported on this OS`.
3. **Licence** — `SAM License`, `Apache-2.0`, `AGPL-3.0` (YOLO, badge kept per the hard rule),
   `CC-BY-NC-4.0` (Mask2Former weights, `Non-commercial` badge).
4. **No project** — the use action is disabled with "Choose a project first." [empty: no provisioned
   model → "No segmentation model is provisioned on this host." + a link to the setup doc].

## Backend changes
- Models/schema: none.
- Routers: `GET /api/ws/{ws}/inference/segmentation?host=&project=` → `{models: [...], project:
  {slug, name} | null}`; each row `{id, name, family, params_m, licence, vram: {"512": mb, "1024": mb},
  engine, source_url, provisioned: {ok, reason}, auto_label: {ref, engine_hint, classes_required}}`.
- Services/jobs: `apps/backend/app/services/inference_segmentation.py` (new).
  - `SEGMENTATION: list[dict]` — the five rows; VRAM figures are **published/measured** values with a
    `source_url` and a note, not derived from the LLM estimator (image-resolution activations are a
    different model).
  - `provisioned(model, host_inventory)`:
    - `sam3.1` → `SAM_ENABLED != "0"` and `(SAM_ROOT / "checkpoints" / "sam3.1_multiplex.pt").exists()`
      (the shipped path) and the adapter import path exists.
    - `sam2` → a checkpoint under `LD_SEG_MODELS_DIR` named `sam2*.pt`, else missing with that env named.
    - `yolo-seg` → `PRETRAINED_DIR.glob("yolo26*-seg.pt")` non-empty (ADR 0004's env contract).
    - `mask2former` → `LD_SEG_MODELS_DIR` contains a `mask2former*` directory, else missing.
    - A row that needs a GPU is `Not supported` when the host reports `gpus: []`.
  - `auto_label_ref(model)` returns the exact ref the existing flow accepts (`sam3:sam3.1`,
    `ultralytics:yolo26n-seg`, …, matching `adapters/catalog.py::_zoo` names), plus whether the project
    must have classes.
- Permissions + workspace isolation: admin only; `project` resolves via the existing `project_ctx`
  (slug + workspace), a foreign or unknown slug is 404; `host` from the deployment's host list.
- Secrets/safefetch: none.
- OpenAPI: yes.

## Notes for the implementer
Do not run the LLM estimator for these rows: segmentation memory is dominated by image-resolution
activations and encoder choice, so the catalogue carries published figures and says so. Read `SAM_ROOT`
and `PRETRAINED_DIR` from `config.py`; never hard-code `../labeldesk-ml`.
